个人学习工具

深度扎根

由人工智能协助创建的学习工具使用网站

把平时手写的题目与答案整理归档，按间隔安排回顾。本站由个人开发者借助人工智能辅助工具搭建与维护，用来介绍这套自用工具的用途与用法。

功能一览 使用方法 关于数据

功能一览

从记录到回顾，围绕一次练习把零散的纸面内容收拢起来。

拍照整理题目

把纸面上的题目和手写答案拍下来，自动识别成可编辑的文字，省去逐个打字。

按学科归档

按学科、按年级分类保存，查找时可以先限定范围，再看具体条目。

标记做错的题

做错的题单独标记，方便之后集中回看，不必翻遍所有记录。

到期提醒回顾

按 1、3、7、14、28 天的间隔安排回顾，到期后在列表里提示。

汇总导出

把选中的条目合成为 PDF 或 Word 文件，方便打印或在别的设备上查看。

找回自己的资料

在自己导入的资料里按题目内容检索，找到出处后打开核对。

使用方法

三步走完一次记录，后面的回顾交给时间。

  1. 拍照或导入题目图片，确认识别出的文字后保存。
  2. 选择学科与年级，保存时自动归档；做错的题加上标记。
  3. 之后按提示到期回顾；需要时把若干条目汇总导出。
