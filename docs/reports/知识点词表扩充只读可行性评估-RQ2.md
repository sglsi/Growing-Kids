## 0. 结论摘要

**技术上可行，但不建议把 870 个知识点名整批导成词表替换现有 `TOPIC_TERMS`。** 四条理由：

1. **形态不匹配，只能增补不能替换**：870 个节点名是「长短语 / 教材单元名」，现有 55 词是「2–4 字短术语」。简单切分得 832 个候选，与 55 词**仅 8 个完全重合**；而 **55 词中有 47 个根本不出现在任何候选层**。
2. **噪声明显**：原始名混有变量与公式（`y=ax² 的图象与性质`、`c 关系`）、方位词（`东北`、`东南`、`上下前后左右`）、教材活动名（`七巧板`、`买卖我做主`、`低碳生活`）。直接入库会造出无意义共现信号。
3. **有「更多但更差」的实证风险**：在图谱 3,627 道合成题上做方向性诊断，词表从 55 → 434 词后，命中 ≥3 个术语的题从 **2.3%(84) 升到 5.8%(209)**；`sharedSignals()` 的 `MIN_SHARED_SIGNALS=3` 会更容易被凑够 ⇒ 可能放进更多低质量参考例题。**该数字来自合成题，不得外推到本项目 OCR 题干。**
4. **改动成本不在词表本身，在契约**：改 `question-reference.ts` 会破 `P-025 T4`「契约 sha 前后一致」口径，须另立提案 + 评估 `CACHE_VERSION v14`（旧缓存留存旧 Top-3）+ 同步 M37 断言 + 独立盲测验证。

⇒ **RQ2 产出是「可行性结论 + 分层候选清单」，不是待落地代码**。词表扩充**仍是字面匹配，不解决 OCR 错字，不能替代语义召回**（`P-026` 线 A）。

## 2. 实测数据（本地全量解析，非 README 自述）

### 2.1 输入形态

| 指标 | 实测值 |
|---|---|
| 现有 `TOPIC_TERMS` | **55** 词（55 unique）；语域为 K12 中文理科短术语 |
| 数学节点 | **870** 个，唯一名 **861**（9 个重名） |

| 含括号 / 数字 / 分隔符 | **17 / 32 / 41** 个 |
| 领域分布 | 数与代数 430、图形与几何 277、统计与概率 114、综合与实践 49 |
| 学段分布 | 14 个 `grade` 值（1–14），初中段（7/8/9）合计 315 个最密 |

### 2.2 候选词分层

| 层 | 规则 | 词数 | 不在现有 55 词 | 与 55 词完全重合 |
|---|---|---|---|---|
| 原始切分 | 去括号 + 分隔符切分，不做汉字/长度过滤 | **832** | **824** | **8** |
| **L1 严格层** | 2–6 字纯汉字 | **387** | **379** | **8** |
| **L2 中等层** | 2–8 字纯汉字 | **618** | **610** | **8** |

- 现有 55 词中 **50 个**能以**子串**形式出现在 870 个节点名里（与上一轮报告一致，语域同源成立）。
- 但 **55 词中 47 个不在任何候选层** ⇒ 原因：图谱名多为「三角形的面积」「一元二次方程的解法」这类长短语，切分后不会单独产出「面积」「方程」。**替换会丢掉现有最有效的短术语，只能取并集增补。**
- L1 新增词长度分布：2 字 38、3 字 49、4 字 94、5 字 116、6 字 82。

### 2.3 噪声实例（必须人工裁剪）

| 类型 | 实例 | 问题 |
|---|---|---|
| 变量 / 公式 | `y=ax² 的图象与性质`、`c 关系`、`k 的图象与平移` | 含拉丁字母与公式，OCR 题干中写法千变万化，作字面词必失效 |
| 方位 / 常识 | `东北`、`东南`、`上下前后左右` | 不是数学术语，会在应用题里高频误命中 |
| 教材活动名 | `七巧板`、`买卖我做主`、`低碳生活`、`体育中的数学` | 是单元/情境名，不是可复用共现信号 |
| 超长短语 | `一次函数与二元一次方程组`（13 字） | 精确字面共现概率极低，等于不生效 |
| 同义重复 | `三角形内角和定理` / `三角形的内角和` / `三角形的内角和定理` | 同一知识点多种写法，会造成同一信号重复计数 |

## 3. 假共现风险（方向性诊断，不外推）

`sharedSignals()`（`question-reference.ts:140`）对**每个词**做 `question.includes(t) && stem.includes(t)`，`MIN_SHARED_SIGNALS = 3`（`:112`），命中数用于参考例题筛选与排序。词表扩大 ⇒ 任意两道题凑够 3 个共享词更容易 ⇒ 可能放进更多「字面像、思路不相干」的参考例题。

用图谱 3,627 道数学合成题的 `prompt` 做命中分布对比（**只用图谱自带题，未碰生产数据；仅诊断、不得外推到本项目 OCR 题干**）：

| 词表 | 词数 | 命中 ≥3 词的题 | 占比 | p50 | p95 | max |
|---|---|---|---|---|---|---|
| 现有 55 词 | 55 | **84 / 3,627** | **2.3%** | 0 | 2 | 8 |
| 55 + L1 严格层 | 434 | **209 / 3,627** | **5.8%** | 0 | 3 | 11 |
| 55 + L2 中等层 | 665 | **215 / 3,627** | **5.9%** | 0 | 3 | 11 |

**读法与限制**：

- 「命中 ≥3」是**共享信号数**，不等于参考例题质量；上升 2.5 倍只说明阈值更易被满足，**不能推断「变好」也不能推断「变坏」**。
- 图谱题是纯文字自包含合成题（题干 p50 28 字），本项目题干来自 OCR 教辅 PDF（图形、公式、题号噪声、`U+FFFD` 2,007 条，D-034）⇒ **分布严重不匹配，该比例不可外推**。
- 真要判定，必须走 `P-026` T0：独立盲测样本（与调参样本物理分离）+「Top-3 中至少 1 条同知识点 / 同方法」事前注册判据。
- **另有未实测的在线成本**：`sharedSignals()` 是词表长度 × 题干长度的线性 `includes` 循环，且在深挖循环内对每份文档的每行对象执行；词表从 55 → 434/665 会增加在线扫描量。当前 P95 实测 **3443/3457/3488 ms**，硬闸是 `P95<3s`（**尚未达标**）⇒ 该项须计入 `P-026` A1 的 L3 资源实测，**本轮未测、不下结论**。
