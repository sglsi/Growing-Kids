## 3. 阶段 B · 分段计时（Q1①）

### 3.1 方法（零生产变更的三个抓手）

| 抓手 | 说明 |
|---|---|
| 端点差分 | `GET /netdisk/search?q=…`（全链路）vs `?q=…&deep=0`（同一 `searchLocal` / 输入闸门 / 打分，**只跳过深挖循环 + 同源例题 + 附件装配**）。controller `@Query('deep')` 既有只读能力，不是新埋点 |
| 双端对账 | 响应自带 `data.tookMs`（服务端内部计时）与客户端 `Date.now()` 对账 |
| 只读复现 | `pg` 直连复现通道 A/B SQL；PostgREST `GET /rest/v1/netdisk_files?…` 复现通道 B 端到端；JS 归一化逐字复用生产编译产物 `dist/shared/public-library.js::flatText` |

脚本 `.tmp/gk-p021-stageB.mjs`（临时诊断，**不进 `server/scripts/`**）；分析 `.tmp/gk-p021-analyze.py`。6 轮 × 5 题 × 2 模式 = **60 次**，nonJson 0 / errors 0 / `exact=0` / `deepCount=8` 恒定 / `refs≤3`。`deep=0` 的 note 全部为「按资料库索引检索（…未读取正文深挖）」⇒ 参数确实生效。

### 3.2 分段构成（以 `geo-fixed` 稳态档为主，均为间接推导）

| 段 | 耗时 | 证据 | 等级 |
|---|---|---|---|
| L0 通道 A：`name/path ilike` 多 OR，284 行 | **892 ms**（5 次 892/892/889/889/892） | `pg` 直连同量级 SQL | 间接复现 |
| L0 通道 B：`text_flat ilike`，1,133 行 / 9.29M 字符 | **462 ms** DB（690/475/448/462/449） | `pg` 直连 + D-029 的 490ms `EXPLAIN ANALYZE` 互证 | 间接复现 |
| 通道 B 经 PostgREST 端到端 | **769 ms** / 9,626,831 B（809/776/769/746/727） | 只读 `GET /rest/v1/…` | 间接复现 |
| ↳ 序列化 / HTTP / JSON 解析增量 | **≈307 ms** | 769 − 462 | 差分 |
| L0 JS 归一化（`flatText` × 1,133 行） | **39 ms** | 生产 dist 逐字复用 | 直接复现 |
| L0 打分 / 合并 / 排序 / hits 组装（残差） | **≈0.4 s** | `deep=0` 端点 ~2.1s − 上述 ~1.7s | 残差，**非直测** |
| 深挖 8 份 + 判定层 + 同源例题 + 附件装配 | **≈0.19 s**（上界） | 配对差分，见 §3.3 | 差分 |
| 客户端 − 服务端 | **4 ms**（max 21ms） | `tookMs` 对账 | 直接 |

🔴 通道 A 用响应里的真实 `keys` 构造 OR，通道 B 用 D-029 已验证的两个长锚点（`平行四边形` / `面积最大值`）；生产 `pickTextAnchors()` 的实际产出未逐字复现 ⇒ 上述 DB 段是**同量级复现**，不是逐字埋点。

### 3.3 配对差分（`full − shallow`，同轮同题；修正中位数错位）

| tag | n | 中位数 | 均值 | min / max | shallow/full |
|---|---|---|---|---|---|
| `geo-raw` | 6 | 149 ms | −41 ms | −1028 / 203 | 106.2% |
| **`geo-fixed`** | 6 | **193.5 ms** | **190.5 ms** | **156 / 211** | **93.2%** |

## 5. 边界与不宣称

- **分段是差分与同量级复现，不是生产埋点**：未改一行业务代码、未贴临时日志级别、未设环境变量。判定层与附件装配**没有单独埋点**，二者与深挖一起被 0.19s 的差分包住 ⇒ 只能给合计上界，不能给各自数值。
- **A/B 交替会互相扰动缓存**，故负差分与 >100% 比值如实保留；若需精确分段，须另立提案申请只读副本上的诊断埋点。
- **不归因**：没有切题前后同条件对照，仍不能把长尾归因于 `question_objects` 行数翻倍；D-028 / D-029 的「不归因、不宣称达标、不回滚」处置完全保留。
- **不实施**：`§5` 六个候选优化方向本轮一个都不做；列裁剪 / 索引 / 预算相关改动须独立提案 + 前后对照 + M 门同步。
- 采样是单机、单端点、5 条构造题的方向性证据，**不外推真实用户分布、不计算召回率**；`exact=0` 不表述为「误判归零」。
- 与本轮无关但状态不变：P-020 抠图仍不放行，Q5 / F4 / 阶段 2 小批量 / 阶段 3 二次评审未授权，`question_inline_figures` 的 `.doc` 来源仍 **0 行**。
