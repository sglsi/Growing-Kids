## 0. 先纠正一个容易搞错的点

**「公安联网备案数据码」不是「已通过公安备案」的证明。**

它是腾讯云把你在 ICP 备案时填的主体/网站信息**同步给公安部平台**后拿到的一串关联凭据（32 位十六进制，**有效期 30 个自然日**）。作用是：你到公安部平台输入这串码，系统把 30 余项信息自动填好，你只需补 7 项就能提交。

真正的「已通过」标志只有一个：**拿到公安备案号**，形如 `陕公网安备 61011302000XXX号`，且在平台「我的 → 我的网站 → 详情」里能下载备案编号图标。

所以现在的状态是：**ICP 备案已完成，公安联网备案待办，且 30 天倒计时已经在走。**

|---|---|---|

| 网站（域名）ICP 备案 | ✅ 已通过（2026-11-04，腾讯云新增服务） | 腾讯云备案控制台「备案成功」页 |

### 1.2 已经做了什么

首页源文件此前不在仓库里（直接改的服务器），且 footer 写的是占位符：


本轮已处理：

1. 首页纳入仓库：`server/www/index.html`（此前无副本，改动无从追溯）

### 1.3 备案号后缀：已核实（2026-11-04）

**结论：两个服务条目后缀不同，且都必须按原文挂，禁止"统一"。**

| 服务条目 | 备案号（腾讯云控制台原文） | 挂载位置 |
|---|---|---|
| 微信小程序（成长学童） | `陕ICP备2026030931号-1X` | 平台自动展示 + 包内 `ICP_FILING_NO` |
| 网站（`deep-root.cn`） | `陕ICP备2026030931号-2` | 首页 footer（`server/www/index.html` → `/srv/www/index.html`） |

⚠️ 本条曾按"新增服务会分配新后缀，待核实"记录。2026-11-04 思傅回传控制台原文确认网站为 **`-2`**；当日线上首页仍是 `-1X`（占位值），已改为 `-2` 并重新部署。

**核对方法**：腾讯云控制台 → 备案 → 我的备案 → 找到本次「新增服务」那条记录 → 复制完整备案号（含 `-N` 后缀），与下面两个值逐字比对。

```bash
# ⚠️ 下面两条都在**开发机仓库根目录**执行。
#    服务器上只有构建产物（dist / server/dist），没有 src/ 源码树，
#    在服务器上跑第一条必然报 "No such file or directory"——那是路径问题，不是文件丢了。

# 2) 线上首页（网站悬挂用，期望 -2）
```

**如果后缀不一样**，要改两处（网站一条、小程序一条可以不同，但不能错）：

| 位置 | 用途 | 改哪里 |
|---|---|---|
| 网站首页 | 管局/腾讯云核查 | 服务器 `/srv/www/index.html`（源文件 `server/www/index.html`） |

## 2. 第二项：保持备案信息真实有效（必须）

这一项不是一次性动作，是持续义务。腾讯云/管局会做「专项核查」（截图里那个链接），核查不通过会被责令整改，严重的注销备案号。

### 2.1 四条硬约束（对本项目逐条对照）

| 约束 | 本项目现状 | 动作 |
|---|---|---|
| 域名必须解析到**腾讯云**服务器 | `deep-root.cn` / `www` → `42.192.36.120`（腾讯云轻量 L3）✅ | 别把域名解析改到别家 |
| 网站必须**可公开访问** | `http://deep-root.cn/` → **308 跳 https** → `https://deep-root.cn/` 200 ✅ | 别关 80/443 端口、别加访问口令。⚠️ 见下方「关于 308 跳转」 |
| 网站**名称**必须与备案填写的一致 | 首页 `<title>学习记录</title>` | ❓ 核对备案时填的网站名称是否就是「学习记录」 |
| 网站**内容**必须与备案的服务内容一致 | 首页：「个人学习内容整理与复习工具」 | ❓ 核对备案「服务内容」选项（应为「其他」，不能是教育/培训类） |

#### 关于 308 跳转（2026-11-04 启用 HTTPS 后新增）

11:11 起 `http://deep-root.cn/` 返回 **308 → `https://deep-root.cn/`**（Caddy 的自动 HTTP→HTTPS 跳转，浏览器/爬虫会自动跟随）。这是全行业通行做法，核查不受影响。

⚠️ **唯一例外**：若公安备案退回的理由写着「网站无法访问 / 未检测到备案号」，那就说明对方的抓取程序**不跟随跳转**。此时让 80 端口直接吐出 200 正文即可：

```caddyfile
# 在 Caddyfile 顶部全局块加一行（关闭自动跳转，http 与 https 并存）
{
	auto_https disable_redirects
}
```
```bash
sudo systemctl reload caddy
curl -sI http://deep-root.cn/ | head -3     # 期望变成 200，且仍能 grep 到备案号
```

改完记得把这条偏离写回本文档——**它会让站点同时开着明文 HTTP**，属于为过审做的临时让步，不要长期留着。

### 2.2 三个必须记住的红线

🔴 **L3 轻量服务器到期 ⇒ 备案失效。** 备案是绑在接入商（腾讯云）和这台服务器上的。到期不续费，腾讯云会取消接入，备案号随之被注销。续费提醒要提前设。

🔴 **备案信息变了必须 30 日内做变更备案。** 域名增减、主体信息变更、网站服务内容变更都算。不主动变更，被核查出来同样整改。

🔴 **首页文案禁出现「教育 / 培训 / 课程 / 辅导」。** 个人主体办不了前置审批（《互联网信息服务管理办法》第五条把教育列入前置审批范围），文案一旦被认定涉教育，不是慢，是备案会被撤。当前首页刻意写「学习记录 / 学习内容整理」就是这个原因，**以后改首页别破坏这条**。

### 2.3 顺手记下现在的正确状态（便于以后比对）

```
域名：deep-root.cn、www.deep-root.cn
解析：42.192.36.120（腾讯云轻量 L3，Ubuntu 24.04）
接入商：腾讯云
首页：http://deep-root.cn/  （静态说明页，Caddy `:80` → /srv/www）
后端：/api/* → 127.0.0.1:3000
```

## 3. 第三项：公安联网备案（30 日内，本轮重点）

### 3.1 前置检查（不满足会白跑）

| 检查项 | 判据 | 本项目 |
|---|---|---|
| 网站能公网访问 | 手机 4G 流量（**不用 Wi-Fi**）打开 `http://deep-root.cn/` 能出页面 | ✅ 已验证 200 |
| 数据码未过期 | 腾讯云备案控制台能看到数据码与有效期 | ⚠️ 30 日倒计时，从拿到码那天算 |
| 身份证在手 | 人像面 / 国徽面 / 手持照，白底、清晰、不反光 | ⬜ 你准备 |
| 域名证书 | 域名注册商后台可下载（腾讯云/阿里云「域名证书下载」） | ⬜ 你准备 |

> ⚠️ 审核期间网站必须保持可访问——审核员会实际打开看。别在这期间停服/换 IP。

### 3.2 操作步骤（照着点）

**第 1 步：登录公安部平台**

打开 <https://beian.mps.gov.cn> → 点「用户登录」→ 会跳到公安部「互联网+政务服务」平台做登录/实名。首次用需要注册并完成实名认证。

**第 2 步：绑数据码（省掉 30 多项手填）**

登录后在平台首页**右上角**找「数据码」按钮 → 弹窗里填：

- 数据码：`e5b07584a39ba9352da47fc8f6bb48ae`
- 负责人手机号：你备案时填的那个号
- 负责人证件号：身份证号

系统检测到与腾讯云同步的数据匹配后，会提示「可使用数据码绑定数据」→ 确认。绑定后选择「创建主体 + 创建网站」，生成草稿。

**第 3 步：补齐 7 项缺失信息（其余已自动填好）**

草稿里需要手动补的主要是：

| 字段 | 怎么填 | 注意 |
|---|---|---|
| 负责人常住详细地址 | 身份证住址所在的街道门牌 | 精确到门牌号，别只填省市 |
| 域名证书 | 上传注册商下载的 PDF/图片 | 域名必须是 `deep-root.cn` |
| 身份证人像面 / 国徽面 / 手持 | 上传 | 单个文件 ≤5MB，png/jpeg/jpg |
| 网站安全负责人 | 个人主体通常同本人 | 勾「同主体负责人信息」 |
| 网站应急联络人 | 建议填一个**能 7×24 联系到**的号码 | 个人主体一般只能填本人；若有家人可代接，填家人更好 |
| 网站服务内容 | 选「其他」（有「互联网信息服务」也选这个） | ⛔ 别选教育/培训类 |
| 网站开通时间 | 填首页实际上线的日期 | 与 ICP 备案的经营性/非经营性口径一致 |

**第 4 步：提交，等属地公安审核**

提交后由**属地公安机关网安部门**审核（按主体所在地分配，本项目应为陕西）。官方时限 20 个工作日，实际常见几天到两三周。

平台「我的 → 我的申请」可看进度；状态为「审核不通过」时**会写原因**，按原因改完重新提交即可（不是一票否决）。

**第 5 步：拿到备案号后，悬挂到首页**

审核通过后：平台「我的 → 我的网站」→ 选中该网站 →「详情」→「下一步」→ 网站基本信息页 → 这里有两个按钮：

- **点击下载备案编号图标**（警徽，16×16 PNG）
- **点击复制备案编号 HTML 代码**

把图标存成 `/srv/www/gongan.png`，HTML 代码粘到首页 footer。`server/www/index.html` 里**已经写好了注释模板**，把注释解开、把 `61011302000XXX` 换成真实号码即可：

```html
<p>
  <a href="https://beian.mps.gov.cn/#/query/webSearch?code=61011302000XXX" target="_blank" rel="noopener noreferrer">
    <img src="/gongan.png" alt="" width="16" height="16" style="vertical-align:-3px;margin-right:4px">
    陕公网安备61011302000XXX号
  </a>
</p>
```

⚠️ 要求是「**网站所有页面底部显著位置**」，不能隐藏（不能 `display:none`、不能白字白底）。本项目只有首页一个页面，挂在 footer 即可。

### 3.3 驳回的六个常见原因（按本项目定制）

| 原因 | 本项目风险点 | 预防 |
|---|---|---|
| 网站打不开 | 审核期间关了 80 端口 / 换了 IP | 提交后别动服务器 |
| 网站名称与 ICP 备案不一致 | 首页 title「学习记录」，备案可能填了别的 | 提交前先核对备案记录里的「网站名称」 |
| 服务内容与网站实际不符 | 首页写「学习内容整理」，选项却选了教育类 | 选「其他」 |
| 域名证书缺失或域名对不上 | 只传了 `www` 或传了别的域名 | 证书上的域名要能覆盖 `deep-root.cn` |
| 证件照不合格 | 反光、边角被裁、手持照看不到人脸+证件 | 重拍，四角完整 |
| 应急联络人电话打不通 | 填了不常用的号 | 填能接的号，审核期保持畅通 |

## 5. 备案之后紧接着要做的两件事（不在本次备案范围，但会卡上线）

### 5.1 给 `deep-root.cn` 配 HTTPS

现状：Caddy 只有 `:80` 站点块，**443 未监听**，`https://deep-root.cn` 连不上（实测 `000`）。

为什么必须做：

- 微信小程序的「服务器域名」白名单**只收 https 域名**，`http://` 与 IP 都填不进去 ⇒ 正式版无法上线
- 备案核查走 http 没问题，但审核员/用户手动输 https 会打不开，观感差且可能被判「服务不可用」

做法（Caddy 自动签发，域名已备案 + 已解析，可直接申请）：

```caddyfile
deep-root.cn, www.deep-root.cn {
    encode gzip
    handle /api/* { reverse_proxy 127.0.0.1:3000 }
    handle { root * /srv/www
             file_server }
    header { X-Content-Type-Options nosniff
             X-Frame-Options SAMEORIGIN
             Referrer-Policy strict-origin-when-cross-origin }
}
```

同时要改小程序编译期常量：`.env.local` 的 `PROJECT_DOMAIN` 由 `http://42.192.36.120` 改为 `https://deep-root.cn`，**然后必须重新 `build:weapp`**（`PROJECT_DOMAIN` 是编译期常量，改配置不重建不生效）。

### 5.2 备案号与政策文本对齐

若本次网站备案号后缀与小程序备案号不同，`src/constants/privacy-policy.ts` 与 `docs/legal/隐私政策.md` 第十节的「已完成小程序 ICP 备案，备案号：…」需同步（两处副本必须逐字一致）。
