**四闸实现要点**

- **F0**：`sha256(extract_docx 流 → stripNul → slice(0,200000))` 与 `doc_convert_done.text_sha256` 比对，不符**整份跳过**（不用 docx 二进制哈希，D-024 已证 12/12 全不同）。
- **F1**：`norm(clean)` 是 `norm(text_content)` 的严格前缀、首差异 `== len(norm(clean))`、`b_len>0 && max_offset>0`、图对象数与 `doc_convert_done` 记账对账、stem 不越正文边界；无图标记单独记 `no_marks`（正常结果，非闸门失败）。
- **F2**：`q_exp = len(norm(text_content[:char_start]))`，枚举 `ns` 全部匹配取**唯一最近**；无唯一最近 / `dist>0` / `exp_ok=false` ⇒ 丢图。`offset_in_stem` 复用生产真相源。
- **F3**：`kind='formula'` 标记全部跳过，不产出、不入库、不下发。
