### 5.3 32 条确定性抽查（固定步长，覆盖不同文档）

多数 `insert_before` / `insert_after` 与题干语义相符（如「属于有机合成材料的是（ ）」↔「A．」），但发现三类风险：

1. **shape 尺寸残串混入正文**：`-37147512763528`、`30861007861303.`、`961390635`、`2203450206375`、`1778085725` 等出现在 `insert_after` 里 ⇒ 文字流不是干净题干。
2. **超长 stem（切题粒度粗）**：`char_offset=693 / stem_len=3347`（第四节 祖国的神圣领土——台湾省.doc）、`10986 / 12024`（历史下册复习提纲）⇒ 一「题」实为整段教案 / 整章提纲，图落在整章而非具体题目。
3. **疑似跨题边界**：`char_offset=3 / stem_len=24`，`after="\n \n四、解答题（共3小题，满分"` ⇒ 插在题号「36．」后却紧接下一大题标题。

⇒ 阶段 3 的「越界 0 / 串题 0」是**坐标系与期望位置口径下的结论**，不等于「图插在孩子能看懂的位置」。本轮补上的语义核对**不支持放行**。
