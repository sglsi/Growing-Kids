## 6. D 二元结论与代价清单（按 Q3①：只出结论，修复另立提案）

**D 判定：本轮证据不足以支持「需要重建坐标系」，且不支持任何放行。**

依据（三条，均为本样本内事实）：
1. `m:oMath`/`m:oMathPara` **0 个** ⇒ 不存在 OMML 公式需要新的坐标映射层；
2. 362 个 `w:object` **100% 为 OLE+VML 图片、零内部文字** ⇒ 没有「可从对象回收的文字」需要并入文字流；
3. T3 的长度差**口径不一致**（§4），不能作为「坐标系错位」的证据。

⇒ **不启动坐标系重建、不改 `parse_docx()`、不清洗原文、不重映射 `char_offset`、不动 `text_content`/`text_sha256`**。若将来真要复核文字流，须**另立提案**并用真相源 `extract_docx()` 同口径重做。

**代价清单（若将来仍要走「文字流 + 对象枚举」路线）**：① 需为 `w:object`(362) / `w:pict`(536) / `v:shape`(1,735) / `w:txbxContent`(1,094) 四类形态分别定义语义与坐标；② 需解释 `w:fldChar`/`w:instrText`(18 份) 域代码；③ 需处理 `w:sym`(3 份) 的 Symbol 别名；④ 需重做 T3 同口径对比；⑤ 上述成本**不改善** D-035 已登记的「只解决显对、不改善给对」。⇒ 与 D-041 已定的 `.doc` 整题快照路线相比，性价比更低，**本轮不建议重启该路线**。

🔴 **与 Q5 的关系（一个字没松）**：`Q5 --apply` 六项解除条件（T1–T4 出数且 D 判定明确／40 条复核签核／`offset_zero` 语义闸＋≥30 条复核／M42 升 v4／写前备份＋一键下线演练／另建放行 D 号）**仍未全绿**；40 条复核 18 不通过、M42 仍 v3 ⇒ `.doc` 内联图保持 **0 行**。本报告只满足其中「T1–T4 出数」一项，且 D 判定为「证据不足」，**不构成放行提请**。
