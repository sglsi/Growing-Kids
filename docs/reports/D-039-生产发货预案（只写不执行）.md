## 1. 核心判断：**现在不建议单独发货**

`curriculum_topics` 目前是**孤立维度表 + 零引用模块**：没有读端点、没有服务调用、没有前端消费。单独把它推到生产库，面客收益为 0，却要承担一次完整发货风险（备份 → 迁移 → 可能换 dist → 重启 → 复比）。
