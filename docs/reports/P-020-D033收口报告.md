## 2. A：独立 `.doc` 产图链路（F4 的落地形态）

### 2.1 为什么是「独立」而不是改候选 SQL

`netdisk-inline-build.mjs` 的 `pendingSources()` 写死 `nf.ext='docx'`，它下载 docx 原件、直接调 `crop.py`、写完即删。把 `.doc` 塞进去会让 F0 同源、F2 消歧、F5 语义闸与已收口的 docx 链路（7,286 份 / 273,037 张图）混在一条真相源上，**零回归无法证明**。本轮另起一条：

```
下载 .doc → 独立 LO profile 重转 docx → F0 同源 → F1 严格前缀 →
F2 char_start 唯一最近 → F3 OLE 全跳过 → F5 / F5b 语义闸 →
doc-inline-figure-crop.py 按 mark_offset 反查 w:drawing 内嵌图 →
WebP 落【本地暂存目录】→ 生成「待写清单」JSON（不写库、不写生产 storage）
```

| 文件 | 作用 |
|---|---|
| `server/scripts/doc-inline-figure-build.mjs` | Node 驱动：只读 SELECT、下载、独立 profile + `nice19` / `ionice -c3`、`MemAvailable` 门槛、单份超时、用完即删；`applyWrites()` 写库末端完整实现但被硬锁挡住 |
| `server/scripts/doc-inline-figure-crop.py` | Python 侧：`importlib` 只读加载 `doc-inline-shadow.py::run_shadow` 与 `netdisk-inline-crop.py::parse_docx / grab_figure / save_webp`，**版本守卫**要求影子模块带 `F5B_NOISE` 才准产图 |

🔴 **不改** `netdisk-inline-build.mjs`、**不改** `netdisk-inline-crop.py`、**不改** `ocr-engine/pdf_tool.py`、**不改** `question-match.ts`。

## 3. B：F5b「换行 + 短数字串」专项规则与同 seed 重跑

### 3.1 规则（不简单放宽阈值）

D-032 §4① 的 3 条漏网距插点恰好 **9 字**（> F5 `neighbor=8`），若直接把 neighbor 放宽或把位数从 7 降到 6，会误伤年份 `2017年`、下划线填空、题号。改为只认一个形态：

```python
F5B_NOISE = re.compile(r'[\r\n]+[ \t]*(-?\d{6,})(?!\d)')   # 换行 + ≥6 位纯数字
F5B_ALLOW_WORDS = ('导学号', '准考证', '编号', '学号', '考号', 'ISBN', ...)
```

- 在插点前后 32 字窗口扫描；允许词在 48 字上下文里找（覆盖「导学号 58|504170」被插点切断的情形）；
- **判定顺序固定**：F5 既有判据优先，F5b 只补漏 ⇒ D-032 的 `drop_reasons` 基线可前后对照；
- 仍**不清洗原文、不重映射 `char_offset`、不碰 `text_content` / `text_sha256`**；
- `--gate-selftest` **25/25**（本地 + L3 生产 Python 各一次），原 15 条 F5 用例零回归、原四闸合成反例 **10/10** 不回归。
