# 「成长记忆」页面设计方案

> 状态：已确认，待实施
> 作者：UI 改造轮 + 用户确认
> 时间：2024-12

## 1. 背景与定位

| 维度 | 现有 | 记忆（新增） |
| --- | --- | --- |
| 主题 | 学习 / 错题 | 学习 / 生活 / 爱好 / 感触（混合） |
| 数据表 | `timeline_items` | 新增 `memories` + `memory_media` |
| 入口 | TabBar 第 3 段「文档」 | TabBar 第 4 段「记忆」 |
| 媒体类型 | 图片（OCR 入口） | 图片 / 语音 / 视频 / 文本 |
| 学科关联 | 强（subject_id 必填） | 弱（仅 category=study 时可选） |
| 配额 | `user_quota` 已有 | V1 暂不接入，V2 再加 |

定位边界**清晰**：

- memory 与 `timeline_items` **平行**，不混入学习收件箱
- memory 与 `library_docs` **共享 TOS 存储**，但 UI 完全分立
- 不复用 `blob_objects` 去重表——学习错题会去重（相同题目可被多家孩子共享），记忆是个人独有，去重收益低、维护成本高

## 2. 数据库设计

### 2.1 `memories`（记忆主表）

```sql
create table if not exists memories (
  id              varchar(36) primary key default gen_random_uuid(),
  user_id         varchar(36) not null references users(id) on delete cascade,

  -- 内容
  title           varchar(128),                       -- 可选标题
  content         text,                                -- 文本/纯文本/V1 不上富文本

  -- 分类与情境
  category        varchar(16) not null default 'life',-- 'study'|'life'|'hobby'|'feel'|'other'
  mood            varchar(16),                         -- 'happy'|'calm'|'excited'|'thoughtful'|'sad'|'proud'
  subject_id      varchar(36) references subjects(id) on delete set null,
  tags            text[] not null default '{}',

  -- 媒体摘要（列表展示用，无需 join）
  cover_key       text,
  cover_mime      varchar(64),
  media_count     int not null default 0,
  audio_duration  int,

  -- 时间
  occurred_at     timestamp with time zone not null default now(),
  created_at      timestamp with time zone not null default now(),
  updated_at      timestamp with time zone not null default now(),
  deleted_at      timestamp with time zone
);

create index memories_user_occurred_idx  on memories (user_id, occurred_at desc) where deleted_at is null;
create index memories_user_category_idx  on memories (user_id, category) where deleted_at is null;
create index memories_subject_idx        on memories (user_id, subject_id);
create index memories_tags_gin           on memories using gin (tags);
```

### 2.2 `memory_media`（记忆媒体 1:n）

```sql
create table if not exists memory_media (
  id              varchar(36) primary key default gen_random_uuid(),
  memory_id       varchar(36) not null references memories(id) on delete cascade,
  user_id         varchar(36) not null references users(id) on delete cascade,

  file_key        text not null,
  thumb_key       text,
  mime_type       varchar(64) not null,
  width           int,
  height          int,
  size_bytes      bigint,
  duration_sec    int,                                 -- 音/视频时长
  transcript      text, -- ASR 转写预留，V1 暂不写

  kind            varchar(16) not null,                -- 'image'|'audio'|'video'
  sort_order      int not null default 0,
  created_at      timestamp with time zone not null default now()
);

create index memory_media_memory_idx on memory_media (memory_id, sort_order);
```

### 2.3 迁移文件

`migrations/0006_memory.sql`（仅 DDL，无 data migration）。

### 2.4 V1 不改 `user_quota`

记忆（特别是视频）会快速消耗配额，V1 不加 memory 配额；`memory_used_bytes` / `memory_quota_bytes` 在 `0007_memory_quota.sql` 单独扩展。

## 3. 后端 API

| Method | URL | 说明 |
| --- | --- | --- |
| `GET` | `/memories` | 列表（`category` / `subject_id` / `tag` / `keyword` / `since` / `page` / `pageSize`） |
| `GET` | `/memories/:id` | 详情（含 `media` 列表） |
| `POST` | `/memories` | 创建（`content` / `media[]` / 可选`category` / `mood` / `occurredAt`） |
| `PATCH` | `/memories/:id` | 修改（除 media 之外） |
| `DELETE` | `/memories/:id` | 软删 |
| `POST` | `/memories/:id/media` | 追加媒体 |
| `DELETE` | `/memories/:id/media/:mediaId` | 删除媒体 |

**统一响应** `{ code, msg, data }`（沿用现有 envelope 模式）。

**隔离**：所有查询强制 `where user_id = :currentUserId`，不启用 RLS（项目惯例）。

## 4. 前端页面结构

### 4.1 路由

```
TabBar 第 4 段：记忆
└─ pages/memory/index.tsx        主页（时间倒序瀑布流）
   ├─ pages/memory/detail.tsx   详情（只读 + 编辑入口 + 删除）
   └─ pages/memory/edit.tsx     新建/编辑（4 种媒体）
```

TabBar 列表变成：「首页 / 复习本 / 文档 / 记忆」—— 微信小程序 TabBar 最多 5 项，仍有余量。

### 4.2 TabBar 图标

推荐 `BookHeart`（书页+心，与"记忆"语义一致，且不与复习本的 `NotebookPen` 重复）：

```bash
npx taro-lucide-tabbar BookHeart -c "#9A948A" -a "#BE3E2D" -o ./src/assets/tabbar -s 81
```

### 4.3 主页 `pages/memory/index.tsx`

```
┌──────────────────────────────────────┐
│ [搜索]            [批量]   [+ 新增] │  ← FilterHeader 风格
├──────────────────────────────────────┤
│ [全部] [学习] [爱好] [生活] [感触]   │  ← 5 chips（SubjectBadge 风格）
├──────────────────────────────────────┤
│ 2024 年 12 月                          │  ← 月份分组头（吸顶）
│ ┌────────────────────────────────┐ │
│ │ 12-15 周日 14:32  · 😊 心情     │ │  ← 记忆卡
│ │ 🏷 学习 · 数学                   │ │
│ │ 今天做了一道求和的题...           │ │  ← 内容截断 3 行
│ │ [IMG] [IMG] [▶录音 32s]         │ │  ← 媒体预览
│ │ #课堂 #感悟        [⋮]          │ │
│ └────────────────────────────────┘ │
└──────────────────────────────────────┘
```

**关键交互**：

- 顶部「+ 新增」主按钮（朱砂红 `#BE3E2D`，CTA 圆角）
- 分类筛选：5 个 chips（复用 `SubjectBadge`）
- 时间分组：按 `occurred_at` 月份分组，吸顶显示
- 卡片多选态：复用 `CheckDot` + `SelectionBar`
- 空状态：插画 + 「还没有记忆」+ 「记录下第一段成长足迹」
- 加载态：复用 `Skeleton` 灰块

**复用公用组件**：`SubjectBadge`（学科胶囊）、`SegmentedTabs`（分类筛选）、`SelectionBar`（批量）、`CheckDot`（多选态）、`FilterHeader`、`EmptyCard`。

### 4.4 编辑页 `pages/memory/edit.tsx`

```
┌──────────────────────────────────────┐
│ [取消]                [草稿] [保存]  │  ← 顶部头
├──────────────────────────────────────┤
│ 发生时间   [2024-12-15 14:32]  🕒    │
│ 分类       [●学习] [生活] [爱好] [感触] [其他] │
│ 心情       [😊 😌 🤩 🤔 😢 ] 6 选 1 │
│ 学科       [语文/数学/...]（仅学习时显示）│
├──────────────────────────────────────┤
│ 标题（可选）                           │
│ ┌────────────────────────────────┐ │
│ └────────────────────────────────┘ │
│ 内容                                 │
│ ┌────────────────────────────────┐ │
│ │ 今天做了一道求和的题...         │ │  ← Textarea（≥160 高）
│ └────────────────────────────────┘ │
├──────────────────────────────────────┤
│ 媒体（图片 / 音频 / 视频）           │
│ ┌──────┐ ┌──────┐ ┌──────┐         │
│ │ IMG  │ │ IMG  │ │  +   │         │
│ └──────┘ └──────┘ └──────┘         │
│ [🖼 相册] [🎤 录音] [🎬 视频]       │
├──────────────────────────────────────┤
│ 标签    [+ #课堂] [+ #感悟]          │
└──────────────────────────────────────┘
```

**关键交互**：

- 标题可选，V1 不上富文本（不引入 MD 编辑器）
- 内容 `maxlength=2000`，纯文本
- 媒体 3 种入口：
  - **图片**：相册 1-9 张（用 `Taro.chooseMedia` / H5 `<input multiple>`）
  - **录音**：跨端适配（关键，详见 §6）
  - **视频**：仅相册导入（V1 不上拍视频）；限制 60 秒
- 标签：每输入 `#xxx` 自动加入 tag chips
- **自动保存草稿**：每 5 秒把编辑内容写 `localStorage`，下次进入询问是否恢复

### 4.5 详情页 `pages/memory/detail.tsx`

- 顶部右上角铅笔头按钮（编辑入口）
- 内容只读，媒体可全屏预览（图片 `Taro.previewImage`、音视频内嵌播放器）
- 底部「删除」红色文字按钮（`AlertDialog` 二次确认）

## 5. 服务层

新增 `src/services/memory.ts`：

```ts
import { Network } from '@/network'

export type MemoryCategory = 'study' | 'life' | 'hobby' | 'feel' | 'other'
export type MemoryKind     = 'image' | 'audio' | 'video'
export type MemoryMood     = 'happy' | 'calm' | 'excited' | 'thoughtful' | 'sad' | 'proud'

export interface Memory {
  id: string
  title?: string
  content?: string
  category: MemoryCategory
  mood?: MemoryMood
  subjectId?: string
  tags: string[]
  coverKey?: string
  coverMime?: string
  mediaCount: number
  audioDuration?: number
  occurredAt: string
  createdAt: string
  updatedAt: string
}

export interface MemoryMedia {
  id: string
  memoryId: string
  kind: MemoryKind
  fileKey: string
  thumbKey?: string
  mimeType: string
  width?: number
  height?: number
  durationSec?: number
  transcript?: string
  sortOrder: number
}

export const MemoryApi = {
  list:       (p) => Network.request({ url: '/memories', method: 'GET', data: p }),
  detail:     (id) => Network.request({ url: `/memories/${id}`, method: 'GET' }),
  create:     (b) => Network.request({ url: '/memories', method: 'POST', data: b }),
  update:     (id, b) => Network.request({ url: `/memories/${id}`, method: 'PATCH', data: b }),
  remove:     (id) => Network.request({ url: `/memories/${id}`, method: 'DELETE' }),
  addMedia:   (id, b) => Network.request({ url: `/memories/${id}/media`, method: 'POST', data: b }),
  removeMedia:(id, mid) => Network.request({ url: `/memories/${id}/media/${mid}`, method: 'DELETE' })
}
```

**媒体上传复用**：`Network.uploadFile` + 现有 storage 直传通道（与 library 一致），**不走 OCR、不走 image-actions**。

## 6. 跨端关键点（基于现有规范）

| 功能 | 小程序 | H5 |
| --- | --- | --- |
| 录音 | `Taro.getRecorderManager()`（useEffect 内初始化） | 降级提示「请在小程序中录音」 |
| 录音保存 | 压缩为 mp3/aac，限制 60 秒 | — |
| 视频选择 | `Taro.chooseMedia({ mediaType: ['video'] })` | `<input type="file" accept="video/*">` |
| 时间选择 | `<picker mode="date-time">` | `<input type="datetime-local">` |
| 图片预览 | `Taro.previewImage` | 同左 |
| 音频播放 | `Taro.createInnerAudioContext()` | `<audio controls>` |
| 视频播放 | `<Video>` 组件 | `<video controls>` |

**录音的三个必守规则**：

1. `useEffect` 内初始化 RecorderManager，不得在组件顶层直接调用
2. `Taro.getEnv()` 检测 `[WEAPP, TT]` 双平台支持
3. H5 端降级（不直接调用录音 API）
