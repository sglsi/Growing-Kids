## 0. 本文怎么读

### 0.1 三种身份三种读法

| 你是谁 | 读哪几节 | 用途 |
|---|---|---|
| 产品决策者 | §2（判据）、§5（决策器）、§6（准则）、§7.4（张力裁决） | 判断一个功能「该不该做」，以及为什么不该做 |
| 设计 / 研发 | §3（框架）、§6（准则全文）、附录 A（三向索引） | 写功能时能指回一条机制；写代码注释时知道引哪个准则号 |
| 评审 / 复核者 | §4（证据纪律）、§8（可错性）、20b 原文 | 反驳某条结论时，知道该去查哪一条文献 |

### 0.2 本文的写作纪律（三条，比内容更重要）

1. **可追溯**：凡结论必须指到 20b 的具体条目。查不到出处的段落，不得作为设计依据（元准则 E1）。
2. **可证伪**：每条准则都要写清「如果这条错了，我们会观察到什么」（§5.4、§6.2 的 falsifier 栏）。写不出证伪条件的准则不是准则，是信仰。
3. **可执行**：每个结论都要能落到「禁止做 / 必须做 / 怎么做」三选一，而不是停留在感慨。

### 0.3 本文不做什么

- ❌ 不复述 20b 的表格与文献细节——那是证据卷的职责，本文只引用条目号。
- ❌ 不给孩子的学习建议，也不是家长操作手册（那是 SRS-03）。
- ❌ 不追求理论完备：范围限定在**K12 书面作业与错题场景**，其他场景明确划界（§8.3）。

## 1. 引言：为什么需要「形而上」的一层

### 1.1 三层文档结构

本套文档此前只有两层，本文补上缺失的第三层：

| 层 | 回答 | 典型文档 | 失效时的症状 |
|---|---|---|---|
| **价值层** | 我们为谁解决什么问题 | SRS-01 | 产品做得挺顺，但说不清为什么值得存在 |
| **方法层**（本文） | 凭什么说这样做能解决问题 | **SRS-20a / 20b** | 每个功能都能讲出理由，但理由之间互相打架 |
| **工程层** | 具体怎么实现、怎么验证 | ADD / DD / QA 系列 | 代码质量高，方向错了 |

### 1.2 缺方法层的三个后果（都真实发生过）

| 后果 | 本项目里的具体形态 |
|---|---|
| **立论靠情怀** | 「举一反三」写了半年，但没人能说清它对应哪个认知过程；直到做 20b 时才确认它 = 自我解释（0.54）+ 交错（0.47）+ 迁移，且**收益集中在概念理解而非程序流畅** |
| **设计靠竞品** | 竞品普遍做「打卡日历 / 连续天数 / 励志推送」，看起来是行业共识；证据却是效应量 d ≈ 0.05 与挤出效应，照抄等于付费买噪声 |
| **返工靠感觉** | C1（`mastered` 是布尔量）被当成"小瑕疵"拖了很久，实际它挡的是 ERE 的 0.505/−0.428 梯度——**这不是缺字段，是缺机制** |

**结论**：方法层不是装饰。它的产出物是**否决权**——没有它，团队只能不断做加法。

### 1.3 本文回答的四个问题

1. **学会是什么？**（可判定的判据，§2.1）
2. **学习靠什么发生？**（三条不变量与三个约束，§2.2–2.4）
3. **这些知识怎么组织成一个体系？**（四层框架 GK-LSM，§3）
4. **以后遇到新证据，怎么判断该不该采纳、该落到哪一层？**（研究方法，§4–§5）

第 4 问是本文与前身（20b）最本质的区别：**20b 给的是素材与结论，本文给的是产生结论的机器。**

## 2. 第一原理：学习的定义、不变量与约束

### 2.1 什么叫「学会了」：三条判据

> **定义（本文采用）**：学习已经发生 = 在**延迟至少一天**之后、**不提供原题刺激与答案**的条件下，于**相似但不相同**的任务上，表现出稳定、可重复的提升。

拆成三条可判定的判据：

| 判据 | 要求 | 违反它就退化成 | 证据 |
|---|---|---|---|
| **L1 延迟** | ≥ 1 天（跨睡眠周期更佳） | 工作记忆里的暂时激活，即"当堂会" | Roediger & Karpicke 2006：5 分钟后重读组更好，**一周后自测组 61% vs 重读组 40%**（20b §3.2） |
| **L2 无提示** | 不给答案、不给原题、不给解题步骤 | 再认（认出答案）而非回忆（想出答案） | 回忆式优于再认式（Adesope 2017，g ≈ 0.51，20b §3.2） |
| **L3 迁移** | 换数字、换情境、换问法仍成立 | 记住了这一道，而非这一类 | PF 的收益**只在概念理解与迁移**上出现，程序性流畅度与常规教学持平（Sinha & Kapur 2021，20b §3.3） |

这三条判据的用途不是"评价孩子"，而是**评价产品**：任何一个功能，如果不能提高 L1+L2+L3 下的表现，它就只是在提高"当堂正确率"——那是最容易被伪造的指标（Kornell & Bjork 2008：**78% 的人在学习后认为块状练习更有效，即使刚看过自己的成绩**，20b §3.2）。

> ✅ **推论 D1（贯穿全项目）**：**能当场测出来的提升，都不是学习**；能证明学习的测量，一定带来"产品看起来没那么有效"的代价。
> 这不是设计缺陷，是**判据本身的性质**。想同时讨好两者，只能靠 UI 的诚实（M3）。

### 2.2 三条不变量

从素材中可提炼出三条**在所有证据里反复出现、且不依赖任何特定理论流派**的机制。称其为"不变量"，因为它们跨年龄、跨学科、跨材料反复成立：

| 不变量 | 一句话 | 为什么它是不变量而非技巧 | 效应量级 |
|---|---|---|---|
| **I1 提取（Retrieval）** | 记忆的可及性由**成功提取的次数**决定，不由**重复输入的次数**决定 | 从 1913 年的测验效应到 2021 年 222 项课堂研究，方向从未反转过 | d ≈ 0.50–0.74；低风险测验约 **0.5 SD**（20b §3.2、§4.1） |
| **I2 修正（Correction）** | 错误表征不会随时间自愈，必须由**含推理分析的反馈**显式改写 | 只犯错不纠正**可能强化错误**；反馈粒度直接决定效果梯度（0.05→0.32→0.49） | 精细反馈 0.49 vs 仅对错 0.05（20b §3.4） |
| **I3 间隔（Spacing）** | 同样的提取总量，**分散在时间上**优于集中 | 271 组可比实验中 **259 组**分散更优；且最优间隔在 70–350 天区间几乎不变 | d ≈ 0.85（20b §4.1、§4.3） |

**为什么只有这三条**，而不是市面上常说的"五种高效学习法"？

入选标准有三条，缺一不可：

1. **跨情境可复现**：至少有一个元分析级别的证据，且方向一致；
2. **有明确边界**：知道它在什么条件下反向（否则无法指导设计）；
3. **不需要假设不可观测量**：只依赖可操作化的变量（次数、延迟、反馈内容）。

用这三条筛，很多流行概念会被筛掉：

| 概念 | 未入选原因 |
|---|---|
| 三种认知负荷（intrinsic/extraneous/germane） | 不满足第 3 条：**germane 已被 CLT 内部降格**，Sweller 明说 intrinsic + extraneous 已足够解释数据，两次测量未能复现第三因子（20b §3.5）。**保留的是它的操作结论**（减少无关负荷），不是它的分类学 |
| 最近发展区（ZPD） | 不满足第 3 条：无公认测量工具，动态评估预测效度仅 r ≈ .12–.24（20b §3.6）。**保留的是它的启发式替身**（掌握学习，+0.52 SD） |
| 成长型思维 | 不满足第 2 条的一半：效应 d ≤ 0.05–0.14，且**信念改变而成绩不动**（20b §2.3）。它连"边界内的正效应"都难指认 |
| 学习风格（视觉型/听觉型） | 不满足第 1 条：无稳定复现，本项目不予采纳（未入库） |

> ✅ **推论 D2**：**框架的价值一半来自它收进了什么，一半来自它挡掉了什么。** 一个什么都收的框架等于没有框架。

### 2.3 三个约束

不变量决定**方向**，约束决定**剂量**。三条不变量若无约束，会推出"越多越难越好"的荒谬结论。

| 约束 | 内容 | 它限制了什么 | 证据锚点 |
|---|---|---|---|
| **C-资源** | 工作记忆容量有限；外在负荷会挤占用于理解核心复杂性的资源 | 限制 I1/I2 的**单次密度** | ERE：低先备者受益于高辅助 **d = 0.505**，高先备者从低辅助获益 **d = −0.428**（20b §3.5） |
| **C-动机** | 自主 / 胜任 / 关联三需求；外部奖励显著时产生挤出 | 限制 I3 的**可承受总量** | Slemp 2024（N = 443,556）：三需求各自解释独立变异；Cerasoli 2016：激励显著时关联 ρ 从 .45 降到 .22（20b §2.2） |
| **C-元认知** | 人对"自己会不会"的判断系统性偏差 | 决定 I1/I3 的收益**用户感知不到**，必须靠外部结构兜住 | 78% 判断错误；Sitzmann & Yeo 2013：控制时间趋势后效能→表现 ρ = .06 不显著（20b §3.2、§3.7） |

**三约束的方向性（关键，且与直觉相反）**：

- 资源约束的方向是 **"新手多给帮助"**（0.505 > |−0.428|）⇒ 教学上「宁可多给」，与"越早放手越好"的流行说法相反；
- 动机约束的方向是 **"喂养胜任 ≠ 给鼓励"**（掌握性经验最强，言语说服最弱）⇒ 夸不解决问题，做成才行；
- 元认知约束的方向是 **"不要相信用户的自我报告"** ⇒ 满意度、觉得有用、感觉学会了，都不是效果证据。

### 2.4 不变量 × 约束 = 设计空间

把两条轴放在一起，可以解释**为什么市场产品的重心与证据的重心几乎错位**：

| | **感知强**（用户当下就觉得有用） | **感知弱**（当下无感，甚至更挫败） |
|---|---|---|
| **效应大** | 精细反馈（0.49）、难题的延迟反馈（1.17） | **提取练习（0.74）、分散练习（0.85）、交错（数学 0.34）** ← 本项目的主战场 |
| **效应小/零** | 重读（0.47 但评级低）、划重点、励志与打卡、连续天数 | 术语化解释、理论灌输 |

四象限的读法：

- **右上（感知弱 + 效应大）是本项目存在的全部理由。** 家长与孩子都不会自发做这件事——这正是"工具"能提供的价值。
- **左上（感知强 + 效应大）是最容易被采纳的部分**，也是最不需要方法论的。
- **左下（感知强 + 效应小）是市场的主流，也是最危险的区域**：它卖的是体验，不是学习。一旦产品指标被这类功能主导，就会陷入"用户很满意、成绩没变化"的境地。
- **右下（感知弱 + 效应小）不必做。**

> ✅ **推论 D3**：**产品的位置在右上象限，代价是必须用"诚实"换"信任"。**
> 这直接推出 M3（不得以当次正确率为指标）与 §5.5 的度量纪律：如果把右上象限的功能按左下的方式展示（比如把"复习了 20 次"当成成果），收益会被元认知错觉抹平。

### 2.5 立场声明：本文的理论谱系

本文**不选边任何单一学派**，但选机制。理由与边界如下：

| 流派 | 采纳的部分 | 不采纳的部分 |
|---|---|---|
| 行为主义 | 频率、反馈、强化对行为的塑形 | 把学习等同于行为变化（无法解释迁移） |
| 认知负荷理论 | 外在负荷挤占资源；ERE | 三分类学（germane 已降格） |
| 建构主义 / 生产性失败 | 先备知识激活、概念重构需要挣扎 | 无差别"先让学生失败"（2–5 年级反向，且程序性无收益） |
| 自我决定理论 | 三需求作为动机约束 | 把动机当作学习结果的直接原因（它主要影响投入量，不改变记忆机制） |
| 信息加工 / 记忆研究 | 提取强度 vs 存储强度；间隔效应 | 单一"记忆模型"的解释垄断 |

一句话立场：**只承认那些不依赖流派、能跨情境复现、能被设计操作化的机制；其余一律降级为启发式或直接剔除。**

## 3. 统一框架：GK-LSM 四层模型

### 3.1 结构

**GK-LSM（Growing-Kids Learning System Model）** 把素材组织为四层。上层只给边界，下层只给实现：

```text
L0 目的层 · Why（教育为了什么）
   ├ 三框架：UNESCO 四支柱 / OECD 学习罗盘 2030 / 中国学生发展核心素养
   ├ 动机层：SDT 三需求（自主 / 胜任 / 关联）
   └ 产出：取舍标准（价值冲突时谁让位）
        │
        │  R1 向下约束：只给边界，不给手法
        ▼
L1 机制层 · How（学习靠什么发生）
   ├ 三不变量：I1 提取 / I2 修正 / I3 间隔
   ├ 三约束：C-资源 / C-动机 / C-元认知
   └ 产出：不变量 + 边界条件 + 学习判据 L1 / L2 / L3
        │
        ▼
L2 策略层 · What（按什么顺序、什么剂量做）
   ├ 十种技巧的证据评级（Dunlosky 三档 + Donoghue & Hattie 的 d）
   ├ 错题处理八步流程 / 间隔「时间山脊」表
   └ 产出：可执行顺序（谁先谁后、隔多久、混不混）
        │
        ▼
L3 设计层 · Build（系统里哪一条必须成立）
   ├ 准则宪法 M1–M10 + 元准则 E1–E5
   ├ 缺口语义 C1–C8 / 度量体系 / 可执行断言
   └ 产出：条款、falsifier、验收判据

R2 向上归因（反向）：每个功能都必须能指回一条 L1 不变量；
指不回去的功能即为装饰品（decoration），不得进入主线。
```

### 3.2 每层的产出物与常见错误

| 层 | 必须产出 | 该层不该出现的 | 常见错误 |
|---|---|---|---|
| L0 | 取舍标准（价值冲突时谁让位） | 具体功能、具体技术 | 把"培养核心素养"直接写成"做一个素养打卡表" |
| L1 | 不变量 + 边界 + 判据 | 产品语言（"让孩子爱上学习"） | 把机制说成需求，导致无法验证 |
| L2 | 可执行顺序与剂量 | 对外承诺、指标定义 | 把"分散练习"理解成"多复习几遍" |
| L3 | 条款 + falsifier + 验收 | 新的理论主张 | 在代码注释里发明依据 |

### 3.3 四条传递规则

| 规则 | 内容 | 违反的后果 |
|---|---|---|
| **R1 向下约束** | 上层只规定边界与不可违背的约束，不规定实现手法 | 上层越界 → 设计僵化，创新被扼杀 |
| **R2 向上归因** | 每个功能必须能指回至少一条 L1 不变量或约束 | 指不回去 → 功能变成装饰，占用注意力预算 |
| **R3 同层不冲突** | 同层条目之间若冲突，走 §7.4 的张力裁决规则，不允许两说并存 | 两说并存 → 谁都能找到依据，方法论失效 |
| **R4 跨层禁跳跃** | 禁止从 L0 直接跳到 L3（"育人目标 → 加一个打卡日历"） | 跳跃谬误 → 理由与手段之间没有因果链，无法证伪 |

R2 是最实用的一条：**给任何新功能提案的第一个问题不是"有没有竞品在做"，而是"它推进哪条不变量"**。答不出就退回。

### 3.4 安置检验：一条新素材该放进哪一层

拿到一条新证据（比如"某研究发现睡前复习更有效"）时，用四个问句定位：

| 问句 | 若答"是" | 归属 |
|---|---|---|
| 它说的是"为什么值得学"？ | 目的与价值判断 | L0 |
| 它说的是"人怎么记住 / 怎么改变表征"？ | 机制 | L1 |
| 它说的是"应该按什么顺序、什么剂量做"？ | 策略与流程 | L2 |
| 它说的是"系统里哪一条必须成立"？ | 条款与验收 | L3 |

四个都答"否" ⇒ 不入库（很可能只是话术）。

⚠️ **如果一个主张同时落在两层**（例如"间隔复习"既是机制也是策略）：**机制进 L1，具体间隔表进 L2**，不得合并。合并会让"改表格"和"改理论"变成同一件事，从而失去变更审计。

### 3.5 框架的解释力检验

一个框架好不好，看它能否**解释素材里的反常**，而不只是把素材装进去。用五个反常反推：

| 反常现象 | 框架给出的解释 | 对应推论 |
|---|---|---|
| 当堂表现与长期保持**反向** | I1 的"提取强度"受重复输入影响，而"存储强度"只由费力提取增厚；两者不同步 | D1（当场可测的提升都不是学习） |
| **78% 的人判断错**哪种练习更有效 | C-元认知 约束：自我判断基于当下流畅度，而流畅度与存储强度负相关 | M3（指标与展示必须诚实） |
| 生产性失败在**小学 2–5 年级反向** | C-资源 约束：无先备知识时"有意义地失败"不成立，退化为非合意困难 | M4（零基础不丢去试错） |
| ERE **非对称**（给新手帮助的收益 > 撤走专家帮助的损失） | C-资源 约束的方向性：资源的边际收益递减，但为负时损失更陡 | M6（宁可多给） |
| 成长型思维**信念变了成绩不动** | 它作用在 L0/动机侧的自我叙述，**未触及 I1 与 I2**；框架预测：不改变提取与修正的干预不改变可测结果 | M2（不做独立模块） |

最后一条是框架最有价值的输出：它把"这个功能效应量小"升级为"**这个功能在因果链上不占位置**"。前者可以被"再优化一下"糊弄过去，后者不能。

### 3.6 框架的失效条件

GK-LSM 明确不适用于：非书面作业场景、成人自我调节学习、口语与艺术技能（§8.3）。它是一张**限定域内的地图**，不是普适学习理论。

## 4. 研究方法（一）：证据的采集与定级

这一节回答：**见到一个说法，怎么判断它够不够格进入我们的决策？**

### 4.1 证据四级

| 级别 | 判据 | 本项目如何用 | 20b 中的例子 |
|---|---|---|---|
| **A** | 多研究元分析或大样本 RCT（k ≥ 50 或 N ≥ 10,000），含发表偏倚检验 | 可作为**主力依据**，可支撑"做"的决策 | Cepeda 2006（839 效应）、Adesope 2017（272 效应 / 15,427 人）、Slemp 2024（N = 443,556）、Macnamara 2023（N = 97,672）、Yang 2021（48,478 人）、Donoghue & Hattie 2021（169,179 人） |
| **B** | 单篇高功效 RCT / 元分析但 k 较小 / 有独立重复 | 可作为**主要依据**，须同时抄下边界条件 | Roediger & Karpicke 2006、Rohrer 2020（54 班 / 787 人）、Tetzlaff 2025（176 效应）、Van der Kleij 2015（70 效应）、Sinha & Kapur 2021 |
| **C** | 小样本实验、单课堂实施、无重复 | **只能用于"不做的理由"或"待观察"**，不得用于"要做的理由" | Chowrira 2019（574 人，期中 +4.78pp，**期末优势消失**） |
| **D** | 叙事性综述的专家判断、理论概念、机制假说 | 只作**启发式**，或作为 A/B 级结论的背景解释 | Dunlosky 2013 的三档评级（叙事综述，非元分析）、ZPD 概念本身、CLT 三分类学 |

⚠️ **门槛规则**：**"要做"的决策需要 ≥ B 级证据；C/D 级只能用于否决或暂缓。** 这条规则不对称，是故意的——做错的代价高于少做的代价（元准则 E4）。

⚠️ **冲突规则**：当 A/B 级证据方向相反时，**取更保守的一侧**。例：反馈时机上"应用场景倾向立即、实验场景倾向延迟"（16:11，20b §3.4），故不建立"一律延迟"的规则，改为按任务类型分派（M5）。

### 4.2 效应量口径守则（六条）

这是最容易出错、也最容易被人利用的地方。

| # | 守则 | 违反的实例 |
|---|---|---|
| 1 | `d` 与 `g` 大致可比；`ρ` `r` 是相关系数，**不可与 d 互换** | 把 ρ = .496 说成"d = 0.5 的效应"⇒ 夸大约一倍以上 |
| 2 | 引用点估计必须同时给 **95% CI** | 只写"d = 0.14"，隐去 [.06, .22] |
| 3 | 必须同时报 **k 与 I²** | Latimier 2021 的 g = 0.034 之所以可信，正因为 **I² = 0%**、CI [−0.10, 0.17]：这是一个"精确的零"，而非"测不出来" |
| 4 | 优先使用**发表偏倚校正后**的值 | Macnamara & Burgoyne 2023：原始 0.05，校正后 0.01–0.03 且不显著 |
| 5 | **建模估计 ≠ 实测** | PF 的 g = 0.87 是偏倚校正后的建模估计，不能与实测 0.36 混用 |
| 6 | **显著 ≠ 有用** | d = 0.05 在大样本下可以显著；"显著"不能作为"值得做"的依据 |

### 4.3 边界优先原则

> **原则**：平均效应是"对谁平均"的产物；**设计依据必须是条件效应**。

每条入库结论都要回答四个边界问题：

| 边界 | 为什么必须写 | 20b 中的典型 |
|---|---|---|
| **年龄 / 学段** | 同一干预在不同学段可反向 | PF 在小学 2–5 年级反向；ERE 在中小学生较弱 |
| **先备知识** | 同一辅助对新手与熟手符号相反 | ERE：0.505 vs −0.428 |
| **材料 / 学科** | 同一策略可正可负 | 交错：数学 0.34、绘画 0.67、说明文不显著、**单词背诵 −0.39** |
| **实施保真度** | 效果随执行质量大幅波动 | PF：总体 0.36 → 按设计原则实施 0.37–0.58 → 常规课堂实施期末优势消失 |

⚠️ 没有边界条件的结论**不得入库**（20b 的六条入库门槛之一）。这条规则的副产品是：它天然挡住了「某专家说」「研究表明」这类无法核对适用范围的说辞——**凡是作者不肯写"什么情况下不成立"的，通常也不打算被检验。**

### 4.4 六种必查谬误

| 谬误 | 形态 | 本项目实例 |
|---|---|---|
| **排行榜化** | 把分级当排名 | Dunlosky 2013 是**三档、档内无序**，被流传成"第一练习测验、第二分散练习"（20b §4.1） |
| **百分比换算** | 把 d 线性折成"提升 X%" | PF 的"提升 20%""效果是优秀教师一年两三倍"是间接换算，不是 g 值 |
| **相关当因果** | 用横断相关推因果 | 自我效能与 GPA ρ = .59，但个体内控制时间趋势后效能→表现 ρ = .06 n.s.（20b §3.7） |
| **自评当效果** | 用满意度/感觉替代测量 | 78% 的人学完后判断错；"觉得有用"与"确实记住"是两个变量 |
| **单研究当共识** | 一篇反例就推翻，或一篇正例就推广 | 成长型思维：Burnette 0.14 与 Macnamara 0.05 并存，正确读法是"总体很小、亚群可能有" |
| **概念冒充测量** | 用一个未操作化的概念当指标 | ZPD："处在最近发展区内"是好的设计启发式，但没有公认测量工具（r ≈ .12–.24） |

### 4.5 入库六条门槛（20b 的准入规则）

一条素材要进 20b，必须同时满足：

1. **出处可核实**：原始期刊/机构报告，不引二手博客与营销稿；
2. **有量化结果或明确方向**：只有"研究表明"没有数字的，不入库；
3. **写明边界条件**：见 §4.3；
4. **与既有条目去重合并**：重复的合并为"多研究一致"，并累加 k；
5. **标注证据级别**（A/B/C/D）；
6. **标注与本项目的关系**：支持 / 反对 / 无关（"无关"也要记，避免重复调研）。

### 4.6 条目登记格式

为保持 20b 可核查，所有新条目按同一格式登记：

| 字段 | 说明 | 示例 |
|---|---|---|
| 条目号 | 20b 文献序号 | 27 |
| 出处 | 作者（年）·刊名 | Cepeda et al. (2008) *Psych Science* 19(11) |
| 主张 | 一句话，可操作化 | 最优间隔约为目标保持期的 5%–20%，随延迟增长而下降 |
| 量级 | 效应量 + CI + k/I² | 倒 U 形曲线，1,354 名完成全部阶段者 |
| 边界 | 年龄/知识/材料/保真度 | 保持期 7–350 天；超出该区间不外推 |
| 级别 | A/B/C/D | A |
| 关系 | 支持/反对/无关 + 对应准则 | 支持 M8 |
| 纠正 | 流行说法与原文的偏差 | "最优间隔 = 保留期 10–20%"是把曲线压平的经验规则 |

## 5. 研究方法（二）：从证据到设计的转换

有了合格证据，下一步是**决定拿它做什么**。这一节是本文的方法论核心。

### 5.1 三问决策器

任何一条合格证据，过三道闸：

```text
证据（≥ B 级）
   │
   ├─ Q1 量级：效应 ≥ 0.3？
   │      否 → X 禁止（记入不做清单，写明理由与参照系）
   │      是 ↓
   ├─ Q2 覆盖：边界是否覆盖我们的用户与场景？
   │      否 → D 降维 或 X（若边界内为负效应 → X）
   │      是 ↓
   ├─ Q3 可测：能否用现有数据验证它确实发生了？
   │      否 → D 降维（只做启发式：不宣称、不做指标）
   │      是 ↓
   └─ T 移植（做成功能或硬规则）
```

Q1 的阈值 **0.3** 不是物理常数，是本项目的**机会成本线**：低于它的干预，不如把同样的注意力位让给 0.74/0.85 的策略。参照系：高质量辅导 d ≈ 0.40–0.80，成长型思维 d ≈ 0.05。

⚠️ **Q2 是"覆盖"而非"有效"**：证据在我们的用户身上有效才叫覆盖；在大学生身上有效的，若中小学生效应微弱（ERE 即如此），按 D 处理而不是 T。

⚠️ **Q3 不可测时必须诚实降级**：不可测 ≠ 不做，但**不得对外宣称、不得做指标**。这是 M10 的通用化。

### 5.2 三个转换算子

| 算子 | 定义 | 判据 | 本项目实例 |
|---|---|---|---|
| **T 移植** | 直接做成功能或硬规则 | 三问全过 | 精细反馈（0.49）⇒ 导出必须带解析（M4/M5）；掌握学习（0.52 SD）⇒ 连续做对才标掌握（M7） |
| **D 降维** | 保留机制的方向，放弃精度与宣称 | Q3 不过，或 Q2 只部分覆盖 | 分散练习 ⇒ **分段常数**排程（1/3/7/14/28 天），不做 SM-2（M8）；ERE ⇒ 三档辅助而非连续掌握度；ZPD ⇒ 改用掌握学习 |
| **X 禁止** | 不做，并写明理由 | Q1 不过，或边界内为负 | 成长型思维模块（M2）、ZPD 测量（M10）、自适应排程算法（M8）、无限题海（C8） |

降维是本项目最常用、也最容易被误解的算子。它的要点是：**降维后必须同时降级"宣称"**——分段常数排程不能说成"智能算法"，三档辅助不能说成"精准掌握度"。

### 5.3 注意力预算与机会成本

设孩子在产品内可支配的注意力为 **1 个单位**。每个功能都占用一个「注意力位」，且**位是排他的**：给"励志弹窗"的位置，就不能给"再来一次"。

| 候选 | 效应量 | 注意力成本 | 性价比 | 结论 |
|---|---|---|---|---|
| 再来一次（提取） | 0.74 | 低（一道题） | **高** | T |
| 间隔排程 | 0.85 | 中（要等） | **高** | T |
| 精细反馈 | 0.49 | 中（要读解释） | 中高 | T |
| 成长型思维鼓励 | 0.05 | 低但占位 | **低** | X |
| 打卡连续天数 | ≈0（挤出风险） | 低但占位 | **负** | X |

> ✅ **推论 D4**：**"不做清单"不是审美偏好，是预算表。** 一个占位但不产出的功能，其代价等于"少做了一个 0.7 级的功能"。

### 5.4 反证责任与证伪条件

> **规则**：每条准则（M1–M10）都必须写明 **falsifier**——如果这条错了，产品上会观察到什么。

作用是防止准则变成教条。三条要求：

1. **可观测**：falsifier 必须是产品内可采集的数据，不是"重做一遍文献综述"；
2. **可执行**：一旦观察到，必须有明确动作（改准则 / 改实现 / 记录例外）；
3. **不被轻易满足**：如果一条准则的 falsifier 在现有产品里随时都会触发，说明这条准则写得太弱。

示例：

| 准则 | falsifier |
|---|---|
| M3（当次正确率是误导指标） | 若出现一批学生「当次正确率 ≥ 95%」而 30 天后再测 < 60%，则 M3 得到直接印证（当前证据已强，故为"印证点"而非"风险点"） |
| M8（分段常数足够） | 若分段常数排程下 30 天保持率显著低于任意自适应算法（需先能实现），且差距 > 0.2 SD，则应重开算法议题 |
| M2（不做成长型思维模块） | 若出现高保真实施、d > 0.2 的独立 RCT 重复，则应重开该模块 |
| M7（做成的次数 > 夸奖） | 若"夸奖组"在延迟再测上显著优于"重做成功组"，则 M7 失效 |

### 5.5 度量的两个世界

| | 代理指标（Proxy） | 结果指标（Outcome） |
|---|---|---|
| 例子 | 录入数、复习次数、停留时长、连续天数、满意度 | 延迟再测通过率、迁移题通过率、错因改善率 |
| 可测性 | 极易 | 难 |
| 与学习的关系 | 弱（且易被游戏化） | 同构（按 L1/L2/L3 定义） |
| 风险 | 一旦成为 KPI，行为会向指标本身优化 | 样本小、噪声大、易有选择偏差 |

**三条纪律**：

1. **代理指标不得作为产品成功的唯一证据**（"复习了 20 次"不是学习）；
2. **结果指标必须满足 L1 延迟 + L2 无提示**，否则只是又一次当堂测验；
3. **内部纵向对比优先于跨用户横向比较**（样本小、混杂多，横向比较几乎必然得出错误结论）。

### 5.6 落地校验的三道关

一条准则从纸面到工程，必须过三关，缺一关就会退化：

| 关 | 形态 | 退化方式 |
|---|---|---|
| ① 文档 | 20a 的准则条目 + 推导链 | 写完没人读 |
| ② 代码注释 | 实现处引用准则号与边界（如 `review.ts` 注明「依据 M8 / 20b §4.3」） | 注释与实现漂移 |
| ③ 可执行断言 | 自动化用例锁住行为（如 M15 的间隔表硬断言） | 只在被违反时才被发现——但这正是它存在的意义 |

本项目已有的样本：复习排程的间隔表同时出现在 ①（20a/20b）、②（`timeline/review.ts` 注释）、③（M15 硬断言），三处一致才算落地。

## 6. 设计宪法：准则体系

### 6.1 准则的推导格式（七栏）

每条准则必须按固定结构写，**缺任一栏即视为不合格**：

| 栏位 | 作用 |
|---|---|
| 表述 | 一句话，祈使句，可执行 |
| 原理归属 | 指回 L1 的不变量或约束（R2 向上归因） |
| 证据 | 20b 条目号 + 级别 + 量级 |
| 边界 | 不适用条件（§4.3 四问） |
| 落地形态 | 做成什么 / 禁止什么（T/D/X） |
| falsifier | 若错了会看到什么（§5.4） |
| 现状判定 | 本项目 A（合规）/ B（部分）/ X（缺位） |

### 6.2 M1–M10 正文

> 编号沿用 20b 历史编号，**不得重排**——其他文档、代码注释与测试用例都已按此编号引用。

#### M1 同时喂养自主 / 胜任 / 关联；当前最弱的是胜任

| 栏 | 内容 |
|---|---|
| 原理 | C-动机 约束 |
| 证据 | Slemp 2024（N = 443,556，A 级）：支持三需求的行为与需求满足强相关；控制自主支持后，胜任与关联仍解释独立变异（20b §2.2 / 文献 4） |
| 边界 | 跨文化适用（Yu 2018，r = .46 不受文化调节）；但"满足方式"有文化权重——不得据此认为东方孩子不需要自主 |
| 落地 | 产品必须同时提供：可选择（自主）、能做成（胜任）、有陪伴（关联）。**家长参与是 co-agency，不是替代** |
| falsifier | 若某功能在三个维度上均无贡献，却在核心指标上带来提升，说明"三需求"不是必要条件，M1 需弱化 |
| 现状 | **B**：关联与自主已有（家长代办 + 可自选），**胜任最弱**（掌握只有一级台阶，见 C1） |

#### M2 不做成长型思维类独立模块

| 栏 | 内容 |
|---|---|
| 原理 | 该干预不落在 I1/I2 上（§3.5 第五条反常） |
| 证据 | Sisk 0.08、Yeager 0.03、Burnette 0.14 [.06,.22]、Macnamara 0.05（校正后不显著，N = 97,672）、2026 英格兰 100 校 RCT（信念 +0.417 SD，成绩无影响）；均为 A 级（20b §2.3 / 文献 12–18） |
| 边界 | 不是"被彻底推翻"，而是"平均效应接近零，且与效应高一个数量级的活动争同一注意力位" |
| 落地 | **X**：不做模块、不做推送。唯一保留：反馈语言指向方法而非能力（与 M5 同源） |
| falsifier | 出现高保真实施、独立重复、d > 0.2 的 RCT |
| 现状 | **A**（明确不做，已写入 OPS-18 不做清单） |

#### M3 关键指标不是当次正确率

| 栏 | 内容 |
|---|---|
| 原理 | I1（提取强度 ≠ 存储强度）+ C-元认知 |
| 证据 | Roediger & Karpicke 2006（5 分钟反转，一周 61% vs 40%）；Kornell & Bjork 2008（78% 判断错误）；Rohrer & Taylor 2007（同一练习次序在 1 周后完全反转）（20b §3.2） |
| 边界 | 不否认当次正确率的诊断价值（能发现"完全没懂"），否定的是它作为**学习证据**的地位 |
| 落地 | **T**：任何"正确率/已复习 N 次"的展示，必须同时给出延迟语义（下次何时、今天该复习、已逾期几天） |
| falsifier | 若当次正确率与 30 天后再测高度相关（r > .8），M3 可放松 |
| 现状 | **B**：C4 已下发 `next_review_at` 并展示到期语义；但仍无任何延迟再测数据，指标体系尚未建立 |

#### M4 错题闭环到含推理分析的纠正性反馈

| 栏 | 内容 |
|---|---|
| 原理 | I2 修正 |
| 证据 | Metcalfe 2017（只错不纠可能强化错误）；Butterfield & Metcalfe 2001（高修正效应）；Sinha & Kapur 2021（PF g = 0.36，但 2–5 年级反向）（20b §3.3） |
| 边界 | ①零基础不得丢去试错（PF 低龄反向）；②反馈须含"为什么错"，只有正确答案不算订正；③高信心错误优先 |
| 落地 | **B**：导出已实现"提取"，但**缺"核对 + 订正"闭环**（C7）与置信度字段（C2） |
| falsifier | 若"只给正确答案"组在延迟再测上与"给解析"组无差异，则精细反馈的梯度不成立 |
| 现状 | **B/X**：提取有（A2），纠正缺（C7） |

#### M5 反馈默认给解释，且一律指向任务而非自我

| 栏 | 内容 |
|---|---|
| 原理 | I2 修正（粒度决定梯度）+ C-动机（自我威胁抑制学习） |
| 证据 | Van der Kleij 2015：精细 0.49 / 仅答案 0.32 / **仅对错 0.05**；Kluger & DeNisi 1996：平均 0.41 但 **>1/3 反馈使表现变差，指向自我最有害**；Eskreis-Winkler & Fishbach 2019：他人给的失败反馈学到更少（20b §3.4） |
| 边界 | 时机分场景：技能定型期立即（应用型研究倾向立即）、概念重构/难题可延迟（Clariana 2000：难题 1.17 / 简单 −0.06） |
| 落地 | **T**：「对/错」不得作为唯一反馈；一律指向"这一步怎么做" |
| falsifier | 若"仅判对错"组与"给解释"组在延迟测量上无差异（即 0.05 vs 0.49 不能复现） |
| 现状 | **B**：答案+解析已合并为一个编辑框（DD-08），但缺"何时给"的策略（C6） |

#### M6 辅助强度随掌握梯度变化：新手多给、熟手少给

| 栏 | 内容 |
|---|---|
| 原理 | C-资源（ERE） |
| 证据 | Tetzlaff 2025（176 效应 / 5,924 人，B 级）：低先备者高辅助 **d = 0.505**；高先备者低辅助 **d = −0.428**；Kirschner 2006（最少指导对新手不利）（20b §3.5） |
| 边界 | 大学生最明显、中小学生较弱；STEM 明显、人文学科模糊 |
| 落地 | **T/D**：至少三档（详解 → 提示 → 只给题）。当前只有二值 `mastered`，实际是"未掌握=给详解 / 已掌握=不再出现"，缺中间梯度 |
| falsifier | 若低先备者在低辅助条件下表现不差（0.505 无法复现） |
| 现状 | **X**（C1：缺掌握梯度） |

#### M7 提升"做成过的次数"，而非夸出来的信心感

| 栏 | 内容 |
|---|---|
| 原理 | C-动机（胜任）+ I1（成功提取本身即是掌握性经验） |
| 证据 | Sitzmann & Yeo 2013（个体内效能→表现控制后 ρ = .06 n.s.；过去表现→效能 ρ = .30）；Byars-Winston 2017（掌握性经验为四类来源最强，言语说服最弱）；Robbins 2004（ρ = .496）（20b §3.7） |
| 边界 | 效能与表现互为因果（Talsma 2018 交叉滞后），故不能反过来推出"信心无用"——只能说"**指望靠提升信心来提升成绩**无效" |
| 落地 | **T**：设计可辨认的小成功（重做同一道错题并答对、连续三次答对才标掌握） |
| falsifier | 若"夸奖组"在延迟再测上显著优于"重做成功组" |
| 现状 | **B**：有单题重做，但掌握判定是"一次做对"（A5），未达"多次成功" |

#### M8 排程用分段常数即可，不必实现自适应算法

| 栏 | 内容 |
|---|---|
| 原理 | I3 间隔（曲线峰顶平坦） |
| 证据 | Cepeda 2008（最优间隔在 70–350 天区间几乎不变，约三周）；Latimier 2021（递增 vs 均匀 **g = 0.034, 95% CI [−0.10, 0.17], p = .59, I² = 0%**——精确的零）；Cepeda 2006（259/271 组分散更优）（20b §4.3） |
| 边界 | "宁可错晚、不可错早"：过早复习既浪费注意力又制造虚假熟练感；分段常数需覆盖"想记住多久"的常见档位（周/月/学期） |
| 落地 | **T**：五档 1→3→7→14→28 天；基准是**上次复习时间**；做对推进、做错归零次日再来 |
| falsifier | 分段常数下 30 天保持率显著低于自适应算法且差距 > 0.2 SD |
| 现状 | **A**（C4 已落地，三处一致：文档 / 注释 / M15 断言） |

#### M9 交错只在同学科内混入易混题型

| 栏 | 内容 |

| 证据 | Rohrer & Taylor 2007（练习 89/60 → 一周后 20/63，完全反转）；Rohrer 2020（一个月后 61% vs 38%）；Brunmair & Richter 2019（总体 0.42；数学 0.34；绘画 0.67；**说明文不显著；单词背诵 −0.39**）（20b §4.4） |
| 边界 | ①"混合的是题型，不是学科"；②单词背诵、说明文禁用；③需要先具备基本辨别能力，否则退化为非合意困难 |
| 落地 | **X**（C5 剩余部分）：依赖 C3 的错因/题型维度，尚无数据基础 |
| falsifier | 若数学题内交错在延迟测量上不优于分块（0.34 无法复现） |
| 现状 | **X** |

#### M10 不得宣称能测量 ZPD / 智能水平

| 栏 | 内容 |
|---|---|
| 原理 | 元准则 E2（不宣称不可测量之物）+ C-资源 |
| 证据 | Chaiklin 2003（维果茨基未给出评估方法）；Caffrey 2008（动态评估预测效度 r ≈ .12–.24）；Belland 2017（计算机化脚手架 g = 0.46，但 fading 未测出差异）（20b §3.6） |
| 边界 | 不否认 ZPD 的**设计启发价值**（"别给远超能力的东西"），否定的是它的**可测量性**与对外宣称 |
| 落地 | **X + D**：禁止"算出最近发展区"的表述；改用**掌握学习**（Kulik 1990：108 项，+0.52 SD，低能力组 +0.61 SD） |
| falsifier | 出现预测效度 r > .6 的公认 ZPD 测量工具 |
| 现状 | **A**（明确不做） |

### 6.3 元准则 E1–E5

元准则是**约束准则的准则**，它们不针对某个功能，而针对"如何论证"。

| 编号 | 元准则 | 违反的后果 |
|---|---|---|
| **E1** | **无出处不立论**：未标注出处的主张不得作为设计依据 | 论证退化为意见，评审变成投票 |
| **E2** | **不宣称不可测量之物**（ZPD、智能、精确掌握度） | 承诺无法兑现，测试无法证伪 |
| **E3** | **边界优先于平均**：两条结论冲突时取更保守的一侧 | 用"平均有效"掩盖"对我们是负的" |
| **E4** | **宁可少给，不做错**：非合意困难的代价高于少做一次的损失 | 用"多练总没坏处"合理化题海 |
| **E5** | **感知不等于效果**：凡以"用户觉得有用"为依据的提案，须补效应证据 | 产品越来越讨喜，学习毫无变化 |

### 6.4 变更程序

| 变更对象 | 谁能改 | 改要什么 | 改完验什么 |
|---|---|---|---|
| 准则表述（M1–M10） | 文档所有者 + 一轮评审 | 新增 ≥B 级证据条目；复核边界；重写 falsifier | 是否有其他文档/代码引用了旧表述 |
| 间隔表（M8 的具体数值） | 同上 | 同上 + 明确"想记住多久"目标档位 | **三处同步**：20a/20b 表格 + `review.ts` + M15 硬断言 |
| 新增准则（M11+） | 同上 | 必须能归因到 L1 不变量或约束（R2） | 是否与既有准则冲突（R3） |
| 新增/修改元准则 | 需单独评审 | 说明现行元准则导致了什么具体损失 | —— |

⚠️ **准则冻结规则**：准则编号一经发布**不得重排或复用**。废弃时保留编号并标注「已废弃（日期 / 理由）」，新准则追加在末尾。理由：其他文档、代码注释与测试用例都按编号引用，重排会让历史论证全部失效。

## 7. 框架的自我校验：以本项目为样本

方法论如果不拿自己做一次体检，就只是一篇读后感。

### 7.1 三层价值 ↔ 三不变量

SRS-01 §2.3 的三层价值，在这里第一次有了机制归属（而非功能描述）：

| 层 | 产品价值 | 机制归属 | 主要证据 |
|---|---|---|---|
| ① 收得进 | 拍一下入库，少打字 | C-资源（把整理成本转移给工具，保护注意力） | CLT / ERE |
| ② 复习得起来 | 复习本 + 三维检索 + 掌握状态 | **I1 提取（0.74）+ I3 间隔（0.85）** | Roediger 2006；Cepeda 2006/2008 |
| ③ 举一反三 | 错因归类 → 同类题 → 解题通法 | **I2 修正 + 自我解释（0.54）+ 交错（0.47，数学）** | Bisra 2018；Brunmair 2019；PF 的收益分化 |

⚠️ 第 ③ 层的机制要求最高：它依赖的不是"给更多题"，而是"**解释为什么**"与"**混着练**"。

### 7.2 合规判定

| 判定 | 含义 | 本项目条目（详见 20b §5） |
|---|---|---|
| **A 合规** | 不做会出错，现在做对了 | A1–A6（其中 A6 = C4 排程）、M2、M8、M10 |
| **B 部分** | 方向对但缺一半 | M1（缺胜任）、M3（缺延迟测量）、M5（缺时机策略）、M7（缺多次成功） |
| **X 缺位** | 机制缺席，构成实质缺口 | C1 掌握梯度、C2 置信度、C3 错因、C5 交错、C6 延迟反馈、C7 订正闭环 |

### 7.3 缺口排序法（替换拍脑袋）

> **优先级 = 效应量 × 覆盖面 ÷ 实现成本**，且**阻塞项优先**。

| 缺口 | 效应量 | 覆盖面 | 成本 | 是否阻塞 | 排序 |
|---|---|---|---|---|---|
| C3 错因归类 | 0.49（精细反馈的前提） | 高（第③层全部） | 中（受控词表 + 字段） | **阻塞 M9/C5** | **1** |
| C2 自评信心 | 高修正效应（无量化 d，A 级方向） | 中 | 低（一次点击） | 否 | 2 |
| C1 掌握梯度 | 0.505 / −0.428 | 高 | 中（状态机改造） | 否 | 3 |
| C5 交错（剩余） | 0.34–0.47（数学） | 中 | 中（依赖 C3） | 被阻塞 | 4 |
| C6 延迟反馈 | 1.17（仅难题） | 低 | 低 | 否 | 5 |
| C7 订正闭环 | 0.49 | 高 | 高（新流程） | 依赖 C3 | 6 |

结论：**C3 > C2 > C1 > C5 > C6 > C7**。与 20b §5.2 的手工排序一致——但这次是**算出来的**，不是感觉出来的。

### 7.4 四条张力与裁决规则

素材里充满了互相矛盾的结论。它们不是"文献打架"，而是**不同条件下的同一机制**。裁决规则四条：

| 元规则 | 内容 |
|---|---|
| **T-1 边界优先** | 先看条件是否不同（年龄/材料/先备知识），条件不同则不是冲突 |
| **T-2 剂量优先** | 同向但强度不同时，取"更保守的剂量"（E4） |
| **T-3 可测优先** | 两条都说得通时，选能被验证的那条 |
| **T-4 诚实优先** | 无法裁决时，选"少做且说清边界"，而不是"都做且都说有效" |

具体四个张力：

| 张力 | 两侧证据 | 裁决 |
|---|---|---|
| **自主 vs 结构** | SDT 要求自主；PF 在 2–5 年级反向、Kirschner 2006 指出最少指导对新手不利 | **按先备知识分档**，不按年龄拍脑袋：新手给结构，熟手给空间 |
| **挑战 vs 心理安全** | 高修正效应需要"被否定"；Eskreis-Winkler 2019 显示他人给的失败反馈学到更少（自我威胁） | **反馈指向任务 + 不公开比较**：挑战留在任务层，威胁不落到自我层 |
| **及时 vs 延迟** | 应用型研究倾向立即；实验型倾向延迟（16:11）；Clariana：难题 1.17 / 简单 −0.06 | **按任务类型分派**：技能定型立即、概念重构延迟 |
| **交错 vs 分块** | 数学 0.34、绘画 0.67；说明文不显著、单词 −0.39 | **按材料类型分派**：概念类交错、词汇类分块 |

### 7.5 三个已完成的裁决样本

展示方法论如何实际运作（也是给未来评审的模板）：

| 提案 | 走的三问 | 结果 |
|---|---|---|
| 「加一个每日打卡，提升坚持性」 | Q1：效应≈0 且有挤出风险（Cerasoli：激励显著时 ρ 从 .45 降到 .22）→ 不过 | **X**，记入不做清单 |

## 8. 可错性：这份文献可能错在哪

### 8.1 三类可能的错误

| 类型 | 具体形态 | 缓解 |
|---|---|---|
| **取材偏差** | 文献以英文期刊为主，中国 K12 课堂的高质量证据偏少；家庭教育场景（家长代办）几乎没有直接研究 | 边界栏显式标注"跨文化外推风险"；把"家长代办"标为 A1 的**假设**而非结论 |
| **推论过头** | 把"平均效应"当"对我们必然有效"；把"机制存在"当"功能必然奏效" | 元准则 E3/E4；每条准则配 falsifier |
| **情境迁移** | 实验室的"学习"多为文字材料 + 短周期测量，与手机小屏 + 学期周期不同构 | 优先引用课堂研究（Yang 2021、Rohrer 2020、Chowrira 2019）；对纯实验室结论降一级 |

### 8.2 更新触发清单

出现以下任一情况，**必须回来修订本文**（并升主版本）：

1. 出现 ≥B 级的**反证**，方向与某条准则相反；
2. 关键元分析更新（Cepeda / Dunlosky / Van der Kleij 一类有新版）；
3. 本产品的纵向数据与某条准则冲突（例如延迟再测显示当次正确率其实有效）；
4. 场景扩展：加入新学段、新学科（尤其语言/艺术）、新用户角色（孩子自主使用）；
5. 平台或交互形态变化（语音输入、纸笔数字化），使"迁移"的定义发生变化；
6. 出现新的可测量工具，使 M10 的前提（不可测）不再成立。

### 8.3 明确不适用

- 非书面作业（体育、乐器、操作技能）；
- 成人自我调节学习（自主性前提完全不同）；
- 口语与听力（本项目未覆盖）；
- 竞赛拔高与超常教育（证据多来自常规课堂）；
- 心理干预性质的需求（学习动力、亲子关系）——超出本文范围，不应假借本文立论。

## 附录 B 拿到一个新提案时怎么走（操作清单）

```text
1. 它想改善什么？（必须落到 L1/L2/L3 判据上，不能是"体验更好"）
2. 找证据：≥B 级？在 20b 里是否已有条目？
3. 过三问：量级 ≥ 0.3？边界覆盖我们的用户？我们能测出来？
4. 定算子：T 移植 / D 降维 / X 禁止
5. 写 falsifier：如果错了，我们会在哪个数据上看到？
6. 过 R2：它能指回哪条不变量或约束？指不回去 ⇒ 退回
7. 查冲突：与 M1–M10 有无冲突？冲突走 §7.4 张力裁决
8. 落地三关：文档 → 代码注释 → 断言
```

> 📌 本清单是**思维顺序**（怎么想对）；**流程、表单与门禁**见 `GK-OPS-22`（怎么保证真的这么做）。两处冲突时：判断以本文为准，流程以 OPS-22 为准。
>
> 机器会替你守三条（`pnpm method:check` / M16）：提案单六栏齐备且引用可解析、用户可见面不含禁用宣称词、镜像参数（间隔表与导出口径）逐字一致。剩下的——归因是否成立、边界写得对不对——**只有人能判**，不要试图把它塞进断言。
