## 1. 文档目的与读者

**要写**：本文覆盖"图像进来 → 处理 → 识别 → 判错"的全链路；前后端调用方式在 DD-08/DD-09，业务流程在 DD-14，本文只讲算法与管线。历史专题报告并入后原文件标注"已并入 DD-10"。

## 2. 能力总览与入口

**要写**：动作清单表（动作 / 触发入口 / 前端按钮 / 后端端点 / 引擎 / 典型耗时）：
裁剪、旋转、自动调正（几何纠偏）、黑白（二值化）、智能高清（超分）、去手写（擦除）、OCR 快识（fast）、OCR 精识（precise）、红笔判错（verdict）。

## 3. 管线架构

**要写**：
- 阶段顺序图：原始图 → 几何纠偏 → 增强（黑白/超分）→ 擦除 → 识别 → 后处理；
- 每阶段的输入/输出与是否可跳过；
- sharp 的统一使用约定（格式、通道、内存限制）；
- ⚠️ **坐标单位约定**：四角坐标归一化到 [0,1]；⚠️ `dewarp` 的 `keepFullCanvas` 把四角映射到单位空间后，**像素量纲的 margin 不可直接相加**（历史事故，两个调用方 `buildLayoutContext` 与 `image-perspective` 都要遵守）。

## 4. 几何纠偏（自动调正 / 手动拉四角）

**要写**：四角自动检测（误差水平）、单应变换与压平、手动四角交互（前端双模式：矩形裁剪 / 四角透视）、归一化坐标传递、失败回退（检测置信度不足时不强行压平）。

## 5. 黑白二值化

**要写**：⚠️ **服务端与客户端算法不同，这是有意为之，不得"统一"**：
- 服务端：全局 Otsu（管线已归一化，光照均匀）；
- 客户端：Sauvola 局部自适应（原图光照不均）；
- 各自的阈值与适用前提、切换条件。

## 6. 智能高清（超分）

**要写**：ESPCN 模型与倍率（x2/x3/x4 × classical/ESPCN）；⚠️ `multi_modes` 参数**仅用于五模式预览，正式超分绝不带**；**OCR 一致性校验**（相似度 0.75）不达标时回退原图并弹窗提示（安全网）；并发与排队（见第 11 章）。

## 7. 去手写（擦除 erase V2 / v21.8）

**要写**（本项目最复杂的算法，务必写透）：
- 总体思路：hybrid mask → 词级判别器 → adaptive inpaint → 相似性验收；
- **词级判别器三态**：只放行判定为墨迹（state=1）的词，**疑罪从无**；微型词噪声地板 `WORD_NOISE_N=12`；
- v21.8 两处关键修复的具体内容与前后对比；
- 各阶段参数与调参依据；
- 验收判据与指标（见第 10 章）；
- ⚠️ **T7 已知缺口**：手写压在印刷字上时像素级不可分，场景 ② 误擦率约 38%，**产品决策为保持现状**（宁可少擦不可误擦），登记 OPS-18 `R-算法-01`。
**素材**：`docs/reports/擦除修复-v21.8-验证记录.md`、`docs/reports/去手写功能-方法论与技术方案.md`、`docs/reports/去手写-评审意见评估与方案修订.md`

## 8. OCR 双引擎与文本分段

**要写**：
- **fast**：RapidOCR，常驻 Python 进程（stdin/stdout 管道，预热后常驻，1~3s）；
- **precise**：PP-StructureV3，HTTP 侧车 9301，空闲 900s 回收、按需重启（首次请求有冷启动延迟）；
- 两者精度/耗时/适用场景对照表与默认选择策略；
- 文本分段规则（段落、行、题块），与前端 `wrongq-ocr-panel` 的分段消费方式。
**素材**：`docs/reports/OCR-架构说明.md`、`docs/reports/OCR-文本分段设计.md`、`docs/reports/issue-ocr-dual-mode.md`

## 9. 红笔检测与判错（verdict）

**要写**：勾叉几何判据、题号正则、条目级门限（组级门）、与条目切分的协作关系；误判时的兜底（不判错优于错判）。
**素材**：`docs/design/红笔检测与条目级切分-修复验证报告.md`

## 10. 验收体系

**要写**：
- 数据集：五场景 GT 的构成与存放位置；
- 指标口径：**G13 / G15 / G16**（G16 口径 M ≤ 2.0%，每次算法改动后必须回归）；
- 探针脚本：位置、运行命令、输出解读；
- 回归门禁：哪些指标不达标即不允许合并。
**素材**：`server/dynamic-tests/`、`docs/design/错题提取功能验证报告-PaddleOCR3.7.0接入后.md`
