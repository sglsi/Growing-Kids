## 5. 恢复自动识别的操作路径（后期升级用）

1. **入口恢复**（工作量小，管路全在）：
   - 在 `pages/recognize/index.tsx` 渲染中补回「双图上传卡」：两个 `chooseImage('question')` / `chooseImage('answer')` 选图钮 + 一个调用 `handleLink` 的「关联」按钮（复用 123-149 行现成 slot 管路，无需新造）；
   - `handleLink` 成功后会自行 `setPageText` / `setShowEditor(true)`（217-218 行），913/929 行两个渲染块随之复活，改框与选择粘贴链路自动恢复；
   - 移除 176 行与 911/929 行附近的 `#150 暂停` 注释横幅。
2. **入口编排**：若人工流与自动流并存，把 tab 三选一（paper/split/doc）扩展为按模式路由，两链路互不影响。
3. **效果达标标准**：按验证报告 §1 真值表，四页作业（p1-unit1-A / p2-unit1-A / p3-unit1-B / p4-unit2-A）的错题数、位置、分栏切分需全部或大部分达标；当前差距：p1 虚检 8→0、p2 虚检 12→2、p3 位置不准、p4 虚检 13→3 且分栏未分开。
4. **遗留待办**（报告 §1.4 / §7.3）：完形填空行二次切分、Ⅰ.4 归属偏移、item 文本 VLM 补全、p4 dup 重号。
