### ① 判据（L1 / L2 / L3）

**保护性归因：L1 延迟——不新增学习行为，只保护「到期复习时拿到的答案确实是这道题的答案」这一前提能被兑现。**

本提案不改善 L1（隔 N 天还能做对）、L2（无提示）、L3（迁移）中任何一条。它修的是更靠前的两环：

1. **候选可得性**：SQL 无排序地截断，会让「正文共现数最高」的文档根本进不了判定池；深挖上限 3 让 P2 多召回的候选轮不到被判定。**召回变宽但排序/截断没跟上，等于白召。**
2. **来源可核对**：`exact` 已带 `source_location`，但页面不展示；家长无法按题号回原文复核，而这是残余风险期间唯一诚实的兜底（§8.5 第 3 条）。

⚠️ 同 P-006/P-008/P-009/P-010/P-011 的写法：若评审认为「保护性归因」不足以支撑 L1，可当作「不涉及判据的检索正确性与可用性工程」，直接按 ⑥ 的显式不宣称处理。

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：无直接不变量。I1 提取 / I2 修正 / I3 间隔均不涉及「候选怎么排」与「来源怎么展示」。
- **约束**：**C-正确性**（候选池里没有原题 ⇒ 再严的判定也产不出正确答案）、**C-资源**（在线抽取会实时下载 + OCR，家长等不起，4 核 4G 也不该扛）。
- **相关准则**：
  - `GK-SRS-20a M10`：宣称不得超出能力 —— 不得把「深挖放宽」写成「都能搜到」或「已解决张冠李戴」。
  - `GK-SRS-20a M11`：如实告知「找到 / 没找到」，来源卡片是**告知**不是拦截。
  - `GK-SRS-20a M8`：明确隔离 —— 不碰 `REVIEW_INTERVALS`、不进「到期首次作答正确率」分组。
- **合规约束（外部、不可放宽）**：《双减意见》§15 / 2021-12-13 教育部通知 ⇒ `exact` 才放解析、`topic` 答案必须为 `''`；定位仍是「家长整理资料、查原题解析」，**不得改成拍照搜题形态**（报告 §7.6）。来源卡片只展示**来源位置**（文件名 / 题号 / 字符区间）与「请核对」，不新增答案内容、不做自动跳题。
- **性能约束（§4 P0-3 / §8.3）**：端到端 P95 < 3s。深挖从 3 放宽到 8 必须靠预算闸门与排序前置控制，不得靠调低判定标准换速度。
