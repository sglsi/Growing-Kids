> 提案号：P-008 ｜ 状态：已批准（**仅限第一阶段：dry-run**） ｜ 日期：2026-11-05 ｜ 关联决策：D-011 ｜ 关联缺口：无（检索工程，不新增学习行为缺口）

> 分档：**L1（功能级）**——把「资料库检索」的召回依据从文件名扩到正文。**不改准则**，故不走 L2，不升 20a 主版本、不补 20b 条目。

---

### ① 判据（L1 / L2 / L3）

**保护性归因：L1 延迟——本提案不新增学习行为，它保护「检索结果能不能找到这道题」这一前提。**

诚实说明：把正文抽出来建索引，不改善 L1（隔 N 天还能做对）、L2（无提示）、L3（迁移）中的任何一条。它损害的是更靠前的一环：

> 题干里的关键词（「平行四边形」「AB=6」这类条件）根本不出现在文件名或目录名里 → 这份资料**永远进不了候选池** → 正文匹配再准也没机会用上 → 用户搜一道自己网盘里明明有的题，结果只有一串无关文件名。

这不是「找得更聪明」，而是**把本来就存在的内容变得可被找到**。因此宣称必须同步降级（见 ④）：只说「在资料正文里找到 / 没找到」，**不得**说成「都能搜到」「一搜即得」。

> ⚠️ 若评审认为「保护性归因」不足以支撑 L1，可把它当作「不涉及判据的检索工程」，**直接按 ⑥ 的显式不宣称处理**——本提案的证据强度不依赖判据归属成立（同 P-005 / P-006 的写法）。

---

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：无直接不变量。I1 提取 / I2 修正 / I3 间隔均不涉及「检索时拿什么去比对」——**本提案在信息检索层，不在学习机制层**。
- **约束**：**C-资源**（工作记忆与注意力有限）。用户（家长）要在一堆文件名里逐条点开、下载、翻页去找一道题的解析，属与学习无关的外在负荷；找得越久，越不会用。
- **相关准则**：
  - `GK-SRS-20a M10`：宣称不得超出能力 —— 不得把「抽了 1 万份正文」说成「你的资料都能搜」。抽不出正文的（扫描版 PDF、`.doc`、视频音频）必须如实说不在范围。
  - `GK-SRS-20a M11`：「找得到 / 找不到」是**如实告知**，不是拦截，也不是逼用户去开 AI 开关。
  - `GK-SRS-20a M8`：明确隔离 —— 不碰 `REVIEW_INTERVALS`、不进「到期首次作答正确率」分组。抽正文是索引工程，与复习排程、结果指标无任何耦合。

### ④ 算子（T / D / X）

本提案主体是 **X（明确不做）**。`GK-OPS-22` §3.2 的三问决策器（20a §5.1）留痕：

| 问 | 结论 |
|---|---|
| Q1 量级 | 不适用（不是学习干预，不产生新的学习行为） |
| Q2 覆盖 | 不适用（同上） |
| Q3 可测 | **不可测**——「召回变宽」无法在现有指标里体现（结果指标只测到期作答正确率） ⇒ 按 §3.2 边界情形判 **D（降维）**：只做可用性工程，不做指标、不做宣称 |

| 约束 | 内容 | 理由 |
|---|---|---|
| **① 只抽文字层，绝不上 OCR** | `textOnly: true`，扫描页不渲染 | 精准线 OCR 实测 **2.41s/页**、单次驻留 1.6GB；1 万份量级会把 4G 机器打爆。抽不到就是抽不到，如实记 `none` |
| **② 只覆盖实测划算的三类** | `docx` 全量 + `pdf < 1MB` + `txt` = 11,190 份 | pdf `1–5MB` 可抽率 0%、`5–20MB` 12.5%、`20–40MB` 0%——下载量翻 8.7 倍只多 6.6% 正文，不划算 |
| **③ `.doc` 明确不做** | 10,503 份 `.doc` 不纳入本轮 | L3 未装 `soffice` / `antiword` / `catdoc`；二进制老格式转换慢、排版不稳，需单独立项 |
| **④ 环境类失败保持 `pending`** | `no-python` / `no-script` / `timeout` 一律不回写 `none` | `none` 的语义是「确认这份文档没有文字层」，记错了这份文档就**永久判死**。这是 2026-11-03 已经踩过的坑（`library-index-text.mjs` 注释自述） |
| **⑤ 只写三列** | `text_content` / `text_status` / `text_updated_at` | 抽取不得动 `name` / `path` / `size_bytes` / `mtime` / `synced_at` 等元数据；判据 10 §10-5 |
| **⑥ dry-run 是一等公民** | 不带 `--apply` 只统计、只出预估，**一行不写** | 本提案当前**只批准到 dry-run**；写库动作必须另行拍板 |
| **⑦ 不碰检索代码** | `netdisk-search.service.ts` 本轮零改动 | 报告 §11 第 4 步：抽完先用 SQL 试检真题，确认收益真实存在再改代码，避免白改 |
| **⑧ 不碰排程与指标** | 不进 `REVIEW_INTERVALS`、不进「到期首次作答正确率」分组 | `GK-SRS-20a M8` 的隔离精神 |
