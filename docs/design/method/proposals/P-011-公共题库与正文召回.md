## 0. 本轮到底改什么（一句话）

**现状**：326,680 个结构化题目对象 / 10,454 份正文 / 78,430 条网盘索引全部挂在 2 个账号下，而 `searchLocal()` → `ensureText()` → `loadQuestionObjects()` 三处都按登录用户过滤 ⇒ **换任何新账号检索，公共题库零命中**；同时 `searchLocal()` 只查 `name/path ilike`，题干词不在文件名里的原题永远进不了候选池（`AB=6` 文件名 0 / 正文 196）。

**本轮**：把公共资料的查询/缓存/对象统一走**固定公共 owner**（不改表结构、不搬 457MB），并给正文加 `text_flat` 归一化列 + 双通道召回 + 锚点共现排序。用户私有数据（错题、`library_docs` 上传件、`answer_cache`、复习记录）继续按各自 `userId` 隔离，**不放共享开关、不用访问权做对价**。

---

### ① 判据（L1 / L2 / L3）

**保护性归因：L1 延迟——不新增学习行为，只保护「到期复习时拿到的答案确实是这道题的答案」这一前提能被兑现。**

诚实说明：本提案不改善 L1（隔 N 天还能做对）、L2（无提示）、L3（迁移）中任何一条。它修的是更靠前的两环：

1. **数据可得性**：题库是运营者提供的公共内容，却被登录用户 ID 隔离成「只有 1 个账号能查」。不修这一环，P-009/P-010 的全部正确性工程对新用户等于不存在。
2. **召回可得性**：正文已在库（9,450 万字），但检索侧只比文件名。不修这一环，「判定再准也见不到题」。

⚠️ 同 P-006/P-008/P-009/P-010 的写法：若评审认为「保护性归因」不足以支撑 L1，可当作「不涉及判据的数据归属与检索正确性工程」，直接按 ⑥ 的显式不宣称处理——证据强度不依赖判据归属成立。

---

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：无直接不变量。I1 提取 / I2 修正 / I3 间隔均不涉及「题库归谁」「怎么召回」。
- **约束**：**C-资源**（家长不该被迫自己把题目手工搬进公共库）、**C-正确性**（候选池里没有原题 ⇒ 再严的判定也产不出正确答案）。
- **相关准则**：
  - `GK-SRS-20a M10`：宣称不得超出能力 —— 不得把「召回变宽」说成「都能搜到」「精准定位到题」「已解决张冠李戴」。
  - `GK-SRS-20a M11`：如实告知「找到 / 没找到」，不是拦截，也不是逼用户开 AI 开关。
  - `GK-SRS-20a M8`：明确隔离 —— 不碰 `REVIEW_INTERVALS`、不进「到期首次作答正确率」分组。
- **合规约束（外部、不可放宽）**：
  - 《双减意见》§15 / 2021-12-13 教育部通知 ⇒ `exact` 才放解析、`topic` 答案必须为 `''`；定位仍是「家长整理资料、查原题解析」，**不得改成拍照搜题形态**（报告 §7.6）。
  - `R-合规-08` 路径③：网盘凭证是运营者单账号 ⇒ 面客文案与隐私政策必须改为「运营者提供的公共资料库」，不再说「你自己的网盘」。
  - **PIPL §16**：不得以不同意/撤回同意为由拒绝提供服务 ⇒ ⛔ 任何「共享自己的题才能用公共题库」的对价开关；§23/25 单独同意、§15 撤回删除、§28/29 监护人同意。
  - **微信个人主体**：【社交-笔记】类目不开放 ⇒ 用户上传内容供他人查看属 UGC 发布，**本期彻底不做用户贡献通道**。

## 附：为什么现在可以启动 P2（对 D-012 §8.5 的改判说明）

`D-012` §8.5 写「**P1 / P2 / P3 一律不启动**」，理由是「召回一旦变宽，§8.4 的解析归属残余风险会被规模化放大」。这是**当时的拍板范围**，作为历史事实原样保留（M31 有静态断言钉住），本条**追加**改判、不回溯涂改。

改判依据（三条同时成立才动）：

1. **判定层已经换了一代**：`D-012` 时只有全文级 `judge()`；现在 `exact` 必须过 P0 六条硬闸 + P1 `judgeStoredObjects()` 的指纹 / 正文版本 / `link_status` / 定点排除。**召回变宽 ≠ 放行变宽**——多进来的候选仍逐条走同一套串联否决，P1 只会在 P0 之上再拒绝，不新增任何 `exact`。
2. **举证责任没有变**：仍是「未达标不放行」，不是 Top-1 排序、不是调阈值。P2 改的是「谁有资格被审」，不是「审得松一点」。
3. **补偿闸门**：`exact` 仍必须带 `source_location`；呈现层保留「请按来源核对原题解析」；文档**明确保留**「合成『题干 A + 别人解析』仍放行」的残余风险；`strict=1` 与 P3 继续锁；新增 `NETDISK_TEXT_RECALL=0` 可一键退回纯文件名召回。

⚠️ 因此本轮**不得**宣布「第二层上线准入已全绿」。§8.5 卡住的「解析段归属」依旧没解决，P2 只是让「已经对的题」有机会被看见；A9 的真实登录 E2E 未做之前，不得写成已验证全用户可用。

## 附：明确不做（含理由）

| 不做 | 理由 |

| 用户贡献 / 共享开关 / 共享换权限 | PIPL §16 强制同意禁令；个人主体【社交-笔记】类目不开放；教辅信息网络传播权；答案污染 `exact`。思傅 11-07 定「本期不做，后续再评估」 |
