## 0. 一句话，以及为什么这解开了死结

**数据一直在，是不给看。** `D-017` 实测 8 条真实题 `exact=0/8`，曾归因为「库覆盖 / OCR 字面差异 / 英文锚点」。本轮只读取证发现更根本的一层：L3 生产库 `question_objects` **326,087** 行，其中 **92,357** 行 `has_solution=true`、**89,192** 行 `solution_text` 超过 30 字；几何题「中点 + 60° + 面积」相似题 **134** 行、「中点 + 带解析」**2,951** 行，`BMDN` 带解析 2 行、`CD+DE` 5 行。当前 `answer-search.service.ts` ⑤ 兜底把这些全部降级成一串**文件名**，孩子得到的是「没找到这道题的答案」+ 5 个文件路径。**不是没内容，是把内容锁起来了。**

| 专利 CN121031565B / 教育 RAG 综述 | BERT/FAISS 向量召回 → SimHash → BGE-Reranker → LLM 判定；或 BM25 + 向量 + 知识图谱 + RRF + Reranker；元数据（学科/难度/知识点）硬过滤 | 说明「相似题」在工业界是**召回 + 精排 + 判定**三段式，有成熟判据可依 |

**对比结论（本项目设计思想的修正）**：
1. 此前把「检索成功」定义为二元 `exact / 未找到`，是**窄于行业、也窄于最终目的**的定义。行业把「原题答案」与「同类题思路」分成两个并列产品层，本项目只有前者。
2. 「未达标不放行」应该限定为「**未达标不得冒充本题答案**」，而不是「未达标不得提供任何学习材料」。本提案据此把闸门的作用域钉死在 `answer` / `verified` / `canAdopt`，把「参考例题」放在闸门**之外**、声明**之后**。
3. 行业普遍用向量召回 + Reranker。本项目**本期不上**：理由是 ① 现有 32.6 万对象 + `text_flat` trgm + 长锚点共现已足以召回带解析的相似题（§2 实证）；② L3 单机、`P95<3s`、第二层上线准入仍锁，引入 embedding 服务与 32 万向量索引属 L2 级改动；③ 按思傅「按能不能实现最终目的为目标」，**最小改动先让孩子看到思路**比先铺基础设施更符合目标。向量化 / 知识点元数据 / Reranker 作为后续独立提案方向登记（§4）。

## 3. 六栏

### ① 判据（L1 / L2 / L3）

**L1（本轮）**：判定层 `question-match.ts` 零改动；`exact` 六条硬闸、举证责任倒置、`verified` 语义、`answer` 字段口径、`canAdopt` 闸门**全部原样**。新增并列字段 `references[]` 与 `reference_disclaimer`，只在「没有 exact 结果」时出现。
**L2（不做）**：向量召回 / Reranker / 知识点图谱 / 大模型改写讲解 / 用户贡献通道 / 变式题自动生成。理由见 §1 第 3 点。
**L3（不做）**：改 20a 学习准则、改复习排程、改隐私政策口径、动身份治理 4 组文件。

### ② 归因（不变量 / 约束 / 准则）

- **不变量 A（零放宽）**：`answer` 只能来自 `exact`；`verified` 只对检索到的本题答案为 true；参考例题**永不进 `answer`、永不置 `verified=true`、永不提供「采纳」**。
- **不变量 B（同源配对）**：每条参考例题的 `stem` 与 `solution` 必须来自**同一个 `question_objects` 行**，绝不跨对象拼接 ⇒ 从结构上消除「题干 A + 别人解析」。
- **不变量 C（可追溯）**：每条参考题带 `source_location`（哪份资料、第几题、原文字符区间），家长可回原文核对。
- **约束 D（事先声明）**：声明文案由服务端下发，前端**在渲染任何参考题内容之前**先行渲染；且**每条参考题卡片自带重复声明**。声明必须含三要素：不是本题答案 / 仅供借鉴解题思路 / 请先自己想一想再对照。
- **约束 E（合规）**：个人主体、双减「拍照搜题不是作业代答器」定位不变 ⇒ 给的是**另一道题的讲解**供思路借鉴，不是本题答案；不新增 UGC、不新增 AI 生成内容标识问题、不碰隐私政策 r8。
- 准则：`GK-SRS-20a` M8（不拿时长/连续天数当判定）、M10（如实告知，不制造已掌握的假象）、M11（展示与判定分离）。本轮**不改任何学习行为**，故不过 §5.1 三问的新增项。

### ③ 证据（20b 条目 + 级别）

- **A 级（本轮实测）**：§2 的 L3 只读计数与库内解析样例；`D-017` 的 8 条真实题 `exact=0/8`；`kb-upstream-diagnose.mjs` 可重跑。
- **A 级（行业公开资料）**：§1 五类来源（作业帮官网、中国经济网夸克 AI 搜题、2026 横评、两份公开专利、教育 RAG 综述）。⚠️ 行业命中率数字（如 98%）是厂商自述，**不作本项目验收基线**。
- **B 级（工程约束）**：`QA-16 §6.1.7.1` 的 14 项永久排除项、`M35/M36` 判定层 sha256 基线、`CACHE_VERSION` 红线。
- 🔴 **不得据本提案计算召回率**：样本仅 8 条真实题；唯一够格的结果指标仍是 `0021 review_events` 的到期首次作答正确率（当前 0 行）。

### ④ 算子（T / D / X + 边界 + 不做什么）

- **T（筛选）**：新增零业务依赖模块 `server/src/shared/question-reference.ts`，import 判定层纯函数，实现独立判据 `collectReferences(question, rows, opts)`：①对象通过 `validateStoredObject()`（版本 / 指纹 / link_status / 解析边界可信）；②`has_solution` 且 `solution_text` 去空白 ≥60 字（有过程，不是只给答案）；③题干长锚点在 `stem_text` 中共现 ≥2；④排除已被 exact 放行的对象；⑤按共现数 → 解析长度排序，最多 3 条；⑥题干截 500 字、解析截 1200 字。
- **D（透传）**：`netdisk-search.service.ts` 深挖循环已有每个候选文件的 `rows`，在 `judgeWithStore()` 之后顺带收集、按 `sourceId+objectIndex` 去重、汇总进 `NetdiskSearchResult.references`；`answer-search.service.ts` 在未 settled 时把 `disk.references` 透传进 `result`；`CACHE_VERSION v10 → v11`（result 结构变了，按 §4 红线 bump）。
- **X（呈现）**：前端 `answer-editor.tsx` 在结果卡顶部渲染固定声明 banner，逐条展示「库内原题题干 → 它的解析过程 → 来源 → 为什么推荐（共现锚点）」，每条重复声明；`canAdopt` 不变。
- **边界**：只在 `mode=kb` 且 `inputGuard.ok` 时产生（整页 / 多小问仍按 `D-017` 引导用户单独录入小题）；自有题库 / 自有资料库 / ima 命中原题时 `settled=true`，不叠加参考例题。
- **不做什么**：不改 `question-match.ts`、不调六条硬闸阈值、不自动切题、不逐题检索、不用 LLM 改写或生成本题答案、不改 `TEXT_RECALL_KEYS` / `MAX_DEEP_FILES` / `strict`、不写业务库表、不迁移、不动 4 组身份治理文件、不宣称「命中提升 / 修复有效 / 误判归零 / 所有用户已可用」。

### ⑤ falsifier（产品内可采集）

1. **参考题污染答案**：任一 `references` 非空的结果里 `answer !== ''` 或 `verified === true` 或出现「采纳」按钮 ⇒ 立即判失败并回滚。
2. **张冠李戴（结构性）**：任一参考题的 `stem` 与 `solution` 不来自同一 `object_index` ⇒ 判失败。
3. **声明缺失 / 事后声明**：前端先渲染内容后渲染声明，或旧缓存（v10 及以前）结果被当成参考题展示 ⇒ 判失败；`CACHE_VERSION v11` 保证旧结果整体失效。
4. **误判归零口径被破坏**：判定层 `question-match.ts` sha256 与 `M35/M36` 基线不一致 ⇒ 判失败。
5. **目标证伪**：若上线后干净单题（103 字几何题）参考题恒为 0 条，或抽 10 条人工看没有一条「同知识点 / 同方法」，则本层无效，按 `D-016` 先例改判「未达标」，**不得写成收益**。
