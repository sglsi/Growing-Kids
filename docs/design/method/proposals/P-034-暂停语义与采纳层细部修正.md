## 2. 概念澄清（写入文档，防止重复讨论）

### 2.1 三条"出本"路径，语义互不相同

| 路径 | 谁触发 | 依据 | 能否当效果证据 | 数据表现 |
|---|---|---|---|---|
| 系统毕业 | 系统 | 连续做对达到档数（做错即归零） | ✅ 唯一够格的 L1/L2 证据来源 | `review_count >= N` → `in_review_book=false`；保留计数 |
| 家长暂停 | 家长 | 无（"这题暂时不想排"） | ❌ 不能，且**不需要衡量** | `in_review_book=false` + 暂停标记；可一键恢复 |
| 家长导出筛选 | 家长 | 主观判断 | ❌ 不能（M3：78% 自评错误） | `mastered` 列，只控制导出是否纳入；**不再是掌握判定** |

> ⚠️ 思傅第 1 问"暂停即出本如何衡量"——**暂停不是系统判断，是家长主动点一下，不存在"衡量"问题**。需要设计的只是：暂停态怎么存、怎么恢复、与毕业态怎么区分。

### 2.2 已掌握 vs 做对推进（思傅第 2 问）

区别就是**主观判断 vs 系统证据**。上一轮 P-033 按拍板把 `mastered` 降级为"不进入导出"、让五档接管出本。本轮拍板维持该决定 ⇒ **不恢复家长标"已掌握"按钮**。复习本上只有"暂停"，没有"已掌握"。

### 2.3 队列不是手机上做题（思傅第 14 问）

`review-queue.tsx` 卡片**只显示题干与题图，刻意不渲染答案/解析/错面图**。手机端的作用是**登记"做对/做错"**（3 秒/题），不是让孩子在手机上书写作答。真正的作答有两条路：

- **纸质**（推荐，减少孩子屏幕时间）：汇总导出「打印练习卷」→ 孩子纸上做 → 家长对答案 → 回队列点结果；
- **手机**（碎片时间）：孩子看题心算/口述 → 家长在旁边点结果。

两种模式喂同一个 `markReviewed`，不另开写入路径。这就是思傅第 3 问要的双模式，已在 P-033 D 项实现，本提案只把它写清、并在界面加一句提示（§3.6）。

### 2.4 未点击题目默认按做对——明确反对（思傅第 6 问的后半）

"没点"混合三种情况：做了且对、做了错但没记、**根本没做**。默认按对会把三者全记成成功，`review_events` 正确率虚高，**唯一够格的指标当场作废**——用假数据换界面干净，不做。

替代：未点 = 未知，**不写事件**；到期题持续显示直到家长处理；挂起 N 天归入"未作答"单独状态，只提示、不算对也不算错（§3.3）。

### 2.5 0034 迁移是什么（思傅第 15 问）

数据库结构变更的执行脚本。只把**历史上已走完五档、却仍挂复习本占位**的存量题一次性移出；只改 `timeline_items` 两列（`in_review_book`、`added_to_review_at`），不删数据、不碰判定层，重复执行影响 0 行（幂等）。当前**未执行**；放行前先跑文件底部只读 `count(*)` 看影响面。

### 2.6 五档 1/3/7/14/28 的科学依据（思傅第 4 问）

诚实答案分三层，不得宣称"科学最优间隔"：

1. **间隔效应本身**：铁证。Cepeda 2006，271 组可比实验 259 组分散优于集中，d≈0.85（A 级）。
2. **"递增间隔"这个形式**：**没有优势**。Latimier 2021，扩展 vs 均匀 g=0.034，95%CI[−0.10,0.17]，p=.59，I²=0%——精确的零。
3. **1/3/7/14/28 这组数字**：20a **D 降维算子**的工程折中，不是最优解。20a 原话："必须实现的是**有排程**，而不是**有智能排程**"。三个判据：落在 K12 学期尺度、曲线峰顶平坦（大致对就够）、宁可错晚不可错早。

> 所以思傅第 11 问"多次改 2 次"——**证据不支持 5 也不支持 2**，这是"想记多久"的目标选择。拍板结果：做成家长可选、默认 5。

### 2.7 B2 导出三档的现状澄清（思傅第 9 问）

思傅判断正确：**当前项目只有两档**——「打印练习卷」（无答案）/「答疑解惑版」（含答案+解析+错因），见 `src/pages/summary/index.tsx:129,143,195`。GK-SRS-24 的"详解/提示/纯题"三档是**待办（B2）不是现状**。且"提示档"与现有两档是不同维度：现有维度是**有无答案**，三档维度是**辅助强度**——实施时要么明确两维如何合并，否则会做出四档，见 §3.5。

## 3. 要改的设计（方案，未实施）

### 3.1 暂停语义（L1）

| 项 | 方案 |
|---|---|
| 入口 | 复习本列表项 / 详情页各一个「暂停这题」，**不叫"已掌握"** |
| 数据 | 新增 `review_paused` 列（bool，默认 false）+ `review_paused_at`；暂停时 `in_review_book=false`、`paused=true`，**保留** `review_count` / `next_review_at`（恢复后从原档位继续，不白费） |
| 恢复 | 复习本顶部「查看已暂停（N）」→ 一键恢复（`paused=false`、`in_review_book=true`、按保留的 `next_review_at` 继续到期） |
| 与毕业区分 | 毕业是 `review_count>=N && paused=false`；暂停是 `paused=true && review_count<N`。二者都 `in_review_book=false`，**恢复只对暂停开放**（毕业态不提供"恢复"，要重新加入走既有路径） |
| 埋点 | 暂停/恢复**不写 `review_events`**（不是作答，不进任何正确率分母） |
| falsifier | 若暂停后恢复，出现"复习次数归零"或"档位倒退" ⇒ 违反"不白费"约定，回滚 |

### 3.2 毕业档数家长可选（L2）

### 3.3 未点题挂起提示（L1）

- 到期题若 N 天仍未被点（建议 N=7，与最大常用间隔同量级；实施时确认），标记为"挂起"，在复习本横幅显示"N 题挂起超过 7 天"。
- **不写 `review_events`、不算对、不算错**；只提示家长"这题排了但没记录结果"，请他补点或暂停。
- 与 B0 的关系：挂起数本身是采纳层信号（F 层），**不得进入效果结论**。
- falsifier：若挂起题被自动推进档位或写进正确率分母 ⇒ 违反，回滚。

### 3.4 错因四选一录入（L1，即原 B1）

- 采集点：**点「做错了」之后、且只对做错的题问一次**（思傅认可）。做对不弹、跳过也能记。
- 词表：复用已有 7 类（`ocr-error.ts`）：`careless-sign` / `careless-calc` / `concept-mix` / `misread` / `method-step` / `no-answer` / `unscored`（`unknown` 为系统兜底，不作选项）。写入 `content.error_analysis`，展示位已在（详情页卡片 / 列表角标 / Word 导出），**零新增 UI 展示成本**。
- 可选追加"当时确信吗"（信心），同一次弹窗内，均可跳过。
- 文案纪律：不得写"系统识别了你的错因"——是**家长/孩子自己选的**。
- falsifier：若做对题也弹错因选择 ⇒ 打扰且污染数据，回滚。

### 3.5 B2 导出辅助强度三档（L1，待实施）

现状澄清见 §2.7。方案：

| 档 | 触发 | 内容 | 依据 |

## 4. 六栏（归因门硬结构）

### ① 判据（L1 / L2 / L3）

L1（体验是否成立）：暂停/恢复是否不丢档位、未点题是否被误记、错因是否只在做错时问、今日进度是否登录即准。
L2（到期首次作答正确率）：本提案**不产生新 L2 证据**，只保护既有指标不被假数据污染（§2.4 / §3.3 / §3.7）。档数可选（§3.2）改变口径，**须 L2 评审**。
L3（迁移）：不触及。不得宣称提高能力。

### ② 归因（不变量 / 约束 / 准则）

- I1 提取：§3.5 三档辅助强度必须保住"纯题"档的无提示提取。
- I2 修正：§3.4/§3.6 当场反馈（精细反馈 0.49 vs 只判对错 0.05）。
- I3 间隔：§2.6 诚实降维；§3.2 档数是排程参数，不是理论变更。
- 约束：M3 元认知错觉（禁自评当证据、禁连续天数）、M5 指向任务（§3.9 话术）、M6 辅助梯度（§3.5）、M11 边界窄（§3.7/§3.8 只陈述事实）、K1 个人主体 AI 不可用（§3.5 禁 AI 提示）。

### ③ 证据（20b 条目 + 级别）

- Cepeda 2006（A，839 效应，259/271）→ 间隔效应存在；Latimier 2021（A，g=.034 p=.59）→ 递增无优势；Kluger & DeNisi 1996（A，607 效应，1/3 变差）→ 话术指向任务；Dunlosky ERE（B，0.505/−0.428）→ 提示优于详解；Cerasoli 2014 → 外部奖励挤出（ρ .45→.22）。
- 行为/采纳层主张（"默认比说服有效""挂起提示不带效果承诺"）为 **B/C 混合 + 工程判断**，未达入库门槛 ⇒ 不升格新准则。

### ④ 算子（T / D / X）

- **D 降维**：五档固定间隔 ← 放弃 SM-2；档数可选 ← 放弃个体化算法；B5 跨次回看 → 当场反馈 ← 放弃"下次提醒"的复杂度。
- **T 转换**：纸面作答 + 手机登记 ← 把"提取"留给纸、"记录"给手机（降低屏幕时间）。
- **X 交换**：用"家长多一次选择（错因四选一 / 档数）"换"零 AI、零共享题库下的可用数据"。

### ⑤ falsifier

1. 暂停恢复后档位归零或倒计时重置 ⇒ §3.1 失败。
2. 未点题被写进 `review_events` 或被推进档位 ⇒ §3.3 失败，指标作废。
3. 做对题弹出错因选择 / 跳过路径卡住 ⇒ §3.4 失败。
4. 导出出现四档或提示来自 AI ⇒ §3.5 失败。
5. 界面出现连续天数/徽章/"最佳时间快来"/"科学最优间隔"/"自适应难度" ⇒ §3.7/§3.8/§2.6 失败。
6. 改档数后 `stage_after` 超出所选档数 / 三处文档未同步 ⇒ §3.2 失败，**L2 放行撤回**。

### ⑥ 验收断言（建议 M74，实施时新建）

- A1：暂停写 `paused=true` 且保留 `review_count`，恢复后档位不变。
- A2：未点题不写 `review_events`、不推进档位；挂起只提示。
- A3：错因弹窗只在 `result='wrong'` 分支，且可跳过。
