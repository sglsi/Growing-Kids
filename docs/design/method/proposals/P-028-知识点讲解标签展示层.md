## 1. 触发与目标

D-039 已把国家课标 9 科 `curriculum_topics` 维度表写入**开发库**（720 行），但 `server/src/shared/curriculum-topics.ts` 在 `server/src` 内**零引用**（D-040 复核：无路由、无服务调用、前端未消费）⇒ 当前面客价值为 0。

项目目标早已由「完全匹配」调整为「给出适配度最高的 1~3 个参考选项，讲通知识点、方法论、基本原理」。本提案要让维度表产生**最小、可验收**的面客价值：在参考例题卡片上展示「这道题可能涉及的知识点/主题」，**只做讲解标签，不参与排序、不改变候选集合、不宣称判定结论**。

🔴 **不触碰检索链路**：不并入 `TOPIC_TERMS`、不改 `sharedSignals()`、不参与 `MIN_SHARED_SIGNALS` 共现、不进入六闸。RQ2 实测词表扩大后假共现命中 ≥3 词从 2.3%→5.8%，且改 `question-reference.ts` 会破 `P-025 T4` 契约 sha 零改动口径。

### 1.1 三条实现路线（**待拍板 Q1**，成本与代价不同）

| 路线 | 做法 | 主契约 | `CACHE_VERSION` | 代价 / 风险 |
|---|---|---|---|---|
| ① 前端静态字典 | 把只读快照编译成 `constants/curriculum-topics.ts`，前端按题干字面匹配展示 | 零改动 | **不必 bump v14** | 字典随发版更新；字面匹配弱，与 RQ2 同类局限 |

### ① 判据（L1 / L2 / L3）

- **L1（事实）**：`curriculum_topics` 720 行／9 科，`domain`/`topic` 为官方可核验一级框架名（`framework_verified` true 521 / false 199），`term` 为项目自建术语（`term_origin` 恒 `project`）；`question_objects` 无知识点字段（migrations/0026、D-038 实测）；`TOPIC_TERMS` 实测 55 词。
- **L2（工程判断）**：字典与题目表解耦，标签是**呈现层提示**而非标注结论；无「对象↔知识点」映射 ⇒ 只能按字面/弱匹配给「可能涉及」，必须配事先声明；默认关、开关可控。
- **L3（不宣称）**：不宣称知识点标注准确、不宣称覆盖全库题目、不宣称提升适配度或命中率、不宣称课标条文已逐字核对、不代做法务结论、不宣称多科目已完整覆盖。

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：`question-match.ts` 一行未动；`question-reference.ts` 与 `TOPIC_TERMS` 55 词不动；`P-025 T4` 契约 sha 零漂移；判定层六闸与第二层准入锁；`strict=1`。
- **约束**：`curriculum_topics` 全局只读字典、无 `user_id`、服务端只允许 SELECT、不暴露写端点；标签不进排序、不进 `note` 判定、不进缓存键；`term` 不冒充课标条文；第三方 CC BY-NC 原创表达永不入代码/生产。
- **准则**：`20a §5.1` 三问归类＝**不新增学习行为**（只展示名词，不生成「该练什么」/学习路径/推荐，不碰 M10/M11）；`20b §5.5` 代理指标不得作成功证据；面客统一说「资料库」；若开关状态需持久化，须串行过 `guardPolicy` 与 `guardPrivacy` 两道门，隐私接口失败禁 `catch {}`。

### ④ 算子（T / D / X）

- **T（拍板后、且 T0 过后才做）**：T1 按 Q1 选定路线；T2 若路线 ② 则新增只读端点并同步 `PUBLIC_ROUTES` / 令牌 / 免登录口径；T3 前端卡片加标签区与**事先声明**（「系统根据题干字面给出的可能知识点，仅供参考，不作为判定结论」）；T4 默认关 + 开关；T5 在 D-040 固化的 `t0-blind-v1` **独立盲测样本**上做验收，调参另用物理分离样本；T6 前后对照协议 v1.0 实跑（同一份 `measure-baseline.sql` + `measure-baseline-paired.sql`）。
- **D（判定）**：D1 标签只展示、不进排序 ⇒ 判据为**候选集合与顺序前后逐条一致**（sha 比对）；D2 主检索 result 结构不变（路线 ①②）⇒ `CACHE_VERSION` 保持 v14；D3 事先声明常驻、不可关闭；D4 用户可看懂「知识点 / 方法论 / 基本原理」须**单独统计**，不拿命中率代替。
- **X（排除项）**：⛔ 向量召回／Reranker／LLM 兜底／英文锚点（判定层永久排除）／「对象↔知识点」自动打标／掌握度诊断／错题推荐／学习路径／打卡激励／把标签当正确率证据／复用 D-034 40 条样本既调参又验收／单独把 `0032` 推生产。

### ⑥ 验收断言

1. `question-match.ts` sha 与 M42 B1 基线 `84f998ff…` 一致；`question-reference.ts` sha 不变，`TOPIC_TERMS` 仍 55 词。
2. 同一批 query 在开关前后，**候选集合与顺序逐条一致**（路线 ①② 不 bump `CACHE_VERSION`，仍 v14）。
3. 标签不出现在 `note` 判定路径、不进缓存键、不参与 `MIN_SHARED_SIGNALS` 共现。
4. 事先声明常驻且不可关闭；`answer` 为空、`verified=false`、无「采纳」按钮的既有口径不变。
5. 默认关；开关状态若持久化，两道隐私门均有断言覆盖。
6. `method:check` H1/H2/H3 全绿、`verify:gate` 全绿、M43 12/12、M42 v3 不降。
7. 前后对照协议 v1.0 七条纪律 + falsifier 逐条过；配对差分用 `measure-baseline-paired.sql` 同层相减。
8. 验收只在 `t0-blind-v1`（200 条）上做；**不计算召回率/准确率**，结果指标仍以 `0021 review_events` 到期首次作答正确率（每档 ≥30 样本）为唯一够格项，当前 0 行。
