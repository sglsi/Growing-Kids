## 0. 一句话，以及一次必须说清的证伪

**真实题拿不到 `exact` 的主因不是「整页没切题」，而是「库里没有这道原题 / 有也是同字母不同题 / OCR 字面与库内原文对不上」；单独做切题既提不了命中，还会放出一个 `ask=unknown` 的假 `exact`。**

`D-016 裁决记录` 给的方向依据是「完整 375 字库内原题 `exact=2`、截断 320 字 `ask=conflict`」，以此推断「题干完整性是瓶颈」。本轮把推断放到**真实录入题**上直接验证，结论不成立：

| 当时的推断 | 本轮实测（8 条真实题，只读） |
|---|---|
| 切题能让设问一致、从而 `exact` 上升 | 规则切题后 **8 条里仍 7 条 `exact=0`**；`rejectReason` 从「设问冲突」变成「锚点共现不足」或仍是「设问冲突」 |
| 题干质量是第一瓶颈 | 干净的 103 字几何单题（无错字、无连排）**仍 `exact=0`**，L3 查 `stem_text like '%EFC=60%'` = **0 行**、`text_flat ilike '%EFC=60%'` = **0 行** ⇒ **库里根本没有这道原题** |
| 修好上游就有答案 | 至少 4 条真实题的判别性字面串在 `question_objects` / `text_flat` **均为 0 命中**（`ME+EC+CF+MF` / `AC+BC=4` / `heatwave` / `EFC=60`）；`BMDN` 虽有 4 行，但库内是「等邻边四边形…周长最小值」，用户问「面积最大值」（`BMDN`＋`最大值` = **0 行**）⇒ **同字母不同题** |

⚠️ **这不推翻 D-016 的裁决**（P-013 已否决、收益撤回、代码保留，历史文本原样保留），只是把「下一步方向」的**证据基础**补完整：切题/OCR 是真实存在的质量问题，但它**不是**当前 `exact=0` 的充分原因。按 `OPS-22 §3.4`，把 falsifier 前置到拍板之前，避免再走一轮「改完没收益」。

### 1.3 🔴 那个 `exact=1` 是什么（必须留痕）

Query `文中不得提及真实的人名，校名等相关值息。`（20 字、无设问）⇒ 命中 `Unit 7-Unit 8【跟踪训练】-2023年中考英语一轮大单元复习过过过（人教版）（解析版）.docx` 第 80 对象：

```
anchorHit=4 / anchorTotal=5 (ratio 0.8)、requiredRatio=0.55
askQuestion=unknown / askStem=unknown / askMatch=unknown
adjacentSolution=true / solutionChars=972 / solutionCrossesBoundary=false
sourceLocation: objectIndex=80, charStart=19089..20900
```

即：**短文本 + 设问未知 + 锚点共现 0.8 + 相邻解析段** ⇒ 六条硬闸按现设计放行 `exact`。L3 查 `qo_不得提及真实的人名 = 2` ⇒ 库里确有这句，但它属于**作文题的写作要求**，用户录入的也是要求而非题目；给出去的 972 字「解析」是别人的范文/训练内容。这正是 `D-012 §8.5` 登记的「题干 A＋别人解析」残余风险路径，也是 `strict=1` 与第二层上线准入仍锁的理由。⇒ **切题若不加准入闸门，会把这条本来 `topic` 安全兜住的输入推成 `exact` 并放解析**。

## 3. 六栏

### ① 判据（L1 / L2 / L3）

**保护性归因：L1 延迟——不新增学习行为，只保护「到期复习时拿到的答案确实是这道题的答案」这一前提不被「拿整页/作文要求去撞库」破坏。** 与 P-012/P-013 ① 同口径。不改善 L1/L2/L3 任一条效果量；修的是**输入合格性**而非候选可得性。若评审认为该归因不足，按 P-012 同样写法当作「不涉及判据的检索正确性工程」，直接走 ⑥ 显式不宣称。

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：无。I1 提取 / I2 修正 / I3 间隔均不涉及「哪段文本送去检索」。
- **约束**：**C-正确性**（不合格输入 ⇒ 不该产出 `exact` 与解析）；**C-资源**（不增加深挖份数、不新增逐题多次检索，4 核 4G 不额外承压）。
- **准则**：`GK-SRS-20a M10`（宣称不得超出能力：库里没有的题不能说「找到」）、`M11`（如实告知不是拦截：说明「请单独录入小题」而非静默换题）、`M8`（不碰间隔表与结果指标）。
- **外部合规**：《双减意见》§15 ⇒ `exact` 才放解析、`topic` 答案必须为 `''`；本提案不改答案呈现形态，不构成拍照搜题。
- **性能**：保持 P95 < 3s；**不新增逐候选串行检索**（整页 55 个题号若逐题检索必然超时）。
- **既有边界（D-014/D-015/D-016 延续）**：判定层六条硬闸一行不动、举证责任仍是「未达标不放行」、`strict=1` 继续锁、`NETDISK_TEXT_RECALL=0` / `NETDISK_ONLINE_EXTRACT=1` 双回退保留、`CACHE_VERSION v9` 不因本轮无故 bump（除非结果内容真的变化）。

### ③ 证据（20b 条目 + 级别）

**20b 无对应条目**——输入合格性与 SQL 粗筛不是学习干预，无效应量可引。三问决策器（20a §5.1）：Q1 量级不适用（非学习效应）、Q2 覆盖不适用、Q3 **不可测**（M8 隔离，唯一够格指标 `0021 review_events` 当前 0 行）⇒ 按 `GK-OPS-22 §3.2` 判 **D（降维）**：只做正确性工程，**不做指标、不做宣称**。工程证据为 §1 的 8 条真实题实测 + L3 覆盖查询（内部实测，非学习证据）；样本量小，只作方向性因果证据。

### ④ 算子（T / D / X + 边界 + 不做什么）

**D 降维**：把「想让整页题目也能搜到」降维为「**先判定这次输入是不是一道合格的单题；不是就如实告知，不送判定**」；**宣称同步降级**——修完仍只说「在公共资料正文里找到 / 没找到」「请单独录入要查的小问」，不得说「都能搜到」「精准定位到题」。

**明确不做**：
- ⛔ 不放宽六条硬闸、不把 `topic` 给答案、不去掉 `source_location`、不开 `QUESTION_OBJECTS_STRICT=1`
- ⛔ 不改 `question-match.ts` 任何判定逻辑（`extractDistinctive` / `anchors` / `longAnchors` / `judge*` 全不动）
- ⛔ 不做 OCR 错字字典 / 不做自动改写用户原文（只做「选哪一段」，绝不改字符）
- ⛔ 不对整页做逐题多次检索（P95 冲突）、不改 `MAX_DEEP_FILES=8` / 8s / 18s、不启在线抽取
- ⛔ 不改 result 结构、不做自动跳题、不新增答案内容
- ⛔ 不写成「误判归零 / 所有用户已可用 / 已解决张冠李戴 / 命中提升」
- ⛔ 不把「库覆盖」「方案 B 对象级召回」「英文判定锚点」顺手做进来（各需独立提案）

### ⑤ falsifier（产品内可采集）

1. 上线后出现**任何**「非题目文本（作文要求 / 试卷抬头 / 整页）」被判 `exact` 且带解析 ⇒ 准入门失效，立即停下、回滚、登记（`OPS-22 §3.4`）。
2. 同一批 8 条真实题对照，出现新的 `exact` 但来源与题目明显不是同一道（人工抽样核对 `sourceLocation`）⇒ 同上。
3. `check:isolation` 出现任何越权、`topic` 出现非空答案、`exact` 缺 `source_location` ⇒ 违反 D-009/D-012，停下。
4. `tookMs` P95 ≥ 3s，或单次请求出现 >1 次检索调用 ⇒ 性能门破。
5. `question-match.ts` 源码 sha256 与 D-016 钉住值不同 ⇒ 判定层被动过，回滚（M35 钉住）。
6. 文案出现禁用宣称词（H2 门）⇒ 退回。
7. 若把本提案写成「提升命中 / 修复有效」⇒ 与 `D-016 裁决记录`「收益撤回」冲突，按 H1 门退回。

## 4. 边界与仍锁项
