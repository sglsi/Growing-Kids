## 1. 触发与现状（实测代码，不是推测）

- 「错题提取」＝ `src/pages/recognize/index.tsx` 的 `split` 模式（`:1483` `{ value: 'split', label: '错题提取' }`，与「拍照识别」`paper`、「导入文档」`doc` 并列）。
- 现有 `split` 主流程是**人工辅助整理**（#150）：`addBoardPages()` 选图（`:719-764`，≤9 页）→ 每页 `runPageOcr()`（`:767`，`ocrPage` 返回 `PageTextSegment[]`，每段带像素框 `box{x0,y0,x1,y1}`）→ 用户「＋裁剪题目」用 `ImageEditor(cropOnly)` 手工框选（`:2163-2175`）→ 文字/图挂到 `BoardEntry`（`:61-73`）→ `handleBoardSave()`（`:1199-1211`）→ `createTimelineBatch`。
- **已有**：题号输入框 `seqInput`（`:136`，占位「如 3,5,8-12」）、`parseSeqInput()`（`:464-477`）、`applySeqSelection()`（`:494-530`，优先按印刷题号 `question_label` 匹配）、批量分别落库、无解答时 `status='pending'`。
- **缺口**：题号只用在前端「勾选过滤」，**后端所有识别 DTO 都没有「用户给定题号列表」字段**；裁剪全靠人工逐个框选，`split` 模式没有「按题号自动给框」。
- **硬约束（本轮实测）**：`server/src/timeline/timeline.service.ts:466` 唯一强校验 `if (dto.kind === 'question' && !dto.content?.question) throw BadRequestException('题目条目缺少 content.question')` ⇒ Q2=A「文本留空、只存图片」在当前契约下会被 400 拒绝。另有 `src/pages/recognize/index.tsx:1170` 注释「2026-10-21 起允许『只裁剪、不识别』（图片题）」，说明产品意图早已承认图片题，是**校验未同步**。
- **文档出图**：`server/src/ocr/pdf-tool.ts:99-104` `PdfToolPage` 有 `image_base64`，但只在「文字少于 `min_text`」的扫描页渲染（`ocr-engine/pdf_tool.py:55`），纯文字层 PDF **没有页图**；`docx/txt` 零 LO，不出图。

## 2. 落地口径（Q1–Q5 逐条对应）

| 问 | 答复 | 实现口径 |
|---|---|---|
| Q1 | 改造现有入口 | 只在 `split` 模式加「按题号提取」区块，复用 `board`/`handleBoardSave`，不新建页面、不动 `paper`/`doc` |
| Q2 A | 只存图片 | 裁出的题目图 → `content.question_images`，解答图 → `content.answer_images`；`question`/`answer`/`solution` 保持 `''`；题干非空校验放宽为「`question` 非空 **或** `question_images` 非空」 |
| Q3 B | 候选框 + 逐题确认 | 系统按 `segments.box` 算候选框 → `ImageEditor(cropOnly, initialCrop)` 预置该框 → 用户微调后确认才裁；未确认/取消 ⇒ 该题只存题目区 |
| Q4 C | 定位不到给框确认 | 题号在段落里找不到 ⇒ 该题标「未定位」，仍弹候选框（默认全页）让用户手工框，**不入库任何系统猜测的图** |
| Q5 A | 单图 / 单份文档 | 图片直接进 `board`；PDF 走后端新增 `doc-pages` 渲染页图后进 `board`；`docx/txt` 明确提示改用 PDF 或图片（零 LO，不出图） |

## 3. 六栏

### ① 判据（L1 / L2 / L3）

- **L1（事实）**：`PageTextSegment.box` 是**页面图像素坐标**（`src/services/api.ts:1146-1154` 注释「一个段落，不是一行」，分段在后端完成）；`ocrPage` 返回的 `image_url` 是**摆正后**的图，框与图同坐标系；`ImageEditor` 裁剪框是**归一化 0~1**（`DEFAULT_CROP = {x:0,y:0,w:1,h:1}`，`image-editor.tsx:87`）。
- **L2（工程判断）**：① 段落框到归一化框必须用「摆正图宽高」换算，不能用屏幕显示尺寸；② 题号正则必须复用 `shared/question-match.ts` 的既有口径，但**只读不改成**——判定层文件一行不动，前端另写轻量定位函数；③ 解答区与题目区的分界在纯文本上**不可靠**（D-012/D-013 已用 40/40 ROC 证伪「相邻解析段归属」），因此解答区永远是**候选**，必须用户确认，且系统不因「没找到解答」而拒绝该题；④ 落库前必须有图，`question_images` 为空且 `question` 为空的条目**一律不提交**（防脏数据）。
- **L3（不宣称）**：不宣称自动定位准确率；不宣称解答区归属正确；不宣称 `docx/txt` 支持；不宣称真机手势/出图已验证；不宣称已面客或所有用户可用。

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：`server/src/shared/question-match.ts` **一行未动**（P0 六条硬闸、`MATCH_MIN_SOLUTION_CHARS=8`、`splitQuestionObjects()` 全保留）；`CACHE_VERSION` 保持 **v17**；r11 政策与两道发布门不动；`paper`/`doc` 两条既有流程与 `seqInput` 勾选语义不改变。
- **约束**：新端点全 `requireUserId()`、不进 `PUBLIC_ROUTES`；页图与裁图走 `purpose='attach'`（不建条目）；题号定位是**纯函数**，可离线执行与断言；定位不到时**不生成图、不入库**，绝不拿相邻题顶替（D-020）；候选框坐标越界一律收敛到 `[0,1]`；单次最多处理既有上限（`MAX_BOARD_PAGES=9`、`MAX_BOARD_ENTRIES=30`）。
- **准则**：同一能力只留一份实现（裁剪复用 `ImageEditor`，勾选复用 `isDraftSelected` 语义）；best-effort 分支必须打全错；用户可撤销（候选框可取消、裁剪图可删）；改动可回滚、可由静态守卫与离线实证复验。

### ③ 证据（20b 条目 + 级别）

- 代码级：`src/pages/recognize/index.tsx`（`split` 模式新增区块）、`src/lib/question-locate.ts`（新建，纯函数）、`src/components/image-editor.tsx`（`initialCrop`）、`server/src/timeline/timeline.service.ts`（校验放宽）、`server/src/ocr/*`（`doc-pages` 端点）、`src/services/api.ts`。
- 守卫级：新增 `server/scripts/verify/modules/53-recognize-seq-crop.mjs`；既有 M36（输入闸门）、M03（timeline 详情）、M12/M13/M16 不得回退。
- 实证级：新增 `dynamic-tests/run-recognize-p031.cjs`，用 TypeScript 编译器直接执行 `question-locate.ts` 真实纯函数（题号解析、区间合并、边界收敛、未定位分支），并断言编译产物特征串。

### ④ 算子（T / D / X）

- **T（移植）** 只在「交互层」：把「输入题号」这一既有能力从『勾选过滤』延伸到『框定位』，不新增学习机制。
- **D（降维）** 写在明处：解答区归属**只做启发式候选**，不做判定、不写指标、不宣称准确；`docx/txt` 不出图，显式提示改用 PDF/图片。
- **不做**：不做自动判定「这段是不是解答」（D-012/D-013 已证伪）；不做跨页自动配对答案页；不加向量/LLM 兜底；不改判定层；不新增数据库表。
- **宣称同步降级**：所有对外描述只能是「按题号给出候选裁剪框，由你确认」，不得写成「自动切题」「自动识别解答」。

### ⑤ falsifier

- 若上线后出现「用户确认率低 / 大量候选框要手工重画」：说明段落框与题号边界对不齐，产品里会先看到「定位失败」提示频繁出现、以及用户取消候选框的比例偏高——这是**段落级框不足以表达题目边界**的证据，应退回「只做手工裁剪」，不得靠调阈值硬凑。
- 若出现「裁出的图含下一题内容」：说明题目区上界取错（用了段落下沿而非下一题题号上沿），产品里会先看到同一图重复出现在两道题。
- 若「只存图片」条目在复习本显示空白：说明放宽校验放得太宽，产品里会先看到空题干卡片。

### ⑥ 验收断言

- 可执行断言：`question-locate.ts` 的纯函数在给定段落序列下，`1,3,5-6` 必须产出 4 个条目、题号顺序稳定、越界题号进 `unlocated`；`ImageEditor` 传入 `initialCrop` 后 `cropRect` 初值等于该框且被收敛到 `[0,1]`；`handleBoardSave` 对「有图无字」条目必须提交且 `question` 为空串。
- 显式**不宣称**：候选框准确率、解答区归属正确率、`docx/txt` 支持、真机回归。
