## 2. 三条不许越的线

1. **唯一取数源＝教育部官方文本**（教材〔2022〕2号 / 教材〔2025〕1号通知与附件）。`cn-math-taxonomy` 的 `cn-curriculum-standards.json` 803 条中 `verbatim=false` 646 条、逐字原文 0 条，是作者转述，属 CC BY-NC 覆盖的原创表达 ⇒ **不得作为数据源、不得复制任何表达**，仅可作结构参考。
2. **数据分层标注，不冒充课标条文**：`domain` / `topic` 为官方课标公开可核验的**一级框架名**（`framework_verified=true`）；`term` 是本项目为检索自建的**通用学科术语**（`term_origin='project'`），**不是课标条文、不是知识点官方定义**。
3. **不接入判定链路**：本轮新建独立模块 `shared/curriculum-topics.ts`，**不修改** `question-reference.ts` 的 `TOPIC_TERMS` 与 `sharedSignals()`。理由：RQ2 已实测词表扩大后假共现风险上升（命中 ≥3 词 2.3%→5.8%），且改该文件会破 `P-025 T4` 契约 sha 零改动口径、可能触发 `CACHE_VERSION` bump。接入检索链路须另立提案并过 T0。

### ① 判据（L1 / L2 / L3）

- **L1（事实）**：项目库科目清单以 `DEFAULT_SUBJECTS` 为准（10 门）；课标版本以教材〔2022〕2号 /〔2025〕1号官方通知与附件为准；`question_objects` 无知识点字段（D-038 实测）。
- **L2（工程判断）**：知识点体系与 656,898 行题目表**解耦**，落点为独立维度表；数据只进开发库，写端点不暴露；纯静态字典，无 `user_id`（不是用户数据，因此不适用「查询必带 user_id」的 RLS 替代约定，但服务端只允许 SELECT）。
- **L3（不宣称）**：不宣称课标条文已逐字核对、不宣称 2025 修订版覆盖 16 门、不宣称知识点已覆盖全库题目、不宣称提升适配度或命中率、不宣称多科目知识点可直接用于打标、不宣称可商用、不代做法务结论。

### ② 归因（不变量 / 约束 / 准则）

- **不变量**：判定层 `question-match.ts` 一行未动；`CACHE_VERSION` 保持 v14；`strict=1`；第二层准入锁；`P-025 T4` 契约 sha；M42 v3；`TOPIC_TERMS` 55 词保持；`subjects` 表结构与用户数据不变。
- **约束**：`migrations/` 为唯一真相源；migration 必须幂等（`if not exists` + `on conflict do nothing`）；第三方原创表达禁入代码/生产；生产库发货须另走完整流程。
- **准则**：`20a §5.1` 三问归类＝**不新增学习行为**（只是数据字典与检索支撑）；不触碰 M10（禁止测量 ZPD/智能水平）、M11（提醒不得成门槛）——本轮不生成任何「该练什么」的推荐或学习路径。
