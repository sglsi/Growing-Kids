# P-004 连续天数与停留时长的展示口径：可引导、禁止判定

> 提案号：P-004 ｜ 状态：待批准 ｜ 日期：2026-10-30 ｜ 关联决策：D-007 ｜ 关联缺口：无（口径澄清，不新增缺口）

### ① 判据（L1 / L2 / L3）

**L1 延迟**（保护性归因，不是新增学习行为）。

本提案不新增功能，它保护的是 L1 判据不被代理指标挤出：一旦「连续天数 / 停留时长」成为**硬性判定标准**，用户行为会向「保住指标」优化——断签前集中补录、为凑时长反复打开——而「保住连续」与「隔了 N 天还能做对」并不正交，集中补录恰恰是**集中练习**，与分散练习（0.85）反向。

### ② 归因（不变量 / 约束 / 准则）

- 不变量或约束：**C-动机**（外部压力显著时挤出内在动机）；次因 **C-元认知**（代理指标容易被当成效果证据）
- 相关准则：GK-SRS-20a M1（三需求）、M3（当次正确率是误导指标）、M7（做成过的次数，而非夸出来的信心感）
- 一句话：把代理指标升格为判定标准，注意力就从「这次提取是否成功」转移到「指标是否保住」，前者的收益被后者的保全行为替换掉。

### ③ 证据（20b 条目 + 级别）

| 条目 | 级别 | 量级 | 边界 |
|---|---|---|---|
| 文献 5（Cerasoli, Nicklin & Ford 2016） | A | 激励**显著**时，关联需求→表现的 ρ 由 **.45 降到 .22**（k = 108、N = 30,648） | 调节变量是「激励显著性」：激励不显著时该衰减不出现。样本为工作与学业混合场景 |
| 文献 4（Slemp et al. 2024） | A | N = 443,556；控制自主支持后，**胜任与关联仍解释独立变异** | 跨文化成立（Yu 2018：r = .46 不受文化调节）；三需求不可互相替代 |
| 文献 33（Kornell & Bjork 2008） | B | 交错练习客观更优（**d = 0.67**），但 **78% 的被试认为块状更有效**——即使刚看过自己的成绩 | 实验室画家风格辨认任务；说明「用户自觉有效」与「确实有效」可分离 |

### ④ 算子（T / D / X）

- 结论：**D**（展示侧）+ **X**（判定侧）。同一组数字，两种用途，结论不同——这是本提案的全部要点。
- 边界（不适用条件）：仅约束**面向家长与孩子的可见面**（文案、卡片、提醒、达成条件）。**内部异常检测不受此限**——内部用连续天数发现「录入骤降」、用停留时长发现「页面卡住」是正当用法，因为它不进入用户评价。
- 明确不做：连续 N 天解锁 / 达标 / 可获得；按停留时长判定「是否认真学习」；断签惩罚与掉签施压提醒；排行榜与段位。
- 允许做（D 的正面清单）：**事实陈述**（已连续复习 N 天 / 本次停留多久）+ **好处阐明**（隔几天再来记得更牢，依据分散练习 0.85；一次别做太多，依据合意困难与 C8 的剂量边界）。
- 若为 D，对外宣称同步降级为：只说「规律复习更容易记住」，**不得**把连续天数写成任何前置条件或达成式评价。

### ⑤ falsifier

若产品内出现下列任一现象，说明「仅展示」已在事实上产生门槛效应，应收敛展示（乃至改为不展示）：

1. 临近断点的**集中补录**（如第 6/7 天录入量显著高于其他日）；
2. 断签后 7 日内**活跃度骤降**的比例显著上升；
3. 家长侧反馈「被催促 / 被要求」的占比上升。

复核时点：2027-01 季度体检；若上述现象先于该时点出现，则触发式复核。

### ⑥ 验收断言

- 静态：本提案的口径已固化为新增准则 `GK-SRS-20a M11`（20a §6.2）。机器能守的部分是 **H2 观察词表**——「连续 N 天解锁」「达标」「可获得」一类门槛型话术进入 `WATCH`（实施 UI 时同步加入 `method-gates.mjs`）。
- 其余（展示会不会真的造成压力、文案语气是否构成施压）**只能人判**，不硬凑断言——假断言比没有断言更危险（OPS-22 §8）。
- 本期若无 UI 改动，按 OPS-22 §3.3 第三关作「**显式不宣称**」处理：不做任何「连续天数 → 学习效果」的宣称。
