# 决策台账（method decision log）

> 归口：`GK-OPS-22` §5 ｜ 版本：v1.0 ｜ 日期：2026-10-28
> 用途：凡走过三问（20a §5.1）的提案，**无论结论是 T / D / X 都记一条**。台账是「不做清单」的数据源；20b §5.3 与 SRS-01 §10 只是它的摘要版。
>
> 📌 **编号规则**：`D-NNN` 只增不改、不复用（同准则冻结）。结论推翻时新增一条 D 号并在旧条目标「已被 D-NNN 取代」。
> 📌 **为什么必须记「参照系」**：`0.3` 这个阈值是 20a 用来筛「值得做」的量级门槛，不是普适真理。不写参照系，后人会把「0.03 很小」当成结论——但 0.03 在 I² = 0% 的精确零里是**另一回事**。
> 📌 **复核时点**：到点就回来看一眼，触发 falsifier 则按 OPS-22 §3.4 处置（改实现 / 改准则 / 记录例外）。

## 0. 字段说明

| 字段 | 含义 |
|---|---|
| 结论 | **T** 移植（做成功能或硬规则）｜ **D** 降维（保留机制方向、放弃精度与宣称）｜ **X** 禁止（不做） |
| 一句话理由 | 必须含量级，让后人不必重查文献 |
| 参照系 | 这个量级相对什么比较的 |
| falsifier | 若该判断错了，会先在哪个数据上看到 |
| 复核时点 | 定期体检或触发式复核的时点 |

## 1. 台账正文

### D-001 打卡式激励（连续 N 天 / 成长值）— **X**

| 项 | 内容 |
|---|---|
| 提案 | 无（历史口头提案，2026-10-27 评审） |
| 判据 | 无（该提案改善的是「打开频次」，不对应 L1/L2/L3 任一条） |
| 归因 | C-动机（但方向为负：外部奖励挤压内在动机） |
| 一句话理由 | 奖励显著时，内在动机与表现的相关从 ρ = .45 降到 .22（Cerasoli 2016）；即激励越显性，越是在替换而不是增强动机 |
| 参照系 | 与「无外部奖励」基线的相关强度变化；不是效应量 d |
| falsifier | 若上线后「到期复习完成率」显著上升**且** 30 天再测正确率不降，则该判断需要重开 |
| 复核时点 | 2027-01 季度体检 |
| 备注 | 与 D-003 同属「用激励换留存」，一并驳回 |

### D-002 SM-2 / 自适应记忆算法排程 — **X**（改为 D：分段常数）

| 项 | 内容 |
|---|---|
| 提案 | 无（历史口头提案） |
| 判据 | L1 延迟 |
| 归因 | I3 间隔 |
| 一句话理由 | 递增间隔 vs 固定间隔是**精确的零**：g = 0.034，p = .59，I² = 0%；既然曲线峰顶平坦，成本应花在「有排程」上，而不是「排得准」 |
| 参照系 | 0.3 的「值得做」门槛；且这是 I² = 0% 的零结果，不是样本不足导致的「没测出差异」 |
| falsifier | 若分段常数排程下 30 天保持率显著低于某自适应算法，且差距 > 0.2 SD，则重开算法议题（20a M8 的 falsifier） |
| 复核时点 | 结果指标首次出数后 |
| 落地 | 已实现为五档分段常数（迁移 0019 / `timeline/review.ts`），见 D-004 的同类降维思路 |

### D-003 成长型思维独立模块 / 周报 — **X**

| 项 | 内容 |
|---|---|
| 提案 | 无（历史口头提案，2026-10-27 评审） |
| 判据 | 无（不改判据，只改信念表述） |
| 归因 | **指不回任何不变量**——它不落在 I1 提取、也不落在 I2 修正上。这是比「效应量小」更强的否决理由：不是效果弱，是因果链上不占位置 |
| 一句话理由 | 干预效应 d ≤ 0.05–0.14，2026 年英格兰 100 校 RCT 显示信念改变而成绩不动 |
| 参照系 | 与 0.3 门槛比较；且校正发表偏倚后更低 |
| falsifier | 若出现高保真实施、d > 0.2 的独立 RCT 重复，则重开该模块（20a M2 的 falsifier） |
| 复核时点 | 2027-06（等新一轮 meta 分析） |
| 保留形式 | **唯一保留形式是反馈语言指向方法而非能力**（M5 / E5），不单独成模块 |

### D-004 「算出」孩子的最近发展区 — **X**（改为 D：掌握学习替身）

| 项 | 内容 |
|---|---|
| 提案 | 无（历史口头提案） |
| 判据 | L1 延迟（想预测「下一步该学什么」） |
| 归因 | I2 修正 + C-资源 |
| 一句话理由 | ZPD 无公认测量工具，动态评估对学习成绩的预测效度 r ≈ .12–.24；用一个弱预测器去决定练习序列，错误率高于固定顺序 |
| 参照系 | 预测效度 r 的解释力（r = .2 约解释 4% 方差） |
| falsifier | 若出现新的可测量工具使 r 稳定 > .5，则 M10 的前提（不可测）不再成立，重开 |
| 复核时点 | 触发式（20a §8.2 第 6 条：出现新的可测量工具） |
| 替代 | 做**掌握学习**（达到标准才放行）这一可操作替身，0.52 SD；不对外宣称任何「测出 ZPD」 |

### D-005 无限题库 / 题海模式 — **X**

| 项 | 内容 |
|---|---|
| 提案 | 无（历史口头提案） |
| 判据 | 无（增量练不等于迁移） |
| 归因 | I1 提取（但越过了合意困难的边界：过量集中退化为集中练习） |
| 一句话理由 | 间隔练习的收益来自节奏而非总量；且外部目标显著会削弱内在动机（与 D-001 同一机制） |
| 参照系 | 与「同等总量、分散到多天」的比较 |
| falsifier | 若「题海组」在延迟再测上优于「分散组」，则 M9 / 稀疏练习的判断失效 |
| 复核时点 | 2027-01 季度体检 |
| 替代 | 单次练习量显性上限 + 「本次建议 N 题」提示（C8） |

### D-006 错因分类（C3）— **T**（待批准）

| 项 | 内容 |
|---|---|
| 提案 | `P-003`（`docs/design/method/proposals/P-003-C3-错因分类.md`） |
| 判据 | **L3 迁移**（错因 → 同类题 → 换情境仍能做对）；兼 L1 延迟 |
| 归因 | I2 修正；准则 M4（含推理分析的纠正性反馈）、M5（反馈指向任务）；为 M9 交错提供维度 |
| 一句话理由 | 精细反馈 d ≈ 0.49，且「指向任务」是硬条件（指向自我的反馈 > 1/3 变差，Kluger & DeNisi 1996）；错因是生成同类题的**唯一可控维度** |
| 参照系 | 0.3 门槛；与「只给正确答案」（无解析）的比较 |
| 边界 | 小学书面作业、家长代为标注场景；**不做**自动推断错因（模型猜错因无证据支持，且错标会污染后续同类题） |
| falsifier | 上线 8 周后，打标题的 30 天再测正确率与未打标题无差异（内部纵向比较）⇒ 错因维度只是记录负担，回退 |
| 复核时点 | 上线后第 8 周 |
| 状态 | **待批准**：受控词表的具体项数与是否允许「不确定」项待定 |

### D-007 连续天数 / 停留时长：作为硬性判定 — **X**；作为引导性展示 — **D**

| 项 | 内容 |
|---|---|
| 提案 | `P-004` |
| 判据 | L1 延迟（**保护性归因**：防代理指标挤出延迟判据，本身不新增学习行为） |
| 归因 | C-动机（挤出效应）+ C-元认知（代理指标被误当效果）；相关准则 M1 / M3 / M7 |
| 一句话理由 | 激励**显著**时关联需求→表现 ρ 由 **.45 降到 .22**（Cerasoli 2016，k = 108 / N = 30,648）；且 78% 的人会误判哪种练习更有效（Kornell & Bjork 2008）⇒ 把连续天数做成判定，是在**替换**动机而不是增强动机 |
| 参照系 | ρ 由 .45 降到 .22 是相对「激励不显著」基线的相关强度变化；**不是 d**，不可与 0.3 门槛直接比较 |
| 与 D-001 的关系 | **不是推翻，是补边界**。D-001 否决的是「打卡式激励（连续 N 天 / 成长值）」这一**功能**；本条处理的是「同一组数字能不能展示、能不能当门槛」——结论：**展示可（D）、判定禁（X）** |
| falsifier | ①临近断点集中补录；②断签后 7 日活跃骤降比例上升；③家长反馈「被催促」占比上升。任一出现即收敛展示 |
| 复核时点 | 2027-01 季度体检（触发式：上述任一现象先出现即复核） |
| 边界 | 只约束**用户可见面**；内部异常检测（录入骤降、页面卡住）不受限 |
| 保留形式 | 允许「已连续复习 N 天」的事实陈述 + 「隔几天再来记得更牢」的好处阐明；禁止门槛、解锁、断签惩罚、排行榜 |
