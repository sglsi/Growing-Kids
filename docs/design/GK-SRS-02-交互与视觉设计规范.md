## 1. 文档目的与适用范围

**要写**：本文约束所有页面与组件的交互与视觉实现；新增页面/组件必须符合本文；与本文冲突的实现视为缺陷。说明与 `design_guidelines.md` 的关系（后者并入本文后标注"已并入"）。

### 1.1 设计前提：主要用户是家长（2026-10-24 定稿，上游 SRS-01 第 2 章）

本文所有交互与视觉取舍，均以「**家长在碎片时间里用手机单手操作**」为第一前提：

| 前提 | 落到规范上的硬约束 |
| --- | --- |
| 家长是整理者与督导者，孩子只做「做—订正—巩固」 | 录入链路步数最少（拍 → 裁剪 → 入题，尽量不打字）；孩子侧界面克制、不打扰、单次题量可承受 |
| 碎片时间、单手、常被打断 | 关键操作一步可达；写操作后必须保持滚动位置（不得跳回列表顶部）；支持随时中断后继续 |
| 家长要「能打印、能改」 | 导出物同时提供 PDF（拼页省纸，直接打印）与 Word（可编辑、加批注后再打印）——同一入口、用户选格式 |
| 家长也要看得清、看得久 | 视觉基线遵循「纸墨朱」令牌体系（见第 9 章与附录 C）：正文对比度 ≥ 4.5:1、字号下限 12px、触控目标 ≥ 44px |

> 📌 反例：任何"为了视觉精致而增加操作步骤""把关键入口藏进二级菜单"的改动，都违背本文前提，评审时应直接驳回。

## 2. 信息架构

**要写**：
- TabBar 构成（5 个 Tab 的名称、图标、对应页面）【待确认：逐 Tab 确认】；
- 页面树（10 个页面 + 层级关系 + 入口）；

- 页面参数约定（id 传递、来源标记）。
**素材**：`src/pages/`、`src/app.config.ts`（TabBar 配置）

## 3. 导航与返回

**要写**：
- 返回必须回到**原位置**（列表滚动锚点 + 条目定位），不得回到顶部；
- 详情页返回列表的锚回实现约定（`restoreItemIdRef` 之类的机制）；
- 物理返回键 / 左上角返回的行为一致；
- 弹层的关闭方式（遮罩点击、关闭按钮、返回键）。
**素材**：DD-08 第 9 章（列表滚动位置保持）、思傅历次"跳到第 1 题"反馈

## 4. 列表页交互

**要写**：
- 选择态：进入方式（长按 / 批量按钮）、底部批量操作条、退出方式；
- 单条「…」菜单：各列表页菜单项**保持一致**（图片 AI 动作 / 编辑 / 修改分类 / 加入或移出复习本 / 删除）；
- 筛选与搜索：控件位置、触发时机、与后端筛选的关系；
- 分页：触底加载、loading 态、无更多；
- **写操作静默刷新**：操作后不得显示骨架屏、不得重置滚动位置。
**素材**：`src/pages/index|subject|library|memory|document`、`filter-header.tsx`、`selection-bar.tsx`

## 5. 图片交互规则

**要写**（思傅明确规则，务必写死）：
- 点图片 = 打开并可编辑；点列表其它区域 = 进详情；
- 编辑结果**原位替换**，绝不新建条目；
- 图片可删除（详情页题面图 / 答案图 / 图片条目）；
- 预览大图、多图切换；
- 上传附件的语义（附件用 attach，不用 save，避免重复建条目）——指向 DD-12。
**素材**：`src/pages/detail/index.tsx`、`image-editor.tsx`

## 6. 弹层与层级

**要写**：
- z-index 分层表：页面内容 / 固定头部 / 悬浮保存条（100）/ 弹层与遮罩（200）；
- 统一规则：**任何 fixed 浮层必须 > 100**，否则会被保存条盖住（历史事故）；
- 弹层类型与用法：底部抽屉、居中对话框、全屏编辑器、Toast；
- 多弹层叠加的关闭顺序。
**素材**：`detail/index.tsx`、`material-picker.tsx`、`answer-sheet.tsx`

## 7. 表单与编辑

**要写**：
- 编辑态与展示态切换（点「编辑」进入，「完成」退出）；
- 数学输入：符号栏四页签（常用符号 / 希腊字母 / 公式模板 / 常用序号）、网格排列三行限高可滑动、插入位置跟随光标；
- **编辑态绝不显示 LaTeX 源码**，一律可读形式（如 `1/2`、`√3`、`x²`）；
- 公式渲染态与源码态切换；
- 保存语义（局部合并，未传字段不清空）。
**素材**：`math-symbol-bar.tsx`、`src/utils/latex.ts`、`math-text.tsx`

## 8. 反馈机制

**要写**：
- Toast：成功/失败文案规范（明确动作结果，如"已移出复习本"）；
- Loading：全屏遮罩 vs 局部按钮态的选择；
- 骨架屏：仅首屏与筛选切换使用，**写操作后禁用**；
- 空态：空卡片文案与引导动作；
- 错误态：可重试的显式入口；
- 超时与降级提示（如配额上限、识别失败）。
**素材**：`src/components/ui/`、各页 toast 文案汇总

## 9. 视觉基线

**要写**（给出具体数值，不写"合适即可"）：
- 主色 `#BE3E2D` 及使用场景；辅助色、语义色（成功/警告/错误）；
- 字体层级与**字号下限 12px**（所有可点击功能键不低于此值；装饰性角标/提示语除外）；
- 圆角、间距栅格、边框色；
- 按钮/芯片的高度与内边距（保证 12px 字号下不溢出换行）；
- 列表卡片结构（标题、摘要、图片区、操作区）。
**素材**：`design_guidelines.md`、思傅"字号统一""字符太小"反馈
**待确认**：是否需要暗色模式适配。

## 10. 平台差异与已知限制

**要写**：

- iOS / 安卓差异（滚动、图片、字体渲染）；
- 真机与模拟器差异（域名校验、UA、超时）。
**素材**：DD-08 第 12 章（平台坑位清单）
