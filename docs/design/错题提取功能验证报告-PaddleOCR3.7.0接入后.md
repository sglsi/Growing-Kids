## 4. 已知问题与遗留风险

### 4.1 归属偏移（Ⅰ.4 类）
组横跨相邻单元边界时按组心归属，手写答案位置低于印刷题行时会错判给下一题。修正方向：归属时引入组顶边/重叠度加权，或按"答案域"（题行尾部的空白填写区）归属。**本轮未改**（权重微调会波及作业域主战场，需单独 A/B）。

### 4.2 完形行单元缺失（选词 9-14 类）
3.x PP-StructureV3 将完形填空行合并为长行，题号不在行首导致编号入口检测不到。修正方向：对超长 region 按"数字+标点"行内二次切分。**本轮未改**（涉及 wrongq-segment 分段逻辑，风险面大）。

### 4.3 item 文本质量
34 条 item 的题干/原错答字段 OCR 噪声大（红笔覆盖印刷体 + 学生手写混排），订正/答案字段多为空；item 判错本身可靠（34/34 wrong），文本补全依赖后续 VLM 语义层（探针未充分启用）。裁图完整性（目验可读）是当前主口径。

### 4.4 潜在漏报待精核
- p1 题 1/2/4 的红斜线未框选（上轮目验发现，本轮块集已变需复核）；
- 各页标注图中存在疑似未圈红笔（如 p4 顶部个别条目），需逐页精核；
- p4 重点单词空间 `dup=[2..15]`（底部双栏交错重号）待确认良性。

### 7.4 平台限制与已知取舍

- **微信小程序读不到系统剪贴板中的图片**（只能粘贴文字进输入框）：「粘贴手截错题图」按用户决策落为**页内裁剪**（在页面图上拖框裁剪 → 上传 → 入题），复用既有裁剪编辑器；文字回路为 OCR 栏「复制」→ 题目文本框长按粘贴。
- **展示与裁剪基准**：OCR 跑在摆正后的图上，前端展示/裁剪也用摆正后 URL（与 extract-wrong 的 question_url 同口径），保证「看到的」与「识别的」同一张图。
- **保存到最近题目**：本期未做（用户需求仅要求导出 Word）；自动识别代码保留未删，后期检测达标后可恢复入口。
- 粘贴栏条目目前为「文本 + 图片组」的轻结构；若后续要按「题干/学生作答/正确答案」结构化，可在现有导出接口上扩展字段。
