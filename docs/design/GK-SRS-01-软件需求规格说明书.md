## 5. 功能需求详述

> 每个模块统一用四段式：**功能点表 → 关键流程 → 异常与边界 → 验收标准**。
> 功能点表列：编号 / 功能点 / 说明 / 优先级 / 状态。

### 5.1 首页收件箱
**要写**：最近题目列表、学科与时间筛选、批量选择（加入复习本 / 删除）、单条「…」菜单（加入或移出复习本、修改分类、图片编辑与 AI 动作、删除）、包版本角标、缓存与刷新表现。
**素材**：`src/pages/index/index.tsx`、`question-card.tsx`、DD-08 第 4 章（页面清单）
**边界要写清**：写操作后必须保持当前滚动位置（思傅三次反馈点）；筛选走后端而非前端过滤。

### 5.2 学科与复习本
**要写**：分类筛选、时间范围（自动/自定义）、关键词检索、批量操作（合成 PDF / 移出复习本 / 删除）、单条「…」菜单（图片 AI 动作、编辑、修改分类、移出、删除）、填答案、分页加载。
**素材**：`src/pages/subject/index.tsx`、`review-item-card.tsx`、`docs/复习本多图拼页-实现说明.md`
**边界**：未分类哨兵 `subject_id='none'` 的显示口径。

### 5.3 题目详情
**要写**：题干/答案/解题过程的可读化编辑（数学符号输入、公式预览与源码切换）、题面图与答案图（预览 / 编辑 / 识别入题干 / 删除）、图片条目（kind=image）的编辑与删除、答案服务三按钮入口、资料库引用、保存与合并语义。
**素材**：`src/pages/detail/index.tsx`、`math-symbol-bar.tsx`、`src/utils/latex.ts`
**边界**：编辑态绝不显示 LaTeX 源码；题目允许"只有图没有题干"（title 兜底「图片题目」）；删除图片只解引用不删文件。

### 5.4 错题提取（拍照录入）
**要写**：拍照/选图、多来源页管理（添加/重识别/删除/排序）、OCR 识别与文本分段、条目级切分、裁剪为图片题目、批量入题与去重。
**素材**：`src/pages/recognize/index.tsx`、`wrongq-ocr-panel.tsx`、DD-14
**边界**：只裁剪不识别的场景（存图不存字）；识别失败重试。

### 5.5 题目答案服务（三模式）
**要写**：三个按钮的**严格边界**——
- 联网搜题：只检索，不喂 AI，无结果如实说明；
- 知识库：ima 知识库检索，只检索不推理；
- AI 解题：只推理，结果标注未经联网核实。
以及结果展示（来源徽标、引用链接、答案渲染态）、失败与配额提示文案。
**素材**：`题目答案功能-设计方案.md` 第七章、`server/src/answer-search/`、`src/components/answer-editor.tsx`
**边界**：三种模式结果缓存必须隔离（key 带 mode）。

### 5.6 资料库
**要写**：文档导入（聊天文件选择）、中文文件名正确展示、检索与筛选、打开（走后端代理）、删除与批量删除。
**素材**：`src/pages/library/index.tsx`、`server/src/library/`
**边界**：手机访问对象存储必须走代理，直连会 60s 超时。

### 5.7 成长记忆
**要写**：记录创建、分类、关键词检索、媒体（图片）关联、删除与批量删除。
**素材**：`src/pages/memory/index.tsx`、`docs/design/成长记忆-设计方案.md`

### 5.8 文档导出
**要写**：按条件组卷（学科/时间范围/选中项）、PDF 与 DOCX 生成、导出记录列表、打开与下载（代理）、删除。
**素材**：`src/pages/document/index.tsx`、`server/src/document/`、`server/src/pdf/`
**边界**：mime_type 长度限制（历史上导致导出记录入库静默失败）；大文件超时兜底复制链接。

### 5.9 账户与登录
**要写**：微信登录、扫码登录（票据一次性）、匿名降级、身份切换后缓存清理、登出、账户信息展示。
**素材**：`src/pages/profile/`、`src/pages/scan-login/`、`server/src/auth/`
**边界**：登录失败不得阻塞使用（降级为匿名）。

## 附录 A · 术语表（全项目口径基准 · 已填）

> 本表是**唯一口径基准**：所有 GK 文档、代码注释、UI 文案、commit message 均以此为准。
> 新增术语先在此登记再使用。标 ⛔ 的是**禁用说法**——历史文档里出现过，见到即订正。

### A.1 产品与页面

| 标准术语 | 英文/代码 | 含义 | ⛔ 禁用说法 |
|---|---|---|---|
| 首页 | `pages/index` | 应用首个 Tab，展示最近录入的条目 | 主页、首页列表 |
| 收件箱 | inbox / `timeline_items` | 所有录入内容的统一容器（含题目、图片、随手记） | ⛔ 错题库、⛔ 时间线、⛔ 流水 |
| 复习本 | review book / `in_review_book` | 用户从收件箱挑出、需要反复复习的条目集合；页面在 `pages/subject` | ⛔ 收藏夹、⛔ 错题本（与"收件箱"易混，只在口语指代产品整体时用） |
| 资料库 | `library_docs` | 用户导入的教辅/文档资料（PDF/Word 等） | ⛔ 文件库、⛔ 云盘 |
| 成长记忆 | `memories` + `memory_media` | 按时间轴记录的学习成长点滴 | ⛔ 日记 |
| 文档（导出件） | `documents` | 由条目合成的 PDF/Word 导出物及其记录 | ⛔ 导出记录（口语可用，正式文档用"文档"） |
| 学科 | `subjects` | 条目的分类（数学/语文…）；未分类 = `subject_id IS NULL` | ⛔ 科目 |

### A.2 条目与内容

| 标准术语 | 英文/代码 | 含义 |
|---|---|---|
| 条目 | item / `timeline_items` 一行 | 收件箱/复习本中的一条记录，是系统的一等公民 |
| 题目条目 | `kind='question'` | 有题干、可选答案/解析的条目 |
| 图片条目 | `kind='image'` | 条目本身就是一张图（图即条目） |
| 题面图 | `content.question_images` | 题目的题干配图（file_key 数组） |
| 答案图 | `content.answer_images` | 题目的答案/答题卡配图 |
| 未分类 | `subject_id IS NULL` | 尚未归类的条目；UI 上是一个可筛选的虚拟分类 |
| 标签 | `tags` | 条目标签（筛选维度之一） |

### A.3 文件与存储

| 标准术语 | 英文/代码 | 含义 |
|---|---|---|
| file_key | `blob_objects.file_key` | 对象在存储中的唯一键。**一律写 `file_key`，不翻译** |
| 对象记录 | `blob_objects` 一行 | 物理文件与其引用计数；非业务条目 |
| 引用计数 | `ref_count` | 对象被多少处引用；归零即"孤儿" |
| 孤儿对象 | orphan | `ref_count = 0` 的对象，由定时 GC 回收（临时对象 24h） |
| 签名 URL | signed URL | 后端为私有对象生成的临时访问 URL（有有效期） |
| 上传意图 | `purpose` | `/api/upload` 的分流参数，见下方 A.3.1 |
| 访问代理 | `GET /api/storage/files/{file_key}` | 手机端访问文件的统一代理通道（跨境段由服务端承担） |

#### A.3.1 上传意图（purpose）语义表

| purpose | 存储位置 | 是否建业务条目 | 典型用途 |
|---|---|---|---|
| `save` / `1` / `true` | 正式区（引用计数 +1） | **建**（图片→图片条目；文档→资料库条目） | 「存进收件箱」「导入资料库」 |
| `temp` | 临时区（`ref_count=0`） | 不建 | 24h 后 GC 回收的中间产物 |
| `memory` | 正式区 | 不建（由 `memory_media` 关联） | 成长记忆附图 |
| `attach`（及其他未知值） | 正式区 | **不建** | 附件（如题目的题面图，key 由条目 `content` 引用） |

> ⚠️ **"要持久化" ≠ "用 save"**：附件必须用 `attach`。用 `save` 会额外建一条条目，导致同一内容在首页出现两行。

### A.4 图像与 OCR

| 标准术语 | 英文/代码 | 含义 |
|---|---|---|
| 自动调正 | `auto` | 几何纠偏（透视/旋转裁边），非 AI 重绘 |
| 智能高清 | `enhance` | 超分（SR）+ 增强 |
| 超分 | SR | Super-Resolution，真超分模型（x3/x4/ESPCN） |
| 去手写 | `erase` | 擦除画面上的手写笔迹（v21.8 词级三态判别） |
| 擦除 | erase | 同上；"去手写"是 UI 文案，"擦除"是算法文档用语 |
| 快识 / 精识 | OCR 双模式 | 快速模式（RapidOCR 常驻进程）/ 精准模式（PP-StructureV3 侧车） |
| 侧车 | sidecar | 随主服务启停的 Python 子进程/服务（OCR 用） |
| 来源页 | source page | 错题提取中拍摄/导入的原始整页图 |
| 条目级切分 | — | 从一页里切出多道独立题目的过程 |
| 红笔判错 | — | 用红笔标记识别"做错的题" |

### A.5 身份与配额

| 标准术语 | 英文/代码 | 含义 |
|---|---|---|
| 临时用户 | `is_anonymous = true` | 未登录也可用，数据按设备身份隔离，有清理策略 |
| 微信用户 | — | 经 `wx.login` + 后端 `code2session` 建立账号，可跨设备 |
| 配额 | `user_quota` | 按用户统计的高成本资源用量（OCR/超分/AI 调用等） |

### A.6 缓存与交互

| 标准术语 | 英文/代码 | 含义 |
|---|---|---|
| 静默刷新 | silent refresh | 写操作后后台重载、不显示骨架屏，以保持滚动位置 |
| 失效收口 | `invalidateAfter` | 写接口成功后统一清除相关缓存域 |
| 缓存域 | `tl` / `subj` / `lib` / `doc` / `mem` | 前端按域缓存与失效，key 带 userId 隔离 |
| 原位替换 | — | 编辑图片后**替换原条目的 file_key**，不新建条目 |
