## 1. 产品简介

**成长学童**是给家长用的错题管理工具：把孩子作业和考试里的错题拍下来存好，按学科整理，到周末或考前导出成能打印的练习，让孩子重做一遍。

三个核心好处：

1. **收得快**：拍一张照片，几步就变成一条错题，基本不用打字；
2. **找得到**：按学科、标签、时间一筛就出来；
3. **能打印**：一键合成 PDF（省纸）或 Word（可自己加批注）。

> 孩子不需要自己录入。你负责收集和整理，孩子只负责「再做一遍 → 订正 → 巩固」。

## 2. 快速上手

**首次打开**：微信里打开小程序即可使用。建议到「我的」页点「微信登录」——登录后换手机数据还在；不登录也能用，但数据只留在这台手机上（30 天内有效）。

**底部五个 Tab**：

| Tab | 管什么 |
|---|---|
| 首页 | 最近录入的内容，可筛选、批量操作 |
| 复习本 | 你挑出来准备反复练的题 |
| 文档 | 生成练习、查看已导出的成品 |
| 记忆 | 记录孩子的学习点滴（图文音视频） |
| 我的 | 登录、容量与统计、资料库入口 |

**三分钟完成第一次录入**：拍照 → 裁剪成一道题 →（可跳过识别）→ 保存。就这么三步。

---

## 3. 录入错题

**方式一：拍整页再切题（作业多时最快）**

进「识别导入」→ 拍下整页 → 系统自动框出错题 → 拖动/缩放调整框 → 逐题识别 → 勾选后批量存入。

**方式二：直接裁剪一道题**

首页点图片 → 用编辑器裁出题目 → 保存。题目少时用这个最快。

**方式三：只存图不识字**

识别不准时完全可以跳过识别，直接保存图片。图片题同样能复习、能打印。

**其它**：

- 可以一次拍多页，逐页添加后再统一处理；
- 识别不准可以「重新识别」，也可以手动改文字；
- 从微信聊天记录里选文件（教辅、试卷）可存进资料库（见第 8 章）。

**小技巧**：纸摆正、光线均匀，识别更准；拍歪了用「自动调正」修一下。

## 4. 整理与归类

| 想做的事 | 怎么做 |
|---|---|
| 归到学科 | 详情页「修改分类」→ 选学科。还没归类的显示在「未分类」 |
| 打标签 | 详情页加标签（如「一元二次方程」「几何辅助线」），考前按标签一筛就是专项练习 |
| 挑进复习本 | 列表长按或点「批量」→ 勾选 →「加入复习本」 |
| 批量删除 | 批量模式下勾选 → 删除 |
| 找某道题 | 列表顶部按学科 + 时间范围 + 关键词筛选 |

---

## 5. 查看与编辑题目

- **点卡片**（图片以外的区域）进详情：看题干、答案、解题过程；
- **点图片**进编辑：裁剪、旋转、自动调正、智能高清、去手写；编辑后**替换原图**，不会多出重复记录；
- **填答案**：详情页或列表底部面板直接填，可用数学符号栏输入 ½、√3、x² 这类符号（不用记公式写法）；
- 题目允许「只有图没有题干」，识别不出文字也先存下来。

---

## 6. 获取答案与讲解

详情页三个按钮，**来源各自清楚**：

| 按钮 | 给你什么 | 什么时候用 |
|---|---|---|
| 联网搜题 | 网上的相关题目与解析链接（自行核对） | 想看别人怎么解、想看原文 |
| 知识库 | 已收录教辅里的资料片段 | 资料库里有对应教辅时 |
| AI 解题 | 模型推导的答案与步骤（**未经联网核实**） | 前两种都没有时参考 |

- 结果**不会自动写进题目**，确认后点「采纳」才保存；
- 同一道题再查会直接给出上次结果（更快，也不浪费次数）；
- 提示「今日次数已达上限」表示当天用量用完，第二天恢复，可换另一种方式。

## 7. 复习与导出

**复习**：进「复习本」→ 按学科/时间筛选 → 挑题练 → 做完后在详情页点「已复习」。

**导出打印**：

1. 在复习本或首页勾选要练的题；
2. 点「合成 PDF/WORD」→ 选格式：
   - **PDF**：多图智能拼页，省纸，直接打印；
   - **Word**：图片顺序排列，可在电脑上加批注后再打印；
3. 成品自动存到「文档」页，随时打开或删除。

**另一种导出**：「文档」页 → 生成 → 按学科和时间范围组卷 → 直接导出 Word。

---

## 8. 资料库与成长记忆

**资料库**：把教辅、试卷、讲解文档（PDF/Word/图片）存进来，可归到学科、改名、检索，手机上直接打开看。

**成长记忆**：记录孩子的学习点滴（文字 + 图片/音频/视频），按分类与时间轴回看，和错题分开存放。

## 9. 账户与数据

| 问题 | 说明 |
|---|---|
| 不登录能用吗 | 能。数据存在这台手机，30 天内有效；建议登录后长期保留 |
| 换手机怎么办 | 微信登录后数据跟着账号走 |
| 容量 | 游客 20MB / 登录后 500MB（以页面显示为准）；满了会提示，删掉不用的即可 |
| 删除后会怎样 | 条目被删除，占用的空间自动释放；**已导出到手机的文件不受影响** |
| 登出 | 「我的」页点登出，本机缓存一并清空（不会删掉已存数据） |
| 共享 | 本期不支持多人共享，一人一库 |

## 10. 常见问题（FAQ）

| 现象 | 原因 / 怎么办 |
|---|---|
| 识别不出文字 | 可以「只存图」；或重拍更清晰、更正的照片，用「自动调正」后再识别 |
| 打开文档慢或打不开 | 手机是通过我们的服务打开文档的；检查网络，仍不行可复制链接到浏览器打开 |
| 同一道题出现两行 | 一般是重复导入，删掉多余的一条 |
| 合成后图片显示不出来 | 先在图片编辑里重新保存一次再合成 |
| 提示「次数已达上限」 | 当天搜题/知识库用量用完，第二天恢复，或换另一种方式 |
| 提示「存储空间已满」 | 删除不用的图片或文档后重试 |
| 换手机后数据不见了 | 之前没登录（游客数据只在本机）；以后先登录再用 |
| 请求失败或一直转圈 | 服务可能在启动，系统会自动重试一次；持续失败请检查网络后重进 |
