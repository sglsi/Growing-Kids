- `R-技术-08` **全局表零鉴权**（2026-10-24 新增，已加固待彻底修）：`knowledge_articles` 为全局表且内容进 system prompt，CRUD 端点已加 `requireAdmin` + `CHAT_ADMIN_IDS` 白名单（未配置时放行+warn）；彻底方案=`users` 加 role 列做管理员体系，待思傅决策

## 3. 算法已知缺口

**要写**：
- `R-算法-01` **T7：手写压印刷像素级不可分**（去手写场景 ② 误擦率约 38%）：产品决策=**保持现状**（疑罪从无，宁可少擦）；触发重评条件=出现更高优先级用户反馈或新的可分离特征；
- `R-算法-02` **G16 指标看护**：口径 M ≤ 2.0%，每次算法改动后必须跑探针回归；
- `R-算法-03` **OCR 侧车（PP-StructureV3）冷启动**：空闲 900s 回收后按需重启，首次请求有启动延迟；现状=接受（precise 模式容忍）；
- `R-算法-04` **公式渲染为近似实现**：自研 vlist 布局 + 根号近似（√+border-top），复杂公式与专业排版有差距；不支持时整行回退源码（可接受降级）。
