# GK-DD-14 错题提取流程详细设计

> 编号：GK-DD-14 ｜ 版本：v0.0（提纲） ｜ 日期：2026-10-24 ｜ 状态：提纲待审
> 读者：前端 / 算法 ｜ 上游：SRS-01、DD-10 ｜ 下游：QA-15
> 定位：拍照 → 多页 → 识别 → 条目切分 → 编辑 → 入题 的**完整业务状态机**。算法细节在 DD-10，本文讲流程与数据结构。

---

## 1. 文档目的与范围

**要写**：本文讲"错题提取页怎么跑"；识别算法见 DD-10，图像编辑见 DD-08 第 11 章，接口见 ADD-06。历史专题报告（错题提取技术文档、真实作业验收报告、PaddleOCR 接入验证、成果留存索引）并入本文并在相应章节引用。

## 2. 流程总览

**要写**：流程图 + 分阶段说明（选图 → 来源页管理 → 识别 → 条目切分 → 逐条编辑 → 入题）；每步的产物与可回退性；典型耗时。

## 3. 来源页管理

**要写**：
- 数据结构 `boardPages`（页面 url、状态、OCR 结果、条目）；
- 页面操作：添加图片（一次多选）、删除、排序（上移/下移）、看大图、重新识别本页；
- 页面状态机：待识别 / 识别中 / 已识别 / 失败；失败重试与并发控制；
- 多页合并时的顺序与编号规则。

## 4. 版面分析与条目级切分

**要写**：
- 版面分析：页面 → 题目块（红笔检测辅助、题号识别、空白间隔）；
- **条目级切分算法**：如何把一页切成多道题（几何 + 语义双依据）；
- 切分错误的常见形态与人工纠正方式；
- 与红笔判错的协作（判错结果是否参与切分）。
**素材**：`docs/design/红笔检测与条目级切分-修复验证报告.md`

## 5. OCR 结果与文本分段

**要写**：
- 段落结构（页面 → 段 → 行）与前端消费方式（`wrongq-ocr-panel` / `wrongq-text-panel`）；
- 可选中复制、分段采纳（复制单段 / 复制所选 / 全选清空）；
- 识别结果与条目的映射关系；
- 识别不准时的兜底（重新识别本页、手动编辑）。

## 6. 裁剪为图片题目

**要写**：
- 场景：**只裁剪、不识别、只存图**（如几何图形题、无法识别的手写）；
- 裁剪交互（矩形框 / 四角）、归一化坐标；
- 上传语义为 `attach`（不是 `save`），key 写入题目的 `content.question_images`；
- title 兜底「图片题目」，**允许无题干只有图**（后端校验已放宽）。

## 7. 编辑与替换

**要写**：
- 图片编辑（裁剪/旋转/黑白/高清/去手写）后的**原位替换**；
- ⚠️ 替换来源页图片后必须清空该页的旧 OCR 段落（否则文字与图不一致）；
- 条目内文字编辑与数学符号输入。

## 8. 入题与去重

**要写**：
- 批量保存（createBatch）与单条保存的选择；
- 保存时写入的字段（题干、图片、来源页、学科、状态）；
- 去重策略（同一页重复点保存怎么办）；
- 保存后跳转与缓存失效（`tl` 域）。

## 9. 状态机与异常处理

**要写**：完整状态转换表（含中断恢复：切后台、网络失败、识别超时、配额耗尽）；每类异常的用户可见提示与可恢复动作；数据不会丢的保证（草稿暂存策略，若无则写明风险）。

## 10. 验收结果

**要写**：真实作业验收的结论（准确率、耗时、失败模式分布）、探针脚本位置；残留问题登记到 OPS-18。
**素材**：`docs/design/错题提取-真实作业验收报告.md`、`错题提取功能验证报告-PaddleOCR3.7.0接入后.md`
