## 一、这份政策管什么

「成长学习伙伴」（以下简称"本小程序"）由个人开发者运营，用于帮家长整理孩子的错题、复习与学习记录。

本政策说明我们收集哪些信息、为什么收集、会和谁共享、保存多久，以及你可以怎么查、改、删。

本小程序面向家长使用，实际记录的学习数据属于未成年人。因此我们在第 5 节对未成年人信息做了额外约定。

## 二、我们收集哪些信息

1. **身份标识**：微信登录时获得的应用内唯一标识（openid）、你设置的昵称与头像；未登录时使用一个随机生成的设备编号，用于在同一台手机上保持同一份数据。
2. **你主动上传的内容**：错题照片、题目文字、答案与解题过程、学科分类、标签、资料库文档（PDF/Word/图片）、成长记忆中的文字与图片/视频。
3. **学习记录**：题目是否加入复习本、复习次数与掌握状态、导出记录。
4. **运行信息**：识别与搜索失败时的错误信息、耗时，用于排查问题。这类信息不含你的题目内容明细，也不会用于画像或广告。

**我们不会收集**：通讯录、通话记录、短信、精确地理位置、剪贴板内容、相册中未选择的其他照片，也不会读取与本小程序无关的文件。

## 三、这些信息用来做什么

1. **识别题目**：把你拍的题目图转成文字，切分成一道一道题。
2. **检索与讲解**：根据题干去检索参考答案与解题思路，或在没有现成答案时由大模型生成讲解。
3. **复习与统计**：按学科、掌握状态组织复习本，统计你的学习进度。
4. **导出与备份**：把题目导出为 Word、把复习本合成为 PDF；如你开启网盘归档，还会把资料保存到你自己的百度网盘。

其中「检索与讲解」需要把题干发往第三方服务。这一项**默认关闭**——不开启时，识别、切分、复习、导出仍可正常使用，只是不检索现成答案、也不由大模型生成讲解。你可以在「我的 → 隐私与账号 → AI 与在线检索」中开启，也可以随时关闭，关闭后立即生效。

我们不会把你的题目内容用于训练模型、不会向第三方出售，也不会用于广告投放。

## 四、会和谁共享（第三方清单）

实现功能必须把少量数据交给以下服务方处理，除此之外不对外提供：

| 接收方 | 接收内容 | 用途 | 存放位置 |
|---|---|---|---|
| 腾讯云 / Supabase | 账号、题目、图片、文档 | 数据库与文件存储 | 境外区域（新加坡），**可能涉及数据出境** |
| 腾讯 ima 知识库 | 题目的文字或图片 | 题库检索、匹配参考答案 | 境内 |
| 大模型服务商（扣子 / DeepSeek / 腾讯混元） | 题干文字 | 无现成答案时生成讲解 | 境内 |
| 百度网盘 | 你保存的资料 | **仅在你本人开启归档时**，写入你自己的网盘目录 | 境内 |
| 百度网盘（开发者运维备份） | 加密后的数据库整体备份文件 | 系统故障时恢复数据 | 境内（开发者本人网盘账号） |
| 微信开放接口 | 登录凭证、待检测文本 | 登录、内容安全检测（判断文本是否违规） | 境内 |

**受「AI 与在线检索」开关控制的两项**：腾讯 ima 知识库、大模型服务商。该开关默认关闭，未开启时题干不会发往这两处；开启与关闭都在「我的 → 隐私与账号 → AI 与在线检索」中操作，关闭后立即生效。

**关于运维备份**：每天把数据库整体备份后存到开发者本人的网盘，用于系统故障时恢复数据。备份文件在离开服务器前已用 **AES-256-GCM 加密**，网盘里存的是无法直接读取的密文；解密口令单独保管，不与备份文件放在一起。这是**整体备份**，不针对任何个人，也无法按人筛选。

上述服务方仅在本小程序功能所需的范围内处理数据。我们不向其提供你的微信昵称、头像等身份信息（**内容安全检测除外**——该接口必须携带 openid 才能生效）。

## 五、未成年人个人信息（重要）

1. 本小程序的记录对象是未成年人。注册与使用应由**监护人**（家长）完成，并由监护人同意本政策。
2. 我们只收集学习所必需的信息：题目图片、题目文字、答案、复习状态。**不收集**孩子的姓名、学校、班级、身份证号、人脸、声音、位置。
3. 请勿上传含孩子真实姓名、学校班级、身份证号、联系方式等信息的图片；若已上传，可随时删除。
4. 监护人有权随时查看、更正、删除孩子的全部数据，或直接注销账号（见第六节），**无需说明理由**。
5. 若我们发现数据是在未取得监护人同意的情况下收集的，会尽快删除。

## 六、你的权利：查看、更正、导出、删除、注销

- **查看与更正**：在小程序内可直接查看和修改题目、答案、学科、昵称头像。
- **导出**：题目可导出为 Word，复习本可合成为 PDF/Word，数据可带走。
- **删除**：删除单条题目或资料后，其文件在引用计数归零后会被回收。
- **注销账号**：在「我的 → 隐私与账号 → 注销账号」中操作。注销会删除你的账号与本人全部业务数据（题目、图片、文档、学科、成长记忆、对话记录、答案缓存），**不可恢复**。
- **注销时共享内容的处理**：同一份文件如果别的账号也在引用（内容完全相同的图片），只解除你的引用计数、**不会删除文件本身**，以免影响他人数据；跨用户共享的识别结果缓存（同一张图的 OCR 结果）**不随账号删除**。
- 注销后如需继续使用，重新进入即可生成新的匿名身份；已删除的数据无法找回。

## 七、保存多久

- **登录账号**：保存到你注销账号为止。
- **未登录的匿名身份**：连续 **30 天**不使用即自动过期，过期后由后台任务清理，其名下数据一并删除。
- **答案缓存**：成功结果长期保留（避免重复消耗第三方配额），搜不到的结果仅保留数小时。
- **识别结果缓存**：按内容寻址长期保留，用于避免同一张图重复识别；升级识别引擎后会自然失效。
- **服务端运行日志**：保留 **7 天**，仅含接口路径、状态码、耗时等，**不含题目内容**。
- **数据库备份**：本地与异地各保留最近 **14 份**，按天滚动覆盖，旧备份约 14 天后自动删除。备份是整体加密文件，无法单独摘除某个账号，因此**注销账号后，你的数据仍可能在备份中留存不超过 14 天**，之后随旧备份被覆盖而消失。

## 八、我们怎么保护这些数据

1. 每次请求都用**服务端签发的签名令牌**确认身份，不信任客户端传来的身份编号。
2. 所有数据查询都按用户维度隔离，配套静态检查脚本防止漏写条件。
3. 文件存放在对象存储中，通过**不可猜的文件标识**访问；手机上打开文档走后端代理。
4. 密钥只保存在服务端，小程序端不持有任何密钥；部署包中的配置文件加密存放。
5. 数据库每日自动备份，备份文件在写入磁盘和上传网盘**之前**就用 AES-256-GCM 加密，并带完整性校验——文件被截断或改动会直接失败，而不是解出一份看起来正常、实际错误的数据。解密口令与备份文件分开保管。
6. 需要说明的是：**没有绝对安全**。若发生数据安全事件，我们会在小程序内公告并说明影响范围与处置措施。

## 九、本政策会更新

功能或第三方服务变化时我们会更新本政策，并在小程序内提示。

政策版本号变化后，需要你重新确认同意；不同意时你可以停止使用并注销账号。

## 十、联系我们

对本政策有疑问、要行使上述权利、或要投诉，可通过小程序内「我的 → 意见反馈」留言，或通过开发者在小程序详情页公示的联系方式联系。

我们会在 **15 个工作日**内答复。
