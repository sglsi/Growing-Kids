# 百度网盘接入资料库（操作指引）

> 目标：资料库（library）保存的文件，在百度网盘 **`/学生/GrowingKids资料库`** 里同步出现一份副本，
> 家长在电脑网盘里就能直接看到孩子收集的资料。
> 定稿：思傅 2026-10-24。

## 0. 为什么必须走 OpenAPI（而不是 WorkBuddy 的网盘连接器）

| 能力 | WorkBuddy 百度网盘连接器 | 后端 OpenAPI 直连（本方案） |
|---|---|---|
| 列目录 / 搜索 | ✅ | ✅ |
| 上传**文本文件**、URL 转存 | ✅ | ✅ |
| 上传 **PDF / 图片等二进制** | ❌ 不支持 | ✅（precreate → superfile2 → create） |
| 后端（NestJS）可调用 | ❌ 凭据客户端加密，后端拿不到 | ✅ |
| 部署到云端后仍可用 | ❌ | ✅ |

结论：资料库文件是 PDF/图片，只能走后者。

## 1. 思傅只需做一次的操作（约 10 分钟）

### ① 创建应用，拿 AppKey / SecretKey

1. 打开 <https://pan.baidu.com/union/> ，用你的百度账号登录；
2. 「创建应用」→ 应用类型选个人/自用；**是否上架选「否」**（自用不需要审核也能拿到授权）；
3. 创建成功后得到 **AppKey** 和 **SecretKey**。

### ② 写进密钥文件

在 `server/.env.secrets` 追加两行（该文件不进仓库，敏感项部署前会被加密）：

```ini
BAIDU_APP_KEY=你的AppKey
BAIDU_SECRET_KEY=你的SecretKey
```

### ③ 生成授权链接并授权

```bash
node server/scripts/baidu-oauth.mjs auth
```

浏览器打开它打印的链接 → 用**你的百度账号**授权 → 页面给出一个「授权码（code）」。
（code 只有 10 分钟有效，拿到就立刻用掉。）

### ④ 用授权码换 token

```bash
node server/scripts/baidu-oauth.mjs code <授权码>
```

脚本会把 `BAIDU_ACCESS_TOKEN`（30 天）和 `BAIDU_REFRESH_TOKEN`（10 年）写进 `.env.secrets`。

### ⑤ 自检

```bash
node server/scripts/baidu-oauth.mjs check
```

应看到：token 已刷新 / 网盘账号 / 空间用量 / `/学生/GrowingKids资料库` 目录内容。

### ⑥ 开启资料库同步并重启后端

在 `server/.env` 加一行，然后重启后端（`POST http://127.0.0.1:3002/wake`）：

```ini
LIBRARY_NETDISK_SYNC=true
```

## 2. 设计取舍（改代码前必读）

- **主存储不变**：`library_docs.file_key` 仍指向本地/Supabase，小程序内预览照旧秒开；
  网盘只是**归档副本**，路径记在 `netdisk_path`（迁移 `0015`）。
- 为什么不让 `file_key` 直接指向网盘：网盘读取要「filemetas 换 dlink（8 小时有效期）→ 带
  `User-Agent: pan.baidu.com` 下载」，限速且多一跳，每次打开文档都会变慢。
- **同步是 best-effort**：网盘不可用只记日志，绝不让「保存资料」失败；新增资料后副本异步出现（几秒内）。
- **默认不联动删除**：怕误删网盘文件。要联动需显式开 `LIBRARY_NETDISK_DELETE_ON_REMOVE=true`。

## 3. 环境变量一览

| 变量 | 位置 | 默认 | 说明 |
|---|---|---|---|
| `BAIDU_APP_KEY` | `.env.secrets` | — | 开放平台 AppKey |
| `BAIDU_SECRET_KEY` | `.env.secrets` | — | 开放平台 SecretKey |
| `BAIDU_REFRESH_TOKEN` | `.env.secrets` | — | 由 `auth`→`code` 两步取得，10 年 |
| `BAIDU_ACCESS_TOKEN` | `.env.secrets` | — | 30 天；缺失时服务自动用 refresh_token 换 |
| `BAIDU_NETDISK_ROOT` | `.env` | `/学生/GrowingKids资料库` | 网盘归档根目录 |
| `LIBRARY_NETDISK_SYNC` | `.env` | `false` | 开资料库→网盘同步 |
| `LIBRARY_NETDISK_DELETE_ON_REMOVE` | `.env` | `false` | 删资料时同步删网盘副本 |
| `BAIDU_TIMEOUT_MS` / `BAIDU_UPLOAD_TIMEOUT_MS` | `.env` | `30000` / `120000` | 接口超时 |

## 4. 部署前必做

改完 `.env.secrets` 后**必须**重跑加密再部署：

```bash
node server/scripts/encrypt-env.mjs
```

## 5. 排障

| 现象 | 原因 / 处理 |
|---|---|
| `check` 报「access_token 刷新失败」 | refresh_token 失效（换设备/改密码/撤销应用）→ 重跑 ③④ |
| 上传报 `errno=31034` 之类 | 应用未获网盘写入权限 → 授权时确认勾选了 netdisk 权限 |
| 日志 `网盘同步未启用（缺 …）` | `.env.secrets` 缺项，或后端启动时还没写入 → 重启后端 |
| 网盘里没有副本 | 看后端日志 `[library] 已归档到网盘` / `网盘归档失败`；失败原因会完整打印 |
| 中文文件名乱码 | 已由 `sanitizeFileName` + urlencode 处理；若仍异常，检查网盘客户端版本 |
