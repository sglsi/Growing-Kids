## 0. 先看清两条硬事实（决定走哪条路）

### 事实一：为什么找不到「创建应用」

官方《创建应用》文档写明**两个前提条件**：

1. 已登录百度账号；
2. **已通过实名认证**。

没做实名认证时，控制台里不会出现「创建应用」按钮。**实名认证才是卡点**，不是入口错了。
（个人认证：身份证号 + 手机/邮箱，官方称"可立即审核完成"；企业认证 1~3 工作日。）

### 事实二：2026-06-03 之后创建的应用，只能写 `/apps/{应用名}/`

官方文档原文（更新于 2026-08-03）：

> 为进一步保障用户网盘数据安全，降低第三方应用误访问、误操作风险，**2026 年 6 月 3 日后在平台创建的应用**，
> 以下接口仅支持访问 `/apps/{appname}` 目录下的文件：
> `download`、`multimedia?method=listall`、`filemanager`、**`precreate`**、`meta`、`move`

`precreate` 是**上传的第一步** ⇒ 按文档，新应用**无法把文件写进 `/学生/…`**，只能写进 `/apps/{应用名}/…`。

> **⚠️ 实证补充（2026-10-25 联调实测，与本条文档结论相反，以代码注释与本文档并存备查）**：
> GrowingKids 应用（2026-10 新建）实测**可以**读写 `/学生/GrowingKids资料库`——
> precreate/superfile2/create 上传、list、filemanager 删除全部成功（errno=0）。
> 即该新规**当前未对本应用实际生效**（可能仅对上架/审核态应用强制执行）。
> 即便如此，归档根目录仍按合规取 `/apps/GrowingKids/GrowingKids资料库`（防百度后续强制执行时静默失败）；
> 想落 `/学生/` 只需设 `BAIDU_NETDISK_ROOT=/学生/GrowingKids资料库`（免改代码免重编译，重启生效）。

## 方案 A · OpenAPI 直连（详细步骤）

### ① 成为开发者（先做这一步，否则看不到"创建应用"）

1. 打开 **<https://pan.baidu.com/union/>** ，右上角用你的百度账号登录；
2. 首页点「**快速接入**」→ 同意《百度网盘开放平台开发者服务协议》；
3. 按引导完成**实名认证**（个人开发者：身份证号 + 手机号/邮箱）。
   - 个人认证：至少可创建 1 个应用，基础能力含上传/下载/管理文件；
   - 企业认证：最多 10 个应用，1~3 个工作日。

### ② 创建应用

1. 认证通过后打开**控制台**：<https://pan.baidu.com/union/console/applist>
2. 点「**创建应用**」（或「+创建应用」），按下面填：

| 字段 | 填什么 | 注意 |
|---|---|---|
| 应用用途 | **个人使用** | 免审核、创建后直接上线，限 10 个用户；选"公开发布"要提交上线审核 |
| 应用类型 | **软件类别** | 我们是在后端服务里调用接口；⚠️ **选择后无法更改** |
| 应用名称 | 建议 `GrowingKids` | 0~12 字，仅汉字/字母/数字/空格/`-`/`_`；⚠️ **它会成为网盘里的目标文件夹名**（即 `/apps/GrowingKids/`），授权页也会展示 |
| 应用描述 | 至少 30 字 | 例："用于把孩子的错题与教辅资料归档到我的百度网盘，供家长在电脑端查看。" |

3. 创建成功后，在**应用详情页**拿到凭证：**AppId、AppKey、SecretKey、Signkey**。
   （我们只需要 **AppKey** 与 **SecretKey**。）

### ③ 配置回调地址（redirect_uri）

应用详情页 →「**安全设置**」→ 授权回调地址：

- 我们的脚本用 `oob`（无回调，授权后页面直接显示授权码），先把 `oob` 填进去；
- 若平台不接受 `oob`，就填一个你能访问的 https 地址，授权后浏览器地址栏会出现 `…?code=xxxx`，复制 `code` 即可。

### ④ 把凭证写进密钥文件

`server/.env.secrets` 追加两行（该文件不进仓库，部署前会被加密）：

```ini
BAIDU_APP_KEY=你的AppKey
BAIDU_SECRET_KEY=你的SecretKey
```

### ⑤ 生成授权链接并授权

```bash
node server/scripts/baidu-oauth.mjs auth
```

浏览器打开它打印的链接 → 用**你的百度账号**（存资料的那个账号）授权 → 页面给出「授权码（code）」。
（code 只有 10 分钟有效，拿到立刻用。）

### ⑥ 用授权码换 token

```bash
node server/scripts/baidu-oauth.mjs code <授权码>
```

脚本把 `BAIDU_ACCESS_TOKEN`（30 天）与 `BAIDU_REFRESH_TOKEN`（10 年）写进 `.env.secrets`。

### ⑦ 自检

```bash
node server/scripts/baidu-oauth.mjs check
```

应看到：token 已刷新 → 网盘账号与空间 → 归档目录内容。

⚠️ 若报「precreate 失败 errno=xxx」，先确认目录在 `/apps/{应用名}/` 下（见事实二）。

### ⑧ 开启同步并重启后端

`server/.env` 加一行，然后重启后端（`POST http://127.0.0.1:3002/wake`）：

```ini
LIBRARY_NETDISK_SYNC=true
```

> ✅ 2026-10-25 已配置并重启（新后端 pid 44684）。`BAIDU_NETDISK_ROOT` **可不设**——
> 代码默认值即 `/apps/GrowingKids/GrowingKids资料库`（源码 `DEFAULT_ROOT`）；
> 想改目录再显式设它，无需改代码/重编译。

## 联调实录（2026-10-25，全部通过）

### 授权链路

| 步骤 | 命令 | 结果 |
|---|---|---|
| 生成授权链接 | `baidu-oauth.mjs auth` | ✅ |
| 授权码换 token | `baidu-oauth.mjs code <code>` | ✅ access_token（30 天）+ refresh_token（10 年）写入 `.env.secrets` |
| 自检 | `baidu-oauth.mjs check` | ✅ uid=3473753688（VIP2），目录不存在（errno=-9，首次上传自动建） |
| 加密 | `encrypt-env.mjs` | ✅ 17 项 |

> 小插曲：第一个授权码超时报 `invalid_grant`（10 分钟有效期 + 一次性），重新授权后成功。
> **授权码拿到后要立刻用**。

### 服务层全链路（`scripts/netdisk-e2e.mjs`，直接驱动 `BaiduNetdiskService`）

`ensureDir → upload（中文文件名）→ list 命中 → download 回读逐字节一致 → remove → list 确认消失` —— 六步全过。

### 资料库端到端（`scripts/library-netdisk-e2e.sh`，走后端 API）

上传（`purpose=attach`）→ `POST /api/library` → **轮询第 1 次即命中**：

```
netdisk_path=/apps/GrowingKids/GrowingKids资料库/网盘归档联调-082153.txt
```

后端日志：`[library] 已归档到网盘：/apps/GrowingKids/GrowingKids资料库/网盘归档联调-082153.txt`；
网盘目录实测含该文件（81B）；删资料库条目后 DB 记录消失、网盘副本按设计保留。

### 踩坑记录（复现时避开）

1. **dist 比源码旧**：联调最初跑到的是 dist 里的旧 `DEFAULT_ROOT`（`/学生/...`），
   表现为「`/学生/` 竟能写成功」。改完源码必须 `npx nest build` 再重启（本项目老规矩）。
2. **`X-User-Id` 传不存在的裸 id**：中间件 `findById` 查不到 → 每次请求**新建匿名用户**，
   create 落 A 账号、list 查 B 账号，永远查不到刚建的数据。测试要用 **`X-Device-Id`**（稳定身份）。
3. **上传接口返回字段是 `key`**（不是 `file_key`）；`file_key` 是建资料库条目时的入参名。
4. **Git Bash 无 `jq`**：JSON 提取用 `node -e` 正则；本环境也无 `ps` 进程查看，杀进程走 PowerShell
   `Stop-Process -Id <pid> -Force`（Git Bash 的 `kill` 对跨会话进程无效）。

## 方案 B · 本机客户端同步空间（零凭证，目录可落在 `/学生`）

利用本机已安装的**百度网盘 PC 客户端**：它能把「本机文件夹 ↔ 网盘文件夹」双向同步，
后端只要把文件写进本机同步目录，客户端自动上传——**不受 `/apps` 限制**。

1. 打开本机百度网盘客户端 →「同步空间」（或"同步盘/备份"）；
2. 新建同步关系：
   - 本机目录：建议 `D:\AI\gk-netdisk-sync\GrowingKids资料库`
   - 网盘目录：**`/学生/GrowingKids资料库`**（网盘里已建好）
3. 后端配置（`.env`）：
   ```ini
   LIBRARY_NETDISK_SYNC=true
   BAIDU_SYNC_LOCAL_DIR=D:\AI\gk-netdisk-sync\GrowingKids资料库
   ```
   后端把资料库文件**额外写一份到该本机目录**（不动主存储），由客户端上传。
4. 生效条件：这台电脑开机 + 客户端在线；客户端关着时文件暂存，下次启动补传。

> 本方案的后端实现（写本地副本）尚未编码，选定后我再补：在 `library.service` 的
> `syncToNetdisk` 加一条"本地副本"分支，网盘 API 不可用时自动改走它。

## 设计取舍（改代码前必读）

**网盘角色一句话：只写不读的单向归档副本。**
- **能**：小程序用户上传到资料库的文件（图片/PDF/Word 等），保存时自动复制一份到网盘，
  家长在自己电脑的网盘客户端里直接就能看到（本项目接网盘的初衷）。
- **不能/不做**：小程序打开任何资料都走主存储（Supabase 的 `file_key`），**网盘不参与读取**——
  `BaiduNetdiskService.download()` 已实现但无任何业务调用；反向的「网盘 → 资料库」
  （家长在网盘丢个文件想在 APP 里看）**未实现**，是可选后话，要做时在 library 加导入入口即可。

- **主存储不变**：`library_docs.file_key` 仍指向本地/Supabase，小程序内预览照旧秒开；
  网盘只是**归档副本**，路径记在 `netdisk_path`（迁移 `0015`）。
- 为什么不让 `file_key` 直接指向网盘：网盘读取要「filemetas 换 dlink（8 小时有效期）→ 带
  `User-Agent: pan.baidu.com` 下载」，限速且多一跳，每次打开文档都会变慢。
- **同步是 best-effort**：网盘不可用只记日志，绝不让「保存资料」失败。
- **默认不联动删除**：怕误删网盘文件。要联动需显式开 `LIBRARY_NETDISK_DELETE_ON_REMOVE=true`。

## 环境变量一览

| 变量 | 位置 | 默认 | 说明 |
|---|---|---|---|
| `BAIDU_APP_KEY` | `.env.secrets` | — | 控制台应用详情里的 AppKey |
| `BAIDU_SECRET_KEY` | `.env.secrets` | — | 控制台应用详情里的 SecretKey |
| `BAIDU_REFRESH_TOKEN` | `.env.secrets` | — | 由 `auth`→`code` 两步取得，10 年 |
| `BAIDU_ACCESS_TOKEN` | `.env.secrets` | — | 30 天；缺失时服务自动用 refresh_token 换 |
| `BAIDU_NETDISK_ROOT` | `.env` | `/apps/GrowingKids/GrowingKids资料库` | 归档根目录；新应用必须在 `/apps/{应用名}/` 下 |
| `LIBRARY_NETDISK_SYNC` | `.env` | `false` | 开资料库→网盘同步 |
| `LIBRARY_NETDISK_DELETE_ON_REMOVE` | `.env` | `false` | 删资料时同步删网盘副本 |
| `BAIDU_TIMEOUT_MS` / `BAIDU_UPLOAD_TIMEOUT_MS` | `.env` | `30000` / `120000` | 接口超时 |

## 排障

| 现象 | 原因 / 处理 |
|---|---|
| 控制台没有「创建应用」 | 未完成实名认证（先做①的第 3 步） |
| `check` 报「token 刷新失败」 | refresh_token 失效（改密/撤销应用）→ 重跑 ⑤⑥ |
| 报 `precreate 失败 errno=xxx` | 目录不在 `/apps/{应用名}/` 下（2026-06-03 新规）→ 改 `BAIDU_NETDISK_ROOT` |
| 上传报权限类 errno | 授权时没勾选 netdisk 权限，或应用用途/类型选错 |
| 日志「网盘同步未启用（缺 …）」 | `.env.secrets` 缺项或未重启后端 |
| 网盘里没有副本 | 看日志 `[library] 已归档到网盘` / `网盘归档失败`；失败原因会完整打印 |
| 中文文件名乱码 | 已由 `sanitizeFileName` + urlencode 处理；若仍异常检查客户端版本 |
