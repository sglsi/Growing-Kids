## 17:31 复核「为什么不勾手机号 / 相册(仅写入) / 设备信息」（思傅质疑）

- **设备信息**：🔴 订正我 16:29 的粗放说法——项目**有 8 处** `Taro.getSystemInfoSync()`（`lib/measure.ts` / `use-keyboard-avoid.ts` / `image-editor.tsx` / `wrongq-box-editor.tsx` / `ui/popover.tsx` / `dev-debug.ts`），但只取 `windowWidth/windowHeight` 做布局；**官方隐私接口对照表里没有 `getSystemInfoSync`，也没有「设备信息」这一行**（`DeviceInfo` 只出现在第三方平台 `setprivacysetting` 的全量 privacy_key 清单里）。`X-Device-Id` 是前端自生成随机串（存 `gk_device_id`），用于匿名身份锚定 + 登录时 `findOrCreateByOpenId(openid, deviceId)` 数据迁移，**不是微信返回的设备标识符**；思傅说的「设备与个人关联、保护数据安全」目标其实已由这套机制实现，且它作为个人信息**已在应用内《隐私政策》第一节披露**。⇒ 平台清单不勾、应用内政策披露，是两套独立义务，不矛盾。兜底：提审时若后台把「设备信息」列为必填项，就勾并如实填「适配不同屏幕尺寸的界面布局」。
- **不勾 ≠ 不处理 / 不安全**：平台清单只约束微信隐私接口；应用自收集数据走《个人信息保护法》义务（政策披露 + 同意）。数据隔离靠 `.eq('user_id', userId)` + 签名令牌，不靠勾选项。
